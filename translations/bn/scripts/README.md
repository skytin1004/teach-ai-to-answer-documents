# Scripts

এই ফোল্ডারটি রিপোজিটরি যাচাই স্ক্রিপ্ট ধারণ করে।

## `verify_notebooks.py`

স্থানীয় Markdown লিঙ্ক, নোটবুক JSON, নোটবুক আউটপুট পরিচ্ছন্নতা, এবং উচ্চ-ঝুঁকির গোপন প্যাটার্নগুলি যাচাই করে:

```powershell
python scripts\verify_notebooks.py
```

সমস্ত পাবলিক লোকাল-সেফ নোটবুকগুলি চালায়:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions ওয়ার্কফ্লো একই স্ক্রিপ্ট ব্যবহার করে।

`drafts/` এর অধীনে খসড়া উপাদানগুলি তখন পর্যন্ত বাদ দেওয়া হয় যতক্ষণ না এটি পাবলিক ইনডেক্সের জন্য প্রস্তুত হয়।
