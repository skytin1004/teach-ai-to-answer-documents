# পরিবর্তন লগ

## প্রকাশিত হয়নি

**আপনার নথি অনুসারে প্রশ্নের উত্তর দেওয়ার জন্য AI প্রশিক্ষণের** প্রাথমিক প্রকাশিত রিলিজের পরিধি।

### যুক্ত হয়েছে

- RAG আর্কিটেকচার সিদ্ধান্ত, Azure বনাম ওপেন-সোর্স বাণিজ্যিক সুবিধা, এবং ফাইন-টিউনিং কোথায় মানায় তার উপর সিরিজ ১ নিবন্ধ।
- Qdrant লোকাল মোড, FastEmbed লোকাল এম্বেডিংস, হালকা ওজনের রির্যাঙ্কিং, Ollama, এবং Phi-4-mini ব্যবহার করে একটি লোকাল ওপেন-সোর্স RAG ওয়ার্কফ্লো জন্য সিরিজ ২ নিবন্ধ ও নোটবুক।
- সিরিজ ২ ধাপে ধাপে শুরু থেকে শেষ পর্যন্ত টিউটোরিয়াল ফরম্যাট, পাইথন স্নিপেট এবং নোটবুক চালানোর যাচাই নোটসহ।
- লোকাল CPU-বান্ধব রিট্রিভালের ডিফল্ট পথ রেখে ঐচ্ছিক সিরিজ ২ উত্তর-উৎপাদন পথ Ollama এবং Phi-4-mini দ্বারা।
- RTX 3060 ল্যাপটপ GPU-তে `phi4-mini:3.8b` ব্যবহার করে সিরিজ ২-এর জন্য লোকাল Ollama যাচাই।
- স্কুল নীতি এবং কোর্স AI নির্দেশনার জন্য নমুনা ডেটা।
- পাবলিক নোটবুক এবং রেপোজিটরি-স্তরের যাচাইয়ের জন্য রিকোয়ারমেন্ট ফাইল।
- লোকাল মার্কডাউন লিঙ্ক ও নোটবুক যাচাই/চালনার জন্য রেপোজিটরি যাচাই স্ক্রিপ্ট।
- নোটবুক যাচাইয়ের জন্য GitHub Actions ওয়ার্কফ্লো।
- লোকাল Ollama জেনারেশনের জন্য `.env.example` ফাইল, স্থানীয় কনফিগারেশন ছাড়াই বিকল্প সেটআপ।
- নিবন্ধ, নোটবুক, রিকোয়ারমেন্ট, নমুনা ডেটা, এবং স্ক্রিপ্টগুলির জন্য ফোল্ডার-স্তরের README ফাইল।
- পাবলিক নিরাপত্তা এবং যাচাইয়ের জন্য প্রকাশনার চেকলিস্ট।
- ভবিষ্যতের Azure এবং মূল্যায়ন বিষয়াবলীর জন্য ড্রাফট ওয়ার্কস্পেস।

### যাচাই করা হয়েছে

- লোকাল মার্কডাউন লিঙ্ক যাচাই পাস হয়েছে।
- সিরিজ ২ নোটবুক সফলভাবে যাচাই হয়েছে।
- সিরিজ ২ নোটবুক লোকাল যাচাইকরণ পরিবেশে সফলভাবে চালানো হয়েছে।
- নোটবুক ফাইলগুলো সংরক্ষিত আউটপুট বা কার্যক্রম সংখ্যার ছাড়াই রাখা হয়েছে।
- কোনো বাস্তব গোপনীয়তা কমিট করা হয়নি।
