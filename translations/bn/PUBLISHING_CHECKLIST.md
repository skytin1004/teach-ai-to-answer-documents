# প্রকাশের চেকলিস্ট

সার্বজনীন আপডেট কমিট বা পুশ করার আগে এই চেকলিস্ট ব্যবহার করুন।

## নিরাপত্তা

- নিশ্চিত করুন Markdown ফাইল, নোটবুক, নমুনা ডেটা বা স্ক্রিপ্টে কোনো API কী, টোকেন, পাসওয়ার্ড, বা ব্যক্তিগত এন্ডপয়েন্ট লেখা নেই।
- ক্রেডেনশিয়ালগুলো পরিবেশ ভেরিয়েবল বা পরিচালিত পরিচয় ব্যবস্থায় রাখুন, কমিট করা ফাইলে নয়।
- `.env` ফাইল বা নির্বাহিত নোটবুক আউটপুট ফাইল কমিট করবেন না।
- `.env.example` শুধুমাত্র প্লেসহোল্ডার হিসেবে রাখুন।

## যাচাই

রিপোজিটরি যাচাইকরণ স্ক্রিপ্ট চালান:

```powershell
python scripts\verify_notebooks.py
```

পাবলিশ করার আগে সম্পূর্ণ লোকাল-সেফ নোটবুক এক্সিকিউশন চালান:

```powershell
python scripts\verify_notebooks.py --execute
```

প্রত্যাশিত চেকসমূহ:

- লোকাল Markdown লিঙ্ক কাজ করে
- নোটবুক JSON বৈধতা পাশ করে
- নোটবুকে সংরক্ষিত আউটপুট বা কার্যকরী সংখ্যা নেই
- উচ্চ-ঝুঁকিপূর্ণ গোপন প্যাটার্ন স্ক্যান পাশ করে
- সার্বজনীন নোটবুকগুলো স্থানীয়ভাবে কাজ করে
- `drafts/` আওতাধীন খসড়া সামগ্রী ইচ্ছাকৃতভাবে বাদ দেয়া হয়েছে

## পর্যালোচনা

- নিশ্চিত করুন README আরটিকেল লিঙ্কগুলো উদ্দেশ্যপ্রণোদিত ফাইলগুলোতে নির্দেশ করে।
- নিশ্চিত করুন প্রতিটি আরটিকেলে রিপোজিটরি নেভিগেশন এবং সম্পর্কিত নোটবুক লিঙ্ক রয়েছে।
- নিশ্চিত করুন সার্বজনীন সূচক থেকে খসড়াগুলো লিঙ্ক করা হয় না যতক্ষণ না তারা প্রকাশের জন্য প্রস্তুত হয়।
- নিশ্চিত করুন GitHub ইস্যু এবং পুল রিকোয়েস্ট টেমপ্লেটগুলি এখনও রিপোজিটরির কর্মপ্রবাহের সাথে মেলে।
- নিশ্চিত করুন আরটিকেলের যাচাইকরণ ফলাফল সর্বশেষ নোটবুক আউটপুটের সাথে মিলে।
- নিশ্চিত করুন পুশের পরে GitHub Actions ওয়ার্কফ্লো চলার জন্য প্রস্তুত।
- নিশ্চিত করুন `CHANGELOG.md` প্রকাশিত আপডেটটি প্রতিফলিত করে।
- নিশ্চিত করুন `CONTRIBUTING.md` এখনও রিপোজিটরির কর্মপ্রবাহের সাথে মেলে।

## Git

- `git status --short --branch` পর্যালোচনা করুন।
- `git diff --stat` পর্যালোচনা করুন।
- স্পষ্টভাবে প্রস্তুত হওয়ার পরই কমিট ও পুশ করুন।
