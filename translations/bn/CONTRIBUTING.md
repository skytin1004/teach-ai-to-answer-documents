# অবদান রাখা

এই রেপোজিটরিটি একটি ব্লগ সিরিজ এবং কার্যকরী নোটবুক উদাহরণ হিসাবে সংগঠিত।

## একটি পুল অনুরোধ (Pull Request) খুলার আগে

স্থানীয় যাচাই স্ক্রিপ্ট চালান:

```powershell
python scripts\verify_notebooks.py
```

সম্পাদনা বা নোটবুক পরিবর্তনের জন্য, স্থানীয় নিরাপদ নোটবুক এক্সিকিউশন চালান:

```powershell
python scripts\verify_notebooks.py --execute
```

## নোটবুক নির্দেশিকা

- নোটবুক গুলো পাঠযোগ্য এবং সংশ্লিষ্ট নিবন্ধের প্রতি ফোকাসযুক্ত রাখুন।
- সেভ করা নোটবুক আউটপুট বা এক্সিকিউশন কাউন্ট কমিট করবেন না।
- `sample_data/` থেকে ছোট নমুনা ডেটা ব্যবহার করুন যতক্ষণ না নিবন্ধে নির্দিষ্ট একটি বহিরাগত উৎস প্রয়োজন হয়।
- আচরণের পরিবর্তনের সময় যাচাই ফলাফল সংশ্লিষ্ট নিবন্ধে রেকর্ড করুন।

## গোপনীয়তা এবং প্রমাণপত্র

- API কী, টোকেন, পাসওয়ার্ড, ব্যক্তিগত এন্ডপয়েন্ট বা `.env` ফাইল কমিট করবেন না।
- `.env.example` শুধুমাত্র প্লেসহোল্ডার মানের জন্য ব্যবহার করুন।
- ঐচ্ছিক স্থানীয় Ollama পরীক্ষা-নিরীক্ষার জন্য পরিবেশ পরিবর্তনশীল ব্যবহার করুন।

## ডকুমেন্টেশন

- নিবন্ধ নেভিগেশন লিঙ্কসমূহ আপ টু ডেট রাখুন।
- নতুন নিবন্ধ, নোটবুক, রিকোয়ারমেন্ট ফাইল বা নমুনা ডেটা ফাইল যোগ করলে `README.md` আপডেট করুন।
- দৃশ্যমান রেপোজিটরি আপডেট প্রকাশের আগে `CHANGELOG.md` আপডেট করুন।

## যাচাইকরণ

GitHub Actions ওয়ার্কফ্লো চালানো হয়:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` এর অধীনে খসড়া উপাদান রেপোজিটরি যাচাই দ্বারা বাদ দেওয়া হয় যতক্ষণ না এটি পাবলিক ইনডেক্সিংয়ের জন্য প্রস্তুত।

## সমস্যা

নিবন্ধ সংশোধনের জন্য নিবন্ধ প্রতিক্রিয়া টেমপ্লেট ব্যবহার করুন এবং নোটবুক এক্সিকিউশন সমস্যার জন্য নোটবুক সমস্যা টেমপ্লেট ব্যবহার করুন।
