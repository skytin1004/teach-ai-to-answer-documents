# আপনার নথির উপর ভিত্তি করে AI কে প্রশ্নের উত্তর দিতে শেখান

এই রেপোজিটরি ২০২৬ সালের একটি ব্লগ সিরিজ সংগ্রহ করে যেখানে RAG, Azure AI পরিষেবা, ওপেন সোর্স বিকল্প, এবং মূল্যায়ন-কেন্দ্রিক কর্মপ্রবাহ ব্যবহার করে ডকুমেন্ট-ভিত্তিক AI সিস্টেম তৈরির কথা বলা হয়েছে।

## পটভূমি

২০২৩ সালে, আমি Azure AI Search এবং Azure OpenAI ব্যবহার করে PDF নথি থেকে প্রশ্নের উত্তর দিতে ChatGPT কে শেখানোর বিষয়ে দুটো টিউটোরিয়াল নিয়ে কাজ করেছি। "আপনার ডেটার ওপর ChatGPT" ধারণাটি তখনও নতুন মনে হচ্ছিল, এবং লক্ষ্য ছিল একটি ব্যবহারিক কর্মপ্রবাহ প্রদর্শন করা: নথি সংরক্ষণ করা, সেগুলোকে সূচকিত করা, প্রাসঙ্গিক সামগ্রী আহরণ করা, এবং সেই প্রসঙ্গ থেকে উত্তর তৈরি করা।

২০২৬ সালে, RAG ইকোসিস্টেম অনেক বড়। Azure AI Search আধুনিক ভেক্টর এবং হাইব্রিড আহরণের প্যাটার্ন সমর্থন করে, Azure OpenAI বৃহত্তর Microsoft Foundry Models ইকোসিস্টেমের অংশ, এবং ল্যাঙ্গগ্রাফ, লামা ইনডেক্স, হেস্ট্যাক, কিউডরান্ট, মিলভাস, উইভিয়েট, ক্রোমা, ওল্লামা, এবং vLLM এর মত ওপেন সোর্স টুলগুলি বাস্তব সিস্টেমের জন্য ব্যবহারিক বিকল্প হয়ে উঠেছে।

এই কারণেই আমি এই বিষয়টি পুনর্বিচার করতে চেয়েছিলাম। এখন প্রশ্ন আর শুধু "আমি কিভাবে RAG তৈরি করব?" নয়। এখন সেটি তৈরি করার অনেক পথ আছে, এবং আরও গুরুত্বপূর্ণ প্রশ্নটি হলো "আমার পরিস্থিতির জন্য কোন আর্কিটেকচারটি নির্বাচন করা উচিত?"

এই সিরিজটি সেই সিদ্ধান্ত গ্রহণ স্তর থেকে শুরু হয়। গভীর বাস্তবায়নের আগে, এটি দেখে কেন AI পরিষেবাগুলিকে আহরণ প্রয়োজন, কখন Azure-ভিত্তিক পরিচালিত পরিষেবা অর্থপূর্ণ, কখন ওপেন সোর্স বিকল্পগুলি ভাল, এবং কোথায় ফাইন-টিউনিং ফিট করে।

> **লোকালি ক্লোন করতে ইচ্ছুক?**
>
> এই রেপোজিটরিতে ৫০টির বেশি ভাষার অনুবাদ রয়েছে যা ডাউনলোড সাইজ অনেক বাড়িয়ে দেয়। অনুবাদ ছাড়া ক্লোন করতে sparse checkout ব্যবহার করুন:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> এটি আপনাকে একটি অনেক দ্রুত ডাউনলোড সহ কোর্স সম্পন্ন করার জন্য প্রয়োজনীয় সবকিছু প্রদান করবে।
