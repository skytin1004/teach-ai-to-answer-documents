# নমুনা ডেটা

নোটবুকগুলি একটি ছোট পাবলিক নমুনা কর্পাস ব্যবহার করে যাতে উদাহরণগুলি ব্যক্তিগত নথি বা ক্লাউড ক্রেডেনশিয়াল ছাড়াই চালানো যায়।

| ফাইল | উদ্দেশ্য |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | একটি স্কুল নীতি নথি যার মধ্যে শেষ অ্যাসাইনমেন্ট, পরীক্ষা, গবেষণা প্রকল্প এবং ইনস্ট্রাক্টর ওভাররাইড সম্পর্কে বিভাগ রয়েছে |
| [course_ai_guidance.md](./course_ai_guidance.md) | একটি কোর্স গাইড নথি যার মধ্যে অনুমোদিত ব্যবহার, প্রকাশ, উক্তি প্রত্যাশা, এবং গ্রুপ ওয়ার্ক সম্পর্কে বিভাগ রয়েছে |

নমুনা নথিগুলি সচেতনভাবে ছোট করা হয়েছে। এগুলি রিটারিভাল, মেটাডেটা, এবং উদ্ধৃতিগুলি সহজে পর্যবেক্ষণ করার জন্য তৈরিকৃত।
