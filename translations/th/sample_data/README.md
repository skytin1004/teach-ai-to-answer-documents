# Sample Data

สมุดบันทึกใช้ตัวอย่างข้อมูลสาธารณะขนาดเล็กเพื่อให้ตัวอย่างสามารถทำงานได้โดยไม่ต้องใช้เอกสารส่วนตัวหรือข้อมูลรับรองบนคลาวด์

| File | Purpose |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | เอกสารนโยบายของโรงเรียนที่มีส่วนเกี่ยวกับงานมอบหมายสุดท้าย, การสอบ, โครงการวิจัย, และการยกเว้นของผู้สอน |
| [course_ai_guidance.md](./course_ai_guidance.md) | เอกสารแนวทางของหลักสูตรที่มีส่วนเกี่ยวกับการใช้งานที่อนุญาต, การเปิดเผย, ความคาดหวังในการอ้างอิง, และงานกลุ่ม |

เอกสารตัวอย่างมีขนาดเล็กโดยเจตนา เพื่อให้ง่ายต่อการตรวจสอบการดึงข้อมูล, ข้อมูลเมตา, และการอ้างอิง
