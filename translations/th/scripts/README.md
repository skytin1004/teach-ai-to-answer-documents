# Scripts

โฟลเดอร์นี้เก็บสคริปต์สำหรับตรวจสอบ repository

## `verify_notebooks.py`

ตรวจสอบลิงก์ Markdown ในเครื่อง, JSON ของโน้ตบุ๊ก, ความสะอาดของเอาต์พุตโน้ตบุ๊ก และรูปแบบความลับที่มีความเสี่ยงสูง:

```powershell
python scripts\verify_notebooks.py
```

รันโน้ตบุ๊กสาธารณะที่ปลอดภัยในเครื่องทั้งหมด:

```powershell
python scripts\verify_notebooks.py --execute
```

เวิร์กโฟลว์ GitHub Actions ใช้สคริปต์เดียวกัน

วัสดุร่างภายใต้ `drafts/` จะถูกข้ามจนกว่าจะพร้อมสำหรับดัชนีสาธารณะ
