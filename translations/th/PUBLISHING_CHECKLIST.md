# รายการตรวจสอบก่อนเผยแพร่

ใช้รายการตรวจสอบนี้ก่อนทำการคอมมิตหรือผลักดันการอัปเดตสู่สาธารณะ

## ความปลอดภัย

- ยืนยันว่าไม่มีการเขียนคีย์ API, โทเค็น, รหัสผ่าน หรือจุดสิ้นสุดส่วนตัวลงในไฟล์ Markdown, สมุดบันทึก, ตัวอย่างข้อมูล หรือสคริปต์
- เก็บข้อมูลรับรองในตัวแปรสภาพแวดล้อมหรือ managed identity ไม่ใช่ในไฟล์ที่คอมมิตแล้ว
- ห้ามคอมมิตไฟล์ `.env` หรือไฟล์ผลลัพธ์สมุดบันทึกที่ถูกดำเนินการแล้ว
- ให้ไฟล์ `.env.example` เป็นเพียงที่ว่างสำหรับแทนที่เท่านั้น

## การตรวจสอบ

รันสคริปต์ตรวจสอบที่เก็บข้อมูล:

```powershell
python scripts\verify_notebooks.py
```

รันการดำเนินการสมุดบันทึกในเครื่องที่ปลอดภัยแบบเต็มก่อนเผยแพร่การเปลี่ยนแปลงการใช้งาน:

```powershell
python scripts\verify_notebooks.py --execute
```

การตรวจสอบที่คาดหวัง:

- ลิงก์ Markdown ในเครื่องผ่าน
- การตรวจสอบ JSON ของสมุดบันทึกผ่าน
- สมุดบันทึกไม่มีการบันทึกผลลัพธ์หรือจำนวนครั้งการดำเนินการ
- การสแกนรูปแบบความเสี่ยงสูงของความลับผ่าน
- สมุดบันทึกสาธารณะดำเนินการในเครื่องได้
- วัสดุร่างภายใต้ `drafts/` ถูกข้ามโดยเจตนา

## การทบทวน

- ยืนยันว่าลิงก์บทความ README ชี้ไปยังไฟล์ที่ตั้งใจไว้
- ยืนยันว่าบทความแต่ละบทมีการนำทางที่เก็บข้อมูลและลิงก์สมุดบันทึกที่เกี่ยวข้อง
- ยืนยันว่าร่างไม่ถูกลิงก์จากดัชนีสาธารณะเว้นแต่จะพร้อมเผยแพร่
- ยืนยันว่าแม่แบบ GitHub issue และ pull request ยังคงตรงกับเวิร์กโฟลว์ของที่เก็บข้อมูล
- ยืนยันว่าผลลัพธ์การตรวจสอบในบทความตรงกับผลลัพธ์สมุดบันทึกล่าสุด
- ยืนยันว่าเวิร์กโฟลว์ GitHub Actions คาดว่าจะทำงานหลัง push
- ยืนยันว่า `CHANGELOG.md` สะท้อนการอัปเดตที่จะเผยแพร่
- ยืนยันว่า `CONTRIBUTING.md` ยังคงตรงกับเวิร์กโฟลว์ของที่เก็บข้อมูล

## Git

- ตรวจสอบ `git status --short --branch`
- ตรวจสอบ `git diff --stat`
- คอมมิตและผลักดันเฉพาะเมื่อพร้อมอย่างชัดเจนเท่านั้น
