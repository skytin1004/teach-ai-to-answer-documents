# บันทึกการเปลี่ยนแปลง

## ยังไม่ปล่อย

ขอบเขตการปล่อยสู่สาธารณะแรกสำหรับ **สอน AI ให้ตอบคำถามตามเอกสารของคุณ**  

### เพิ่มเติม

- บทความชุดที่ 1 เกี่ยวกับการตัดสินใจสถาปัตยกรรม RAG, การแลกเปลี่ยนระหว่าง Azure กับโอเพ่นซอร์ส และตำแหน่งที่เหมาะสมสำหรับการปรับแต่ง
- บทความชุดที่ 2 และโน้ตบุ๊กสำหรับเวิร์กโฟลว์ RAG แบบโอเพ่นซอร์สในเครื่องโดยใช้โหมด Qdrant ท้องถิ่น, การฝัง FastEmbed ท้องถิ่น, การจัดอันดับใหม่แบบน้ำหนักเบา, Ollama และ Phi-4-mini
- รูปแบบบทเรียนทีละขั้นตอนของชุดที่ 2 พร้อมโค้ด Python และบันทึกการตรวจสอบจากโน้ตบุ๊กที่ประมวลผลแล้ว
- เส้นทางการสร้างคำตอบชุดที่ 2 แบบเลือกได้ด้วย Ollama และ Phi-4-mini พร้อมรักษาเส้นทางการดึงข้อมูลที่รองรับ CPU ในเครื่องเป็นค่าเริ่มต้น
- การตรวจสอบ Ollama ท้องถิ่นสำหรับชุดที่ 2 โดยใช้ `phi4-mini:3.8b` บน RTX 3060 Laptop GPU
- ตัวอย่างข้อมูลสำหรับนโยบายโรงเรียนและแนวทาง AI ในคอร์สเรียน
- ไฟล์ความต้องการสำหรับโน้ตบุ๊กสาธารณะและการตรวจสอบระดับรีโพสิตอรี
- สคริปต์ตรวจสอบรีโพสิตอรีสำหรับลิงก์ Markdown ท้องถิ่น และการตรวจสอบ/ประมวลผลโน้ตบุ๊ก
- เวิร์กโฟลว์ GitHub Actions สำหรับการตรวจสอบโน้ตบุ๊ก
- `.env.example` สำหรับการตั้งค่าการสร้าง Ollama ท้องถิ่นเพิ่มเติมโดยไม่ต้องคอมมิตการตั้งค่าท้องถิ่น
- ไฟล์ README ระดับโฟลเดอร์สำหรับบทความ, โน้ตบุ๊ก, ไฟล์ความต้องการ, ตัวอย่างข้อมูล และสคริปต์
- รายการตรวจสอบสำหรับการเผยแพร่เพื่อความปลอดภัยและการตรวจสอบ
- พื้นที่ทำงานร่างสำหรับเนื้อหาของ Azure และการประเมินผลในอนาคต

### ตรวจสอบแล้ว

- ผ่านการตรวจสอบลิงก์ Markdown ท้องถิ่น
- โน้ตบุ๊กชุดที่ 2 ผ่านการตรวจสอบสำเร็จ
- โน้ตบุ๊กชุดที่ 2 ทำงานสำเร็จในสภาพแวดล้อมการตรวจสอบท้องถิ่น
- ไฟล์โน้ตบุ๊กยังคงไม่มีการบันทึกผลลัพธ์หรือจำนวนครั้งการประมวลผล
- ไม่มีความลับจริงถูกคอมมิต
