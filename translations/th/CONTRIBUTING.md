# Contributing

ที่เก็บนี้ถูกจัดเป็นชุดบล็อกและตัวอย่างโน้ตบุ๊กที่สามารถรันได้

## ก่อนเปิด Pull Request

รันสคริปต์ตรวจสอบภายในเครื่อง:

```powershell
python scripts\verify_notebooks.py
```

สำหรับการเปลี่ยนแปลงที่เกี่ยวกับการใช้งานหรือโน้ตบุ๊ก ให้รันการทำงานโน้ตบุ๊กแบบปลอดภัยภายในเครื่อง:

```powershell
python scripts\verify_notebooks.py --execute
```

## แนวทางการใช้โน้ตบุ๊ก

- รักษาให้โน้ตบุ๊กอ่านง่ายและเน้นในบทความที่เกี่ยวข้อง
- หลีกเลี่ยงการคอมมิตเอาต์พุตหรือจำนวนครั้งที่รันโน้ตบุ๊กที่ถูกบันทึกไว้
- ใช้ข้อมูลตัวอย่างขนาดเล็กจาก `sample_data/` เว้นแต่บทความจะต้องการแหล่งข้อมูลภายนอกเฉพาะ
- บันทึกผลการตรวจสอบในบทความที่เกี่ยวข้องเมื่อพฤติกรรมเปลี่ยนแปลง

## ความลับและข้อมูลรับรอง

- อย่าคอมมิตคีย์ API, โทเคน, รหัสผ่าน, จุดเชื่อมต่อส่วนตัว หรือไฟล์ `.env`
- ใช้ `.env.example` สำหรับค่าแทนที่เท่านั้น
- ใช้ตัวแปรสิ่งแวดล้อมสำหรับการทดลอง Ollama บนเครื่องแบบเลือกได้

## เอกสารประกอบ

- รักษาลิงก์นำทางบทความให้ทันสมัย
- อัปเดต `README.md` เมื่อเพิ่มบทความใหม่, โน้ตบุ๊ก, ไฟล์ความต้องการ หรือไฟล์ข้อมูลตัวอย่าง
- อัปเดต `CHANGELOG.md` ก่อนเผยแพร่การอัปเดตที่มองเห็นได้ของที่เก็บ

## การตรวจสอบ

กระบวนการ GitHub Actions จะรัน:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

เนื้อหาร่างภายใต้ `drafts/` จะถูกข้ามในการตรวจสอบของที่เก็บจนกว่าจะพร้อมสำหรับการจัดทำดัชนีสาธารณะ

## ปัญหา

ใช้แม่แบบข้อเสนอแนะบทความสำหรับการแก้ไขบทความ และแม่แบบปัญหาโน้ตบุ๊กสำหรับปัญหาการรันโน้ตบุ๊ก
