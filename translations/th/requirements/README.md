# ความต้องการ

แต่ละบทความการติดตั้งมีไฟล์ความต้องการที่มุ่งเน้นเฉพาะเจาะจง

| ไฟล์ | ใช้โดย |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | โน้ตบุ๊ก RAG โอเพนซอร์ส ซีรีส์ 2 รวมถึงตัวช่วยสร้าง Ollama ที่เป็นทางเลือก |
| [all.txt](../../../requirements/all.txt) | การตรวจสอบระดับรีโพซิทอรีและ CI |

ใช้ไฟล์ที่มุ่งเน้นเมื่อต้องรันโน้ตบุ๊กเดียว ใช้ `all.txt` เมื่อต้องการตรวจสอบรีโพซิทอรีทั้งหมด

`open-source-rag.txt` และ `all.txt` รวม `fastembed` สำหรับฝังข้อมูลในเครื่อง และ `python-dotenv` เพื่อให้ซีรีส์ 2 สามารถเปิดการสร้าง Ollama ได้ตามต้องการจาก `.env` โดยไม่ต้องเปลี่ยนแปลงกระบวนการดึงข้อมูล
