# प्रकाशन चेकलिस्ट

सार्वजनिक अपडेट को कमिट या पुश करने से पहले इस चेकलिस्ट का उपयोग करें।

## सुरक्षा

- पुष्टि करें कि कोई API कुंजियां, टोकन, पासवर्ड, या निजी एंडपॉइंट्स Markdown फ़ाइलों, नोटबुक, नमूना डेटा, या स्क्रिप्ट्स में नहीं लिखे गए हैं।
- क्रेडेंशियल्स को पर्यावरण वेरिएबल्स या प्रबंधित पहचान में रखें, कमिट किए गए फ़ाइलों में नहीं।
- `.env` फ़ाइलें या निष्पादित नोटबुक आउटपुट फ़ाइलें कमिट न करें।
- `.env.example` को केवल प्लेसहोल्डर के रूप में रखें।

## सत्यापन

रिपॉजिटरी सत्यापन स्क्रिप्ट चलाएं:

```powershell
python scripts\verify_notebooks.py
```

प्रकाशन से पहले पूर्ण लोकल-सुरक्षित नोटबुक निष्पादन चलाएं:

```powershell
python scripts\verify_notebooks.py --execute
```

अपेक्षित जांचें:

- लोकल Markdown लिंक पास हों
- नोटबुक JSON वैलिडेशन पास हो
- नोटबुक में सहेजे गए आउटपुट या निष्पादन गणना नहीं हो
- उच्च-जोखिम वाले सीक्रेट पैटर्न स्कैन पास हो
- सार्वजनिक नोटबुक लोकल रूप से निष्पादित हों
- `drafts/` के अंतर्गत ड्राफ्ट सामग्री जानबूझकर छोड़ दी गई हो

## समीक्षा

- पुष्टि करें कि README लेख लिंक इच्छित फ़ाइलों की ओर संकेत करते हैं।
- पुष्टि करें कि प्रत्येक लेख में रिपॉजिटरी नेविगेशन और संबंधित नोटबुक लिंक हैं।
- पुष्टि करें कि ड्राफ्ट सार्वजनिक सूचियों से लिंक नहीं हैं जब तक कि वे प्रकाशित करने के लिए तैयार न हों।
- पुष्टि करें कि GitHub इश्यू और पुल रिक्वेस्ट टेम्प्लेट रिपॉजिटरी वर्कफ़्लो से मेल खाते हैं।
- पुष्टि करें कि लेख में सत्यापन परिणाम नवीनतम नोटबुक आउटपुट से मेल खाते हैं।
- पुष्टि करें कि GitHub Actions वर्कफ़्लो पुश के बाद चलने की उम्मीद है।
- पुष्टि करें कि `CHANGELOG.md` प्रकाशन किए जा रहे अपडेट को दर्शाता है।
- पुष्टि करें कि `CONTRIBUTING.md` अभी भी रिपॉजिटरी वर्कफ़्लो से मेल खाता है।

## Git

- `git status --short --branch` की समीक्षा करें।
- `git diff --stat` की समीक्षा करें।
- केवल तब कमिट और पुश करें जब स्पष्ट रूप से तैयार हों।
