# Scripts

यह फ़ोल्डर रिपॉजिटरी सत्यापन स्क्रिप्ट्स को शामिल करता है।

## `verify_notebooks.py`

स्थानीय Markdown लिंक, नोटबुक JSON, नोटबुक आउटपुट की सफाई, और उच्च जोखिम वाले गुप्त पैटर्न को सत्यापित करता है:

```powershell
python scripts\verify_notebooks.py
```

सभी सार्वजनिक स्थानीय-सुरक्षित नोटबुक्स को निष्पादित करता है:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions वर्कफ़्लो इसी स्क्रिप्ट का उपयोग करता है।

`drafts/` के अंतर्गत ड्राफ्ट सामग्री तब तक छोड़ी जाती है जब तक कि वह सार्वजनिक सूची के लिए तैयार न हो।
