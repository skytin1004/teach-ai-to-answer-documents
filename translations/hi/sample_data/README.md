# नमूना डेटा

नोटबुक्स एक छोटे सार्वजनिक नमूना कॉर्पस का उपयोग करते हैं ताकि उदाहरण बिना निजी दस्तावेज़ों या क्लाउड क्रेडेंशियल्स के चल सकें।

| फ़ाइल | उद्देश्य |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | एक स्कूल नीति दस्तावेज़ जिसमें अंतिम असाइनमेंट, परीक्षा, अनुसंधान परियोजनाओं, और शिक्षक अधिलेखन के बारे में अनुभाग हैं |
| [course_ai_guidance.md](./course_ai_guidance.md) | एक पाठ्यक्रम मार्गदर्शक दस्तावेज़ जिसमें अनुमत उपयोग, खुलासा, उद्धरण अपेक्षाएँ, और समूह कार्य के बारे में अनुभाग हैं |

नमूना दस्तावेज़ जानबूझकर छोटे हैं। उनका उद्देश्य पुनःप्राप्ति, मेटाडेटा, और उद्धरणों को आसानी से निरीक्षण योग्य बनाना है।
