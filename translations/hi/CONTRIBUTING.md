# योगदान

यह रिपॉजिटरी एक ब्लॉग श्रृंखला और चलाने योग्य नोटबुक उदाहरणों के रूप में व्यवस्थित है।

## पुल रिक्वेस्ट खोलने से पहले

स्थानीय सत्यापन स्क्रिप्ट चलाएं:

```powershell
python scripts\verify_notebooks.py
```

इम्प्लीमेंटेशन या नोटबुक परिवर्तनों के लिए, स्थानीय-सुरक्षित नोटबुक निष्पादन चलाएं:

```powershell
python scripts\verify_notebooks.py --execute
```

## नोटबुक दिशा-निर्देश

- नोटबुक को पठनीय और संबंधित लेख पर केंद्रित रखें।
- सहेजे गए नोटबुक आउटपुट या निष्पादन गणनाएं कमिट न करें।
- `sample_data/` से छोटे नमूना डेटा का उपयोग करें जब तक कि लेख को किसी विशिष्ट बाहरी संसाधन की आवश्यकता न हो।
- व्यवहार में बदलाव होने पर संबंधित लेख में सत्यापन परिणाम रिकॉर्ड करें।

## गुप्त जानकारी और प्रमाणपत्र

- API कुंजी, टोकन, पासवर्ड, निजी एंडपॉइंट या `.env` फाइलें कमिट न करें।
- केवल प्लेसहोल्डर मानों के लिए `.env.example` का उपयोग करें।
- वैकल्पिक स्थानीय Ollama प्रयोगों के लिए पर्यावरण चर का उपयोग करें।

## प्रलेखन

- लेख नेविगेशन लिंक को अद्यतित रखें।
- नया लेख, नोटबुक, आवश्यकताएँ फ़ाइल, या नमूना डेटा फ़ाइल जोड़ते समय `README.md` को अपडेट करें।
- एक दृश्य रिपॉजिटरी अपडेट प्रकाशित करने से पहले `CHANGELOG.md` को अपडेट करें।

## सत्यापन

GitHub Actions वर्कफ़्लो दौड़ता है:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` के अंतर्गत प्रारूपित सामग्री को रिपॉजिटरी सत्यापन द्वारा तब तक छोड़ा जाता है जब तक कि वह सार्वजनिक अनुक्रमण के लिए तैयार न हो।

## समस्याएं

लेख सुधारों के लिए लेख प्रतिक्रिया टेम्प्लेट और नोटबुक निष्पादन समस्याओं के लिए नोटबुक समस्या टेम्प्लेट का उपयोग करें।
