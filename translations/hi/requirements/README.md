# आवश्यकताएं

प्रत्येक कार्यान्वयन लेख में एक केंद्रित आवश्यकताएँ फ़ाइल होती है।

| फ़ाइल | उपयोगकर्ता |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | सीरीज 2 ओपन-सोर्स RAG नोटबुक, जिसमें वैकल्पिक ऑल्लामा जनरेशन हेल्पर्स शामिल हैं |
| [all.txt](../../../requirements/all.txt) | रिपोजिटरी-स्तर सत्यापन और CI |

जब एक नोटबुक चलाएं तो केंद्रित फ़ाइल का उपयोग करें। पूरे रिपोजिटरी को मान्य करते समय `all.txt` का उपयोग करें।

`open-source-rag.txt` और `all.txt` में स्थानीय एम्बेडिंग के लिए `fastembed` और `python-dotenv` शामिल हैं ताकि सीरीज 2 `.env` से ऑल्लामा जनरेशन वैकल्पिक रूप से सक्षम कर सके बिना रिट्रीवल पाइपलाइन को बदले।
