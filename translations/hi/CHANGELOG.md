# Changelog

## Unreleased

**Teach AI to Answer Questions Based on Your Documents** के लिए प्रारंभिक सार्वजनिक रिलीज़ स्कोप।

### जोड़ा गया

- RAG आर्किटेक्चर निर्णयों, Azure बनाम open-source ट्रेडऑफ़, और फाइन-ट्यूनिंग कहां फिट होती है, इस पर सीरीज 1 का लेख।
- Qdrant स्थानीय मोड, FastEmbed स्थानीय एम्बेडिंग्स, लाइटवेट री-रैंकिंग, Ollama, और Phi-4-mini का उपयोग करके स्थानीय open-source RAG वर्कफ़्लो के लिए सीरीज 2 का लेख और नोटबुक।
- Python स्निपेट्स और निष्पादित नोटबुक से सत्यापन नोट्स के साथ सीरीज 2 का चरण-दर-चरण एंड-टू-एंड ट्यूटोरियल फॉर्मेट।
- स्थानीय CPU-अनुकूल पुनःप्राप्ति को डिफ़ॉल्ट पथ बनाए रखते हुए Ollama और Phi-4-mini के साथ वैकल्पिक सीरीज 2 उत्तर-जनरेशन पथ।
- RTX 3060 लैपटॉप GPU पर `phi4-mini:3.8b` का उपयोग करके सीरीज 2 के लिए स्थानीय Ollama सत्यापन।
- स्कूल नीति और पाठ्यक्रम AI मार्गदर्शन के लिए नमूना डेटा।
- सार्वजनिक नोटबुक और रिपोजिटरी-स्तरीय सत्यापन के लिए आवश्यकताएँ फ़ाइलें।
- स्थानीय मार्कडाउन लिंक और नोटबुक सत्यापन/निष्पादन के लिए रिपोजिटरी सत्यापन स्क्रिप्ट।
- नोटबुक सत्यापन के लिए GitHub Actions वर्कफ़्लो।
- स्थानीय कॉन्फ़िगरेशन कमिट किए बिना वैकल्पिक स्थानीय Ollama जनरेशन सेटअप के लिए `.env.example`।
- लेख, नोटबुक, आवश्यकताएँ, नमूना डेटा, और स्क्रिप्ट के लिए फ़ोल्डर-स्तरीय README फ़ाइलें।
- सार्वजनिक सुरक्षा और सत्यापन के लिए प्रकाशन चेकलिस्ट।
- भविष्य के Azure और मूल्यांकन सामग्री के लिए ड्राफ्ट वर्कस्पेस।

### सत्यापित

- स्थानीय मार्कडाउन लिंक सत्यापन सफल होता है।
- सीरीज 2 नोटबुक सफलतापूर्वक सत्यापित होता है।
- स्थानीय सत्यापन वातावरण में सीरीज 2 नोटबुक सफलतापूर्वक निष्पादित होता है।
- नोटबुक फ़ाइलें बिना सहेजे गए आउटपुट या निष्पादन गणना के रखी जाती हैं।
- कोई वास्तविक रहस्य कमिट नहीं किया गया है।
