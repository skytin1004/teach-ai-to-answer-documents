# Vaatimukset

Jokaisella toteutusartikkelilla on keskittynyt vaatimus-tiedosto.

| Tiedosto | Käyttöön |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Series 2 avoimen lähdekoodin RAG-muistikirja, mukaan lukien valinnaiset Ollama generointiapurit |
| [all.txt](../../../requirements/all.txt) | Repositorion tason tarkistus ja CI |

Käytä keskittynyttä tiedostoa, kun ajat yhtä muistikirjaa. Käytä `all.txt` validoidessasi koko repositoriota.

`open-source-rag.txt` ja `all.txt` sisältävät `fastembed` paikallisiin upotuksiin ja `python-dotenv` niin, että Series 2 voi valinnaisesti ottaa käyttöön Ollama generoinnin `.env`-tiedostosta ilman, että noutoputkea tarvitsee muuttaa.
