# Esimerkkidata

Muistikirjat käyttävät pientä julkista esimerkkikokoelmaa, jotta esimerkit voivat toimia ilman yksityisiä asiakirjoja tai pilvivaltuutuksia.

| Tiedosto | Tarkoitus |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Koulun politiikkadokumentti, jossa on osiot lopputöistä, kokeista, tutkimusprojekteista ja opettajan poikkeuksista |
| [course_ai_guidance.md](./course_ai_guidance.md) | Kurssin opas, jossa on osiot sallitusta käytöstä, tiedon paljastamisesta, viittausodotuksista ja ryhmätyöstä |

Esimerkkiasiakirjat ovat tahallaan pieniä. Ne on tarkoitettu tekemään haun, metadataan ja viitteisiin tutustumisesta helppoa.
