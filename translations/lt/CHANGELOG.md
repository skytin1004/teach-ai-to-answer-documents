# Pakeitimų žurnalas

## Neišleista

Pradinis viešasis leidimo apimtis **Mokykite DI atsakyti į klausimus pagal jūsų dokumentus**.

### Pridėta

- Serijos 1 straipsnis apie RAG architektūros sprendimus, Azure ir atvirojo kodo privalumus bei trūkumus ir kur tinka smulkus pritaikymas.
- Serijos 2 straipsnis ir užrašų knygelė vietiniam atvirojo kodo RAG darbo srautui naudojant Qdrant vietinį režimą, FastEmbed vietinius įterpimus, lengvą pervertinimą, Ollama ir Phi-4-mini.
- Serijos 2 nuoseklaus peržengimo pabaigos mokymo formatas su Python fragmentais ir vykdymo užrašų patvirtinimo pastabomis.
- Pasirenkama Serijos 2 atsakymų generavimo kryptis su Ollama ir Phi-4-mini, išlaikant vietinį CPU-draugišką gavimą kaip numatytąją kryptį.
- Vietinis Ollama patvirtinimas Serijai 2 naudojant `phi4-mini:3.8b` ant RTX 3060 nešiojamojo kompiuterio GPU.
- Pavyzdiniai duomenys apie mokyklos politiką ir kursų DI gaires.
- Reikalavimų failai viešajai užrašų knygelės ir saugyklos lygio patikrai.
- Saugyklos patikros scenarijus vietiniams Markdown nuorodoms ir užrašų knygelės validavimui/vykdymui.
- GitHub Actions darbo srautas užrašų knygelės patikrai.
- `.env.example` pasirenkamam vietiniam Ollama generavimo nustatymui be vietinės konfigūracijos įsipareigojimo.
- Aplankų lygio README failai straipsniams, užrašų knygelėms, reikalavimams, pavyzdiniams duomenims ir scenarijams.
- Viešo saugumo ir patikros leidimo darbotvarkė.
- Projekto darbo aplinkos juodraštis būsimiems Azure ir vertinimo turiniams.

### Patvirtinta

- Vietinė Markdown nuorodų patikra sėkminga.
- Serijos 2 užrašų knygelė sėkmingai validuota.
- Serijos 2 užrašų knygelė sėkmingai vykdoma vietinėje patikros aplinkoje.
- Užrašų knygelių failai saugomi be išsaugotų rezultatų ar vykdymo skaičių.
- Tikri slaptažodžiai neįsipareigojami.
