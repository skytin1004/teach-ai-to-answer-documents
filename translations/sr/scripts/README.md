# Скрипте

Овај фолдер садржи скрипте за верификацију репозиторијума.

## `verify_notebooks.py`

Валидација локалних Markdown линкова, JSON фајлова бележница, чистоће излаза бележница и образаца високоризичних тајни:

```powershell
python scripts\verify_notebooks.py
```

Извршава све јавне локално-безбедне бележнице:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions радни ток користи исти скрипт.

Нацртни материјал у `drafts/` је прескочен док не буде спреман за јавни индекс.
