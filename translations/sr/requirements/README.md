# Захтеви

Сваки чланак о имплементацији има фокусиран фајл са захтевима.

| Фајл | Користе га |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Series 2 open-source RAG нотебоок, укључујући опционе помоћнике за генерисање Ollama |
| [all.txt](../../../requirements/all.txt) | Верификација на нивоу репозиторијума и CI |

Користите фокусиран фајл када покрећете један нотебоок. Користите `all.txt` када верификујете цео репозиторијум.

`open-source-rag.txt` и `all.txt` укључују `fastembed` за локалне ембедингс и `python-dotenv` тако да Series 2 може опционално да омогући Ollama генерисање из `.env` без промене процеса извлачења.
