# Подучите вештачку интелигенцију да одговара на питања на основу ваших докумената

![Документ-основани AI RAG систем преглед](../../assets/images/readme-hero.svg)

Овај репозиторијум обухвата серију блогова за 2026. годину о изградњи AI система заснованих на документима коришћењем RAG-а, Azure AI услуга, опен-сорс алтернатива и токова рада оријентисаних на евалуацију.

## Позадина

У 2023, радио сам на пару туторијала о томе како научити ChatGPT да одговара на питања из PDF докумената користећи Azure AI Search и Azure OpenAI. Идеја „ChatGPT на вашим подацима“ тада је још увек деловала ново, а циљ је био да се покаже практичан ток рада: складиштити документе, индексирати их, вратити релевантни садржај и генерисати одговоре из тог враћеног контекста.

Године 2026, RAG екосистем је много већи. Azure AI Search подржава модерне векторске и хибридне обрасце проналаска, Azure OpenAI је део ширег Microsoft Foundry Models екосистема, а опен-сорс алати као што су LangGraph, LlamaIndex, Haystack, Qdrant, Milvus, Weaviate, Chroma, Ollама и vLLM постали су практични избори за стварне системе.

Због тога сам желео да поново обрадим ову тему. Питање више није само „Како да направим RAG?“ Сада постоји много начина за израду, а важније питање гласи: „Коју архитектуру да изаберем за своју ситуацију?“

Ова серија почиње од тог слоја доношења одлука, а затим га претвара у практичне туторијале. Први пут имплементације гради локални опен-сорс RAG систем који свако може покренути са примером података, Qdrант-ом, Олламом и Phi-4-mini.

## Локална Оллама генерација

Бележница Серије 2 је подразумевано локално безбедна. Да бисте омогућили локалну Оллама генерацију, копирајте [.env.example](../../.env.example) у `.env` и попуните вредности за Серију 2.

За Оллама генерацију Серије 2, уклоните коментар:

```text
SERIES2_OLLAMA_BASE_URL=http://localhost:11434
SERIES2_OLLAMA_MODEL=phi4-mini:3.8b
```

Бележница Серије 2 аутоматски учитава `.env` из корена репозиторијума користећи `python-dotenv`.

> [!IMPORTANT]
> Немојте комитовати `.env` фајлове, API кључеве, приватне крајње тачке или вредности специфичне за закупца. Репозиторијум намерно држи тајне ван Markdown фајлова и бележница.

Фајлови са захтевима су документовани у [requirements/README.md](./requirements/README.md).

За валидацију линкова, структуре бележница, чистоће излаза бележница и образаца високоризичних тајних података:

```powershell
python -m venv .venv-verify
.\.venv-verify\Scripts\activate
python -m pip install -r requirements\all.txt
python scripts\verify_notebooks.py
```

Скрипте за верификацију су документоване у [scripts/README.md](./scripts/README.md).

Да бисте извршили све локално безбедне бележнице у истом окружењу:

```powershell
python scripts\verify_notebooks.py --execute
```

Исти ток верификације се покреће у GitHub Actions на пушевима, захтевима за повлачење и ручним покретањима радних токова. Нацрти чланака и бележница су намерно изузети из јавног пута верификације.

Погледајте [CHANGELOG.md](./CHANGELOG.md) за тренутни неријачени преглед промена.
