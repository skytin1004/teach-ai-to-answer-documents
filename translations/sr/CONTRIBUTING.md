# Допринoси

Овај репозиторijум је организован као сериjа блог постова плус извршиви примери у свескама.

## Пре отварања Pull Request-а

Покрените локални скрипт за валидациjу:

```powershell
python scripts\verify_notebooks.py
```

За промене у имплементациjи или свескама, покрените локалну безбедну извршну свеску:

```powershell
python scripts\verify_notebooks.py --execute
```

## смернице за свеске

- Одржаваjте свеске читљивим и фокусираним на повезани чланак.
- Не додаjте сакривене излазне податке или бројачe извршења у комит.
- Користите мале примерке података из `sample_data/` осим ако чланак не захтева одређени спољни ресурс.
- Записуjте резултате верификациjе у повезаном чланку када се понашање промени.

## Тајне и акредитиви

- Не додаjте у комит API кључеве, токене, лозинке, приватне крајње тачке или `.env` фајлове.
- Користите `.env.example` само за вредности замене.
- Користите променљиве окружења за опционе локалне Ollama експерименте.

## Документациjа

- Одржаваjте линкове за навигациjу чланака ажурним.
- Ажурираjте `README.md` када додате нови чланак, свеску, фајл са зависностима или пример података.
- Ажурираjте `CHANGELOG.md` пре објављивања видљивог ажурирања репозиторијума.

## Верификациjа

GitHub Actions workflow покреће:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

Нацрти материjала у `drafts/` се не провераваjу у репозиториjуму док не буду спремни за јавно индексирање.

## Питања

Користите шаблон за повратну информатиjу о чланцима за исправке чланака и шаблон проблема са свескама за проблеме приликом извршавања свеске.
