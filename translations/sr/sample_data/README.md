| Фајл | Сврха |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Документ школске политике са одељцима о завршним задацима, испитима, истраживачким пројектима и надјачавањима инструктора |
| [course_ai_guidance.md](./course_ai_guidance.md) | Документ водича за курс са одељцима о дозвољеним употребама, откривању, очекивањима цитата и групном раду |

Пример докумената је намерно мали. Они су намењени да олакшају преглед преузимања, метаподатака и цитата.
