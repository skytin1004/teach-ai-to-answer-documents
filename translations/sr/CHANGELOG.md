# Историја измена

## Нерелизовано

Почетни опсег јавног издања за **Научити вештачку интелигенцију да одговара на питања на основу ваших докумената**.

### Додато

- Чланак из серије 1 о одлукама архитектуре RAG, компромисима између Azure и отвореног кода и где се уклапа фино подешавање.
- Чланак из серије 2 и бележница за локални радни ток RAG отвореног кода користећи Qdrant локални режим, FastEmbed локалне уграђености, лагано преуредање, Ollama и Phi-4-mini.
- Чланак из серије 2 у корацима крај-до-краја у облику упутства са Python фрагментима и нотама провере из извршене бележнице.
- Опциони пут за генерисање одговора из серије 2 са Ollama и Phi-4-mini уз задржавање локалног CPU-пријатељског преузимања као подразумеваног пута.
- Локална верификација Ollama за серију 2 користећи `phi4-mini:3.8b` на RTX 3060 Laptop GPU.
- Пример података за школску политику и AI смернице курса.
- Фајлови са захтевима за јавну бележницу и валидацију на нивоу репозиторијума.
- Скрипта за проверу репозиторијума за локалне Markdown линкове и валидацију/извршавање бележнице.
- GitHub Actions радни ток за проверу бележнице.
- `.env.example` за опционално локално подешавање генерисања Ollama без комитовања локалне конфигурације.
- README фајлови на нивоу фасцикле за чланке, бележнице, захтеве, пример података и скрипте.
- Контролна листа за објављивање ради јавне безбедности и верификације.
- Нацрт радног простора за будуће Azure и евалуационе садржаје.

### Потврђено

- Локална валидација Markdown линкова пролази.
- Бележница из серије 2 успешно се верификује.
- Бележница из серије 2 успешно се извршава у локалном окружењу за проверу.
- Фајлови бележнице се чувају без сачуваних излаза или бројева извршавања.
- Ниједна стварна тајна није комитована.
