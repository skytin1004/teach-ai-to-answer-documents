# Eksempelddata

Notatbøkene bruker en liten offentlig eksempelkorpus slik at eksemplene kan kjøres uten private dokumenter eller sky-legitimasjon.

| Fil | Formål |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Et skolepolicy-dokument med seksjoner om avsluttende oppgaver, eksamener, forskningsprosjekter og instruktøroverskridelser |
| [course_ai_guidance.md](./course_ai_guidance.md) | Et kursveiledningsdokument med seksjoner om tillatt bruk, avsløringer, siteringsforventninger og gruppearbeid |

Eksempeldokumentene er bevisst små. De er ment å gjøre henting, metadata og siteringer lette å inspisere.
