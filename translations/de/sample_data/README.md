# Beispieldaten

Die Notebooks verwenden einen kleinen, öffentlichen Beispielkorpus, damit die Beispiele ohne private Dokumente oder Cloud-Zugangsdaten ausgeführt werden können.

| Datei | Zweck |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Ein Schulrichtliniendokument mit Abschnitten über Abschlussarbeiten, Prüfungen, Forschungsprojekte und Ausnahmen durch Lehrkräfte |
