# Contributing

ਇਹ ਰਿਪੋਜ਼ਟਰੀ ਇੱਕ ਬਲੌਗ ਸੀਰੀਜ਼ ਨਾਲ ਨਾਲ ਚਲਾਉਣਯੋਗ ਨੋਟਬੁੱਕ ਉਦਾਹਰਨਾਂ ਵਜੋਂ ਸੰਚਾਲਿਤ ਕੀਤੀ ਗਈ ਹੈ।

## Before Opening a Pull Request

ਲੋਕਲ ਵੇਰੀਫਿਕੇਸ਼ਨ ਸਕ੍ਰਿਪਟ ਚਲਾਓ:

```powershell
python scripts\verify_notebooks.py
```

ਲਾਗੂ ਕਰਨ ਜਾਂ ਨੋਟਬੁੱਕ ਬਦਲਾਅ ਲਈ, ਲੋਕਲ-ਸੇਫ਼ ਨੋਟਬੁੱਕ ਚਲਾਉਣਾ ਚਲਾਓ:

```powershell
python scripts\verify_notebooks.py --execute
```

## ਨੋਟਬੁੱਕ ਗਾਈਡਲਾਈਨਜ਼

- ਨੋਟਬੁੱਕਾਂ ਨੂੰ ਪੜ੍ਹਨਯੋਗ ਅਤੇ ਸੰਬੰਧਿਤ ਲੇਖ 'ਤੇ ਕੇਂਦ੍ਰਿਤ ਰੱਖੋ।
- ਸੇਵ ਕੀਤੇ ਨੋਟਬੁੱਕ ਨਤੀਜੇ ਜਾਂ ਚਲਾਉਣ ਗਿਣਤੀ ਸਦੱਸ ਨਾ ਕਰੋ।
- ਸਿਰਫ `sample_data/` ਵਿੱਚੋਂ ਛੋਟੇ ਸੈਂਪਲ ਡੇਟਾ ਦੀ ਵਰਤੋਂ ਕਰੋ ਜਦੋਂ ਤੱਕ ਲੇਖ ਲਈ ਕਿਸੇ ਵਿਸ਼ੇਸ਼ ਬਾਹਰੀ ਸਰੋਤ ਦੀ ਲੋੜ ਨਾਹ ਹੋਵੇ।
- ਜਦੋਂ ਵਿਹਾਰ ਵਿੱਚ ਬਦਲਾਅ ਹੋਵੇ, ਸੰਬੰਧਿਤ ਲੇਖ ਵਿੱਚ ਪ੍ਰਮਾਣਿਕਤਾ ਦੇ ਨਤੀਜੇ ਦਰਜ ਕਰੋ।

## ਰਾਜ਼ ਅਤੇ ਪ੍ਰਮਾਣ ਪੱਤਰ

- API ਕੀ, ਟੋਕਨ, ਪਾਸਵਰਡ, ਨਿੱਜੀ ਐਂਡਪੌਇੰਟ ਜਾਂ `.env` ਫਾਇਲਾਂ ਸਦੱਸ ਨਾ ਕਰੋ।
- ਸਿਰਫ `.env.example` ਵਿੱਚ ਪਲੇਸਹੋਲਡਰ ਮੁੱਲਾਂ ਲਈ ਵਰਤੋਂ ਕਰੋ।
- ਵਿਕਲਪੀ ਸਥਾਨਕ ਓਲਾਮਾ ਪ੍ਰਯੋਗਾਂ ਲਈ ਵਾਤਾਵਰਣ ਵੈਰੀਏਬਲ ਦੀ ਵਰਤੋਂ ਕਰੋ।

## ਦਸਤਾਵੇਜ਼ੀकरण

- ਲੇਖ ਨੈਵੀਗੇਸ਼ਨ ਲਿੰਕਾਂ ਨੂੰ ਅਪ-ਟੂ-ਡੇਟ ਰੱਖੋ।
- ਨਵਾਂ ਲੇਖ, ਨੋਟਬੁੱਕ, ਲੋੜੀਂਦੇ ਫਾਇਲ ਜਾਂ ਸੈਂਪਲ ਡੇਟਾ ਫਾਇਲ ਸ਼ਾਮਿਲ ਕਰਨ ਵੇਲੇ `README.md` ਨੂੰ ਅਪਡੇਟ ਕਰੋ।
- ਸਰਵਜਨਿਕ ਰਿਪੋਜ਼ਟਰੀ ਅਪਡੇਟ ਜਾਰੀ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ `CHANGELOG.md` ਨੂੰ ਅਪਡੇਟ ਕਰੋ।

## ਪ੍ਰਮਾਣਿਕਤਾ

GitHub ਐਕਸ਼ਨ ਵਰਕਫ਼ਲੋ ਚਲਦਾ ਹੈ:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` ਹੇਠਾਂ ਖਾਕੇ ਸਮੱਗਰੀ ਰਿਪੋਜ਼ਟਰੀ ਪ੍ਰਮਾਣਿਕਤਾ ਵੱਲੋਂ ਛੱਡ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ ਜਦ ਤੱਕ ਇਹ ਸਰਵਜਨਿਕ ਇੰਡੈਕਸਿੰਗ ਲਈ ਤਿਆਰ ਨਾ ਹੋਵੇ।

## ਮੁੱਦੇ

ਲੇਖ ਸੰਸ਼ੋਧਨਾਂ ਲਈ ਲੇਖ ਫੀਡਬੈਕ ਟੈਮਪਲੇਟ ਅਤੇ ਨੋਟਬੁੱਕ ਚਲਾਉਣ ਸਮੱਸਿਆਵਾਂ ਲਈ ਨੋਟਬੁੱਕ ਮੁੱਦਾ ਟੈਮਪਲੇਟ ਦੀ ਵਰਤੋਂ ਕਰੋ।
