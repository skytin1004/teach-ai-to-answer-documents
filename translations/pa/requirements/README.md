# Requirements

Each implementation article has a focused requirements file.

| File | Used by |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | ਸੀਰੀਜ਼ 2 ਓਪਨ-ਸੋਰਸ RAG ਨੋਟਬੁੱਕ, ਜਿਸ ਵਿੱਚ ਵਿਕਲਪਿਕ ਓਲਾਮਾ ਜਨਰੇਸ਼ਨ ਸਹਾਇਕ ਸ਼ਾਮਲ ਹਨ |
| [all.txt](../../../requirements/all.txt) | ਰਿਪੋਜ਼ਟਰੀ-ਸਤਰ ਦੀ ਪੁਸ਼ਟੀ ਅਤੇ CI |

ਜਦੋਂ ਇੱਕ ਨੋਟਬੁੱਕ ਚਲਾਉਣਾ ਹੋਵੇ ਤਾਂ ਫੋਕਸ ਕੀਤਾ ਫ਼ਾਈਲ ਵਰਤੋਂ ਕਰੋ। ਪੂਰੇ ਰਿਪੋਜ਼ਟਰੀ ਨੂੰ ਮਾਨਯਤਾ ਦੇਣ ਲਈ `all.txt` ਵਰਤੋਂ।

`open-source-rag.txt` ਅਤੇ `all.txt` ਵਿੱਚ ਸਥਾਨਕ ਐਮਬੈਡਿੰਗ ਲਈ `fastembed` ਅਤੇ `.env` ਤੋਂ ਵਿਕਲਪਿਕ ਓਲਾਮਾ ਜਨਰੇਸ਼ਨ ਨੂੰ ਸੰਭਾਵਿਤ ਬਣਾਉਣ ਲਈ `python-dotenv` ਸ਼ਾਮਲ ਹਨ, ਤਾਂ ਜੋ ਸੀਰੀਜ਼ 2 ਰਿਟਰੀਵਲ ਪਾਈਪਲਾਈਨ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਇਸ ਨੂੰ ਯੋਗ ਕਰ ਸਕੇ।
