# ਪ੍ਰਕਾਸ਼ਨ ਚੈੱਕਲਿਸਟ

ਸਰਵਜਨਿਕ ਅੱਪਡੇਟਾਂ ਨੂੰ ਕਮੀਟ ਜਾਂ ਪੁਸ਼ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇਸ ਚੈੱਕਲਿਸਟ ਦੀ ਵਰਤੋਂ ਕਰੋ।

## ਸੁਰੱਖਿਆ

- ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕੋਈ API ਕੁੰਜੀਆਂ, ਟੋਕਨ, ਪਾਸਵਰਡ, ਜਾਂ ਨਿੱਜੀ ਐਂਡਪੋਇੰਟ ਮਾਰਕਡਾਊਨ ਫਾਇਲਾਂ, ਨોટਬੁੱਕ, ਨਮੂਨਾ ਡੇਟਾ, ਜਾਂ ਸਕ੍ਰਿਪਟਾਂ ਵਿੱਚ ਲਿਖੇ ਨਾ ਹਨ।
- ਪ੍ਰਮਾਣਿਕਤਾ ਨੂੰ ਵਾਤਾਵਰਣ ਚਲ ਹੋਣ ਵੈਰੀਏਬਲ ਜਾਂ ਪ੍ਰਬੰਧਤ ਪਹਚਾਣ ਵਿੱਚ ਰੱਖੋ, ਨ ਕਿCommitted ਫਾਇਲਾਂ ਵਿੱਚ।
- `.env` ਫਾਇਲਾਂ ਜਾਂ ਚਲਾਈਆਂ ਨੋਟਬੁੱਕ ਆਉਟਪੁੱਟ ਫਾਇਲਾਂ ਨੂੰ ਕਮੀਟ ਨਾ ਕਰੋ।
- `.env.example` ਸਿਰਫ ਪਲੇਸਹੋਲਡਰ ਲਈ ਰੱਖੋ।

## ਤਸਦੀਕ

Repository ਤਸਦੀਕ ਸਕ੍ਰਿਪਟ ਚਲਾਓ:

```powershell
python scripts\verify_notebooks.py
```

ਪ੍ਰਕਾਸ਼ਨ ਤੋਂ ਪਹਿਲਾਂ ਪੂਰਾ ਲੋਕਲ-ਸੁਰੱਖਿਅਤ ਨੋਟਬੁੱਕ ਐਗਜ਼ੀਕਿਊਸ਼ਨ ਚਲਾਓ:

```powershell
python scripts\verify_notebooks.py --execute
```

ਉਮੀਦ ਕੀਤੀਆਂ ਚੈਕਸ:

- ਲੋਕਲ ਮਾਰਕਡਾਊਨ ਲਿੰਕ ਸਫਲ ਹਨ
- ਨੋਟਬੁੱਕ JSON ਵੈਧਤਾ ਸਫਲ ਹੈ
- ਨੋਟਬੁਕਾਂ ਵਿੱਚ ਸੰਭਾਲੇ ਗਏ ਆਉਟਪੁੱਟ ਜਾਂ ਐਗਜ਼ੀਕਿਊਸ਼ਨ ਗਿਣਤੀ ਨਹੀਂ ਹਨ
- ਉੱਚ-ਖ਼ਤਰੇ ਵਾਲੇ ਸీక੍ਰਿਟ ਪੈਟਰਨ ਸਕੈਨ ਸਫਲ ਹੈ
- ਸਰਵਜਨਿਕ ਨੋਟਬੁਕ ਲੋਕਲ ਭਾਤਰ ਚਲਦੇ ਹਨ
- `drafts/` ਹੇਠਾਂ ਡਰਾਫਟ ਸਮੱਗਰੀ ਇਰਾਦੇ ਨਾਲ ਛੱਡ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ

## ਸਮੀਖਿਆ

- ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ README ਲੇਖ ਲਿੰਕ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਫਾਇਲਾਂ ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦੇ ਹਨ।
- ਇਹ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਹਰ ਲੇਖ ਵਿੱਚ ਰੈਪੋਜ਼ਿਟਰੀ ਨੈਵੀਗੇਸ਼ਨ ਅਤੇ ਸਬੰਧਤ ਨੋਟਬੁੱਕ ਲਿੰਕ ਹਨ।
- ਇਹ ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਡਰਾਫਟ ਜਨਤਕ ਇੰਡੈਕਸਾਂ ਤੋਂ ਲਿੰਕ ਨਹੀਂ ਕੀਤੇ ਗਏ ਜਦ ਤੱਕ ਉਹ ਪ੍ਰਕਾਸ਼ਨ ਲਈ ਤਿਆਰ ਨਾ ਹੋਣ।
- GitHub ਇਸ਼ੂ ਅਤੇ ਪੁਲ ਰਿਕੁਐਸਟ ਟੈਂਪਲੇਟ ਹਾਲੇ ਵੀ ਰੈਪੋਜ਼ਿਟਰੀ ਵਰਕਫ਼ਲੋ ਨਾਲ ਮਿਲਦੇ ਹਨ, ਇਹ ਪੱਕਾ ਕਰੋ।
- ਲੇਖ ਵਿੱਚ ਤਸਦੀਕ ਨਤੀਜੇ ਆਖਰੀ ਨੋਟਬੁੱਕ ਆਉਟਪੁੱਟ ਨਾਲ ਮੇਲ ਖਾਂਦੇ ਹਨ, ਇਹ ਚੈੱਕ ਕਰੋ।
- GitHub Actions ਵਰਕਫਲੋ ਪੁਸ਼ ਤੋਂ ਬਾਅਦ ਚਲਾਉਂਦਾ ਹੈ, ਇਹ ਪੁਸ਼ਟੀ ਕਰੋ।
- `CHANGELOG.md` ਅਪਡੇਟ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ ਜੋ ਪ੍ਰਕਾਸ਼ਿਤ ਕੀਤਾ ਜਾ ਰਿਹਾ ਹੈ, ਇਹ ਚੈੱਕ ਕਰੋ।
- `CONTRIBUTING.md` ਹਾਲੇ ਵੀ ਰੈਪੋਜ਼ਿਟਰੀ ਵਰਕਫਲੋ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ, ਇਹ ਪੁਸ਼ਟੀ ਕਰੋ।
