# ਆਪਣੇ ਦਸਤਾਵੇਜ਼ਾਂ ਦੇ ਆਧਾਰ 'ਤੇ ਪ੍ਰਸ਼ਨਾਂ ਦੇ ਜਵਾਬ ਦੇਣ ਲਈ AI ਸਿਖਾਓ - ਸੀਰੀਜ਼ ਯੋਜਨਾ

ਇਹ ਯੋਜਨਾ ਲੋਕਪ੍ਰിയ ਸੀਰੀਜ਼ 1 ਅਤੇ ਸੀਰੀਜ਼ 2 ਰਿਲੀਜ਼ ਦੇ ਟਰੈਕ ਨੂੰ ਰੱਖਦੀ ਹੈ। ਬਾਅਦ ਵਿੱਚ Azure ਅਤੇ ਮੁੱਲਾਂਕਣ ਦਾ ਕੰਮ ਖਾਕੇ ਵਜੋਂ ਰੱਖਿਆ ਜਾ ਰਿਹਾ ਹੈ ਜਦ ਤੱਕ ਉਦਾਹਰਨਾਂ ਪੂਰੀ ਤਰ੍ਹਾਂ ਅੰਟ-ਟੂ-ਅੰਟ ਅਤੇ ਜाँचਿਆ ਨਾ ਜਾਵੇ।

ਸਾਫ ਸੂਚਨਾ ਦੇ ਬਿਨਾਂ ਬਦਲਾਅ ਨਾ ਕਰਨ ਜਾਂ ਪੁਸ਼ ਨਾ ਕਰਨ।

## ਲੋਕਪ੍ਰਿਯ ਖੇਤਰ

ਮੌਜੂਦਾ ਲੋਕਪ੍ਰਿਯ ਰਿਲੀਜ਼:

- ਸੀਰੀਜ਼ 1 ਲੇਖ: RAG ਆਰਕੀਟੈਕਚਰ ਫੈਸਲੇ, Azure ਬਨਾਮ ਓਪਨ-ਸੋਰਸ ਟਰੇਡਆਫ਼, ਅਤੇ ਕਿੱਥੇ ਫਾਈਨ-ਟਿੂਨਿੰਗ ਫਿੱਟ ਹੁੰਦੀ ਹੈ।
- ਸੀਰੀਜ਼ 2 ਲੇਖ: ਸਥਾਨਕ ਓਪਨ-ਸੋਰਸ RAG ਟਿਊਟੋਰਿਅਲ।
- ਸੀਰੀਜ਼ 2 ਨੋਟਬੁੱਕ: FastEmbed, Qdrant, Ollama, ਅਤੇ Phi-4-mini ਦੇ ਨਾਲ ਚਲਾਉਣ ਯੋਗ ਸਥਾਨਕ RAG ਲੈਬ।
- ਨਮੂਨਾ ਡਾਟਾ: ਸਕੂਲ ਨੀਤੀ ਅਤੇ ਕੋਰਸ AI ਮਾਰਗਦਰਸ਼ਨ Markdown ਫਾਇਲਾਂ।

ਖਾਕੇ ਵਜੋਂ ਬਣਾਏ ਗਏ ਪਰ ਅਜੇ ਤਕ ਲੋਕਪ੍ਰਿਯ ਸੂਚੀ ਵਿੱਚ ਨਹੀਂ:

- Azure AI Search ਅਤੇ Azure OpenAI ਨਵੀਂ ਬਣਤਰ।
- RAG ਮੁੱਲਾਂਕਣ ਅਤੇ ਰਿਗ੍ਰੈਸ਼ਨ ਜਾਂਚਾਂ।

## ਟਿਊਟੋਰਿਅਲ ਪਹਿਰਾਵਾ

ਸਾਂਝੇ ਪਹਿਰਾਵੇ ਇੱਕ ਸਕੂਲ ਨੀਤੀ ਸਹਾਇਕ ਹਨ।

ਸਹਾਇਕ ਇਸ ਸਵਾਲ ਦਾ ਜਵਾਬ ਸਥਾਨਕ ਦਸਤਾਵੇਜ਼ਾਂ ਤੋਂ ਦਿੰਦਾ ਹੈ:

```text
Can I use generative AI for my final assignment?
```
  
ਉਮੀਦ ਕੀਤੀ ਗਈ ਵਰਤੋਂ ਇਹ ਹੈ:

1. ਸਥਾਨਕ Markdown ਦਸਤਾਵੇਜ਼ ਲੋਡ ਕਰੋ।  
2. ਮਹਿਰਾਬਾਂ ਦੇ ਅਨੁਸਾਰ ਉਹਨਾਂ ਨੂੰ ਪਾਰਸ ਅਤੇ ਚੰਕ ਕਰੋ।  
3. ਸਥਾਨਕ ਇੰਬੈਡਿੰਗ ਬਣਾਓ ਅਤੇ ਮੈਟਾਡੇਟਾ ਦੇ ਨਾਲ ਖੋਜਯੋਗ ਪ੍ਰਤੀਨਿਧਤਾਵਾਂ ਸਟੋਰ ਕਰੋ।  
4. ਸਬੰਧਤ ਨੀਤੀ ਭਾਗ ਪ੍ਰਾਪਤ ਕਰੋ।  
5. ਜਰੂਰਤ ਪੈਂਦੇ ਸਮੇਂ ਫਿਰ ਤੋਂ ਰੈਂਕ ਕਰੋ।  
6. ਜਰੂਰੀ ਜਵਾਬ ਬਣਾਓ ਜਾਂ ਰਚਨਾ ਕਰੋ।  
7. ਹਵਾਲੇ ਵਾਪਸ ਕਰੋ।  
8. ਪੁਸ਼ਟੀ ਪ੍ਰਣਾਲੀਆਂ ਦਾ ਰਿਕਾਰਡ ਰੱਖੋ।

## ਸੀਰੀਜ਼ 2 ਪੁਸ਼ਟੀ

Windows ਤੇ Python 3.12.6 ਨਾਲ ਪੁਸ਼ਟੀ ਕੀਤੀ।

- `requirements/open-source-rag.txt` ਸਫਲਤਾਪੂਰਵਕ ਇੰਸਟਾਲ ਕੀਤਾ।  
- `notebooks/series-2-open-source-rag.ipynb` ਨੂੰ `nbclient` ਨਾਲ ਚਲਾਇਆ।  
- ਸਥਾਨਕ ਪੁਸ਼ਟੀ ਸਫਲ: 2 ਨਮੂਨਾ ਦਸਤਾਵੇਜ਼ ਲੋਡ ਕੀਤੇ, 8 ਚੰਕ ਬਣਾਏ, FastEmbed ਨੇ 384-ਆਕਾਰ ਦੇ ਸਥਾਨਕ ਇੰਬੈਡਿੰਗ ਬਣਾਏ, Qdrant ਇਨ-ਮੈਮੋਰੀ ਕਲੈਕਸ਼ਨ ਸ਼ੁਰੂ ਕੀਤੀ, ਅਤੇ 8 ਵੇਕਟਰ ਸ਼ਾਮਲ ਕੀਤੇ।  
- ਟੈਸਟ ਪ੍ਰਸ਼ਨ: "ਕੀ ਮੈਂ ਆਪਣੇ ਅੰਤਿਮ ਕੰਮ ਲਈ ਜੈਨਰੇਟਿਵ AI ਵਰਤ ਸਕਦਾ ਹਾਂ?"  
- ਹਲਕਾ ਰੈਂਕਿੰਗ ਤੋਂ ਬਾਅਦ ਚੁਣਿਆ ਗਿਆ ਸਰਵਚ ਸ੍ਰੋਤ: `school_ai_policy.md`।  
- ਹਲਕਾ ਰੈਂਕਿੰਗ ਤੋਂ ਬਾਅਦ ਚੁਣਿਆ ਗਿਆ ਸੈਕਸ਼ਨ: `Final Assignments`।  
- ਡਿਫਾਲਟ ਜਵਾਬ ਮਾਰਗ: ਸਥਾਨਕ ਟ੍ਰਾਂਸਪਰੈਂਟ ਅੰਸਰ ਕੰਪੋਜ਼ਰ।  
- Ollama ਨੂੰ winget ਰਾਹੀਂ ਇੰਸਟਾਲ ਕੀਤਾ; `phi4-mini:3.8b` ਸਫਲਤਾਪੂਰਵਕ ਡਾਊਨਲੋਡ ਕੀਤਾ।  
- Ollama ਦੇ ਜਵਾਬ-ਤੁਲਨਾਤਮਕ ਮਾਰਗ: `phi4-mini:3.8b` ਨਾਲ ਪੂਰਾ ਕੀਤਾ।  
- Ollama ਮਾਡਲ ਫਾਇਲ ਦਾ ਆਕਾਰ: ਡਿਸਕ ਤੇ ਲਗਭਗ 2.49GB।  
- Ollama ਲੋਡ ਕੀਤਾ ਮਾਡਲ ਆਕਾਰ: `ollama ps` ਦੁਆਰਾ 3.3GB ਦਰਜ ਕੀਤਾ।  
- GPU ਅਫਲੋਡ: RTX 3060 ਲੈਪਟਾਪ GPU ਤੇ `ollama ps` ਦੁਆਰਾ 100% GPU ਦਰਸਾਇਆ।  
- ਜਨਰੇਸ਼ਨ ਤੋਂ ਬਾਅਦ GPU ਮੈਮੋਰੀ ਦੇਖੀ ਗਈ: ਲਗਭਗ 3.5GB ਤੋਂ 6GB।  
- ਕੇਸ਼ਡ FastEmbed ਮਾਡਲ ਅਤੇ Ollama ਜਨਰੇਸ਼ਨ ਨਾਲ ਨੋਟਬੁੱਕ ਚਲਾਉਣਾ ਔਰ ਟੈਸਟ ਲਗਭਗ 34 ਸਕਿੰਟਾਂ ਵਿੱਚ ਪੁਸ਼ਟੀ ਸਕ੍ਰਿਪਟ ਰਾਹੀਂ ਪਾਰ ਕਰ ਲਿਆ।  
- ਨਿਰੀਖਣ: ਇੱਕ ਪਹਿਲਾ ਦਸਤਾਵੇਜ਼ ਲੋਡਿੰਗ ਦੌਰਾਨ ਗਲਤੀ ਨਾਲ `sample_data/README.md` ਸ਼ਾਮਲ ਹੋ ਗਿਆ ਸੀ; ਨੋਟਬੁੱਕ ਹੁਣ ਸਪਸ਼ਟ ਤੌਰ ਤੇ ਸਿਰਫ ਦੋ ਨਿਰਧਾਰਿਤ ਨਮੂਨਾ ਦਸਤਾਵੇਜ਼ ਲੋਡ ਕਰਦਾ ਹੈ।  

## ਰਿਪੋਜਿਟਰੀ ਪੁਸ਼ਟੀ

- `scripts/verify_notebooks.py` ਸਥਾਨਕ Markdown ਲਿੰਕ, ਨੋਟਬੁੱਕ JSON, ਨੋਟਬੁੱਕ ਆਉਟਪੁੱਟ ਸਾਫ਼-ਸੁਥਰਾ, ਅਤੇ ਉੱਚ-ਖਤਰੇ ਵਾਲੇ ਗੁਪਤ ਪੈਟਰਨਾਂ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ।  
- `scripts/verify_notebooks.py --execute` ਰਿਪੋਜਿਟਰੀ ਰੂਟ ਤੋਂ ਲੋਕਪ੍ਰਿਯ ਨੋਟਬੁੱਕ ਚਲਾਉਂਦਾ ਹੈ।  
- `drafts/` ਹੇਠ ਖਾਕੇ ਸਮੱਗਰੀ ਜਾਣਬੂਝ ਕਰਕੇ ਛੱਡੀ ਗਈ ਹੈ।  

## ਅਗਲਾ ਕੰਮ

- ਭਵਿੱਖਲੀ ਸੀਰੀਜ਼ ਦੇ ਹਿੱਸੇ ਵਜੋਂ ਇੱਕੋ ਪਹਿਰਾਵੇ ਨੂੰ Azure AI Search ਅਤੇ Azure OpenAI ਨਾਲ ਦੁਬਾਰਾ ਬਣਾਉਣਾ।  
- ਜਦ ਸਥਾਨਕ ਅਤੇ Azure ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ ਦੋਹਾਂ ਸਥਿਰ ਹੋ ਜਾਣ, ਤਾਂ ਪ੍ਰਾਪਤੀ ਅਤੇ ਜਵਾਬ ਮੁੱਲਾਂਕਣ ਸ਼ਾਮਲ ਕਰਨਾ।
