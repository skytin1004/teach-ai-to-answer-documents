# Zahtjevi

Svaki članak o implementaciji ima fokusiranu datoteku sa zahtjevima.

| Datoteka | Koristi |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Serija 2 open-source RAG bilježnica, uključujući opcionalne Ollama pomoćnike za generiranje |
| [all.txt](../../../requirements/all.txt) | Verifikacija na razini repozitorija i CI |

Koristite fokusiranu datoteku prilikom pokretanja jedne bilježnice. Koristite `all.txt` prilikom provjere cijelog repozitorija.

`open-source-rag.txt` i `all.txt` uključuju `fastembed` za lokalne ugrađene prikaze i `python-dotenv` tako da Serija 2 može opcionalno omogućiti Ollama generiranje iz `.env` bez mijenjanja retrieval pipeline.
