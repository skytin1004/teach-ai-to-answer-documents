# កំណែប្រវត្តិ

## មិនបានចេញផ្សាយ

ដែនកំណត់ចេញផ្សាយសាធារណៈដំបូងសម្រាប់ **បង្រៀន AI ដើម្បីឆ្លើយសំណួរតាមឯកសាររបស់អ្នក**។

### បានបន្ថែម

- អត្ថបទជាស៊េរី 1 អំពីការសម្រេចចិត្តរចនាសម្ព័ន្ធ RAG, ការប្រៀបធៀបរវាង Azure និងប្រភពបើក និងតើការតំរូវការផ្សេងៗនៅកន្លែងណា។
- អត្ថបទជាស៊េរី 2 និងសៀវភៅកំណត់ត្រាសម្រាប់ដំណើរការអន្តរកម្មប្រភពបើក RAG នៅក្នុងតំបន់ ដោយប្រើម៉ូដ Qdrant ក្នុងតំបន់, ការបញ្ចូលមូលដ្ឋាន FastEmbed នៅក្នុងតំបន់, ការតម្រៀបតាមរយៈទំងន់ស្រាល, Ollama និង Phi-4-mini។
- ទ្រង់ទ្រាយសិក្សាដោយជំហាន់រៀងរាល់ជំហានស៊េរី 2 ដោយមានកូដ Python និងកំណត់សម្គាល់ផ្ទៀងផ្ទាត់ពីសៀវភៅកំណត់ត្រាដែលបានអនុវត្ត។
- ផ្លូវបង្កើតចម្លើយជាជម្រើសស៊េរី 2 ជាមួយ Ollama និង Phi-4-mini ខណៈរក្សាទុកការចាប់យកតាម CPU ក្នុងតំបន់ជាដំណើរធម្មតា។
- ការផ្ទៀងផ្ទាត់ Ollama ក្នុងតំបន់សម្រាប់ស៊េរី 2 ប្រើ `phi4-mini:3.8b` លើ RTX 3060 Laptop GPU។
- ទិន្នន័យគំរូសម្រាប់គោលនយោបាយសាលា និងការណែនាំ AI សម្រាប់វគ្គសិក្សា។
- ឯកសារតម្រូវការសម្រាប់សៀវភៅកំណត់ត្រាសាធារណៈ និងការផ្ទៀងផ្ទាត់កម្រិតឃ្លាំងទិន្នន័យ។
- ស្គ្រីបផ្ទៀងផ្ទាត់ឃ្លាំងសម្រាប់តំណ Markdown ក្នុងតំបន់ និងការផ្ទៀងផ្ទាត់/អនុវត្តសៀវភៅកំណត់ត្រា។
- ដំណើរការនៅ GitHub Actions សម្រាប់ការផ្ទៀងផ្ទាត់សៀវភៅកំណត់ត្រា។
- `.env.example` សម្រាប់ការរៀបចំការបង្កើត Ollama ក្នុងតំបន់ជាជម្រើសដោយគ្មានការប្តូរការកំណត់ក្នុងតំបន់។
- ឯកសារ README នៅកម្រិតថតសម្រាប់អត្ថបទ សៀវភៅកំណត់ត្រា តម្រូវការ ទិន្នន័យគំរូ និងស្គ្រីប។
- បញ្ជីពិនិត្យការបោះពុម្ពផ្សាយសម្រាប់សុវត្ថិភាពសាធារណៈ និងការផ្ទៀងផ្ទាត់។
- កន្លែងធ្វើការប្រតិបត្តិការ ខ្យល់សម្រាប់ខាងមុខ Azure និងមាតិកាការវាយតម្លៃ។

### បានផ្ទៀងផ្ទាត់

- ការផ្ទៀងផ្ទាត់តំណ Markdown ក្នុងតំបន់ជោគជ័យ។
- សៀវភៅកំណត់ត្រាស៊េរី 2 ផ្ទៀងផ្ទាត់ជោគជ័យ។
- សៀវភៅកំណត់ត្រាស៊េរី 2 អនុវត្តជោគជ័យនៅក្នុងបរិវេណផ្ទៀងផ្ទាត់ក្នុងតំបន់។
- ឯកសារសៀវភៅកំណត់ត្រាត្រូវបានរក្សាទុកដោយគ្មានលទ្ធផលដែលបានរក្សាទុក ឬ ការរាប់ចំនួនអនុវត្ត។
- គ្មានសម្ងាត់ពិតណាមួយត្រូវបានប្តូរដោយពេញលេញ។
