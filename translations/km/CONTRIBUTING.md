# ចូលរួមចំណែក

គម្រោងនេះត្រូវបានរៀបចំនៅក្នុងប្រភេទស៊េរីប្រកាសប្លក់ និងឧទាហរណ៍កំណត់ត្រាដែលអាចរត់បាន។

## មុនបើកសំណើ Pull Request

រត់ស្គ្រីបផ្ទៀងផ្ទាត់ក្នុងទីលាន៖

```powershell
python scripts\verify_notebooks.py
```

សម្រាប់ការអនុវត្តឬការផ្លាស់ប្តូរកំណត់ត្រា ដំណើរការកំណត់ត្រាដែលមានសុវត្ថិភាពក្នុងទីលាន៖

```powershell
python scripts\verify_notebooks.py --execute
```

## គោលការណ៍កំណត់ត្រា

- រក្សាឲ្យកំណត់ត្រាអាចអានបាន និងផ្តោតលើអត្ថបទពាក់ព័ន្ធ។
- មិនបញ្ចូលលទ្ធផលកំណត់ត្រាទុក ឬចំនួនរត់ក្នុងកំណត់ត្រា។
- ប្រើទិន្នន័យគំរូតូចពី `sample_data/` លើកលែងអត្ថបទត្រូវការធនធានក្រៅជាក់លាក់។
- កត់ត្រាលទ្ធផលផ្ទៀងផ្ទាត់នៅក្នុងអត្ថបទពាក់ព័ន្ធនៅពេលមានការផ្លាស់ប្តូរយុទ្ធសាស្ត្រ។

## សម្ងាត់ និងការផ្ទៀងផ្ទាត់

- មិនបញ្ចូលគ្រាប់ API keys, token, ពាក្យសម្ងាត់, ចំណុចចូលឯកជន ឬឯកសារ `.env` ទេ។
- ប្រើ `.env.example` សម្រាប់តែតម្លៃជំនួសប៉ុណ្ណោះ។
- ប្រើអថេរបរិយាកាសសម្រាប់ការតេស្ត Ollama នៅក្នុងទីលានជាជម្រើស។

## ឯកសារយោង

- រក្សាសម្ព័ន្ធតំណភ្ជាប់ផ្លូវដើរអត្ថបទឲ្យទាន់សម័យ។
- បន្ទាន់សម័យ `README.md` នៅពេលបន្ថែមអត្ថបទថ្មី កំណត់ត្រា ឯកសារទាមទារ មួយឬឯកសារទិន្នន័យគំរូ។
- បន្ទាន់សម័យ `CHANGELOG.md` មុនពេលផ្សព្វផ្សាយបច្ចុប្បន្នភាពគម្រោងមើលឃើញបាន។

## ផ្ទៀងផ្ទាត់

សកម្មភាព GitHub Actions ដំណើរការ៖

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

សម្ភារៈសេចក្តីព្រាងនៅក្នុង `drafts/` ត្រូវបានរំលងពេលផ្ទៀងផ្ទាត់គម្រោងរហូតដល់បានរៀបចំសម្រាប់បញ្ចូលក្នុងសាធារណៈ។

## បញ្ហា

ប្រើពំម៉ែតមតិបញ្ចេញមតិអត្ថបទសម្រាប់កែតម្រូវអត្ថបទ និងពំម៉ែតបញ្ហាកំណត់ត្រាសម្រាប់បញ្ហាការរត់កំណត់ត្រា។
