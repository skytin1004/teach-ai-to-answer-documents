# ទិន្នន័យគំរូ

សៀវភៅកំណត់ត្រាប្រើអត្ថបទគំរូសាធារណៈតូចៗដូច្នេះឧទាហរណ៍អាចរត់បានដោយគ្មានឯកសារឯកជនឬសម្គាល់ក្លោដ។

| ឯកសារ | គោលបំណង |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | ឯកសារទំនាក់ទំនងគោលនយោបាយសាលាមួយដែលមានផ្នែកអំពីកិច្ចការចុងក្រោយ, ប្រឡង, គម្រោងស្រាវជ្រាវ និងការកែប្រែរបស់គ្រូបង្រៀន |
| [course_ai_guidance.md](./course_ai_guidance.md) | ឯកសារណែនាំថ្នាក់ដែលមានផ្នែកអំពីការប្រើប្រាស់បានត្រឹមត្រូវ, ការបញ្ចេញ, ការរំពឹងការឧទ្ទិស, និងការងារក្រុម |

ឯកសារគំរូមានទំហំតូចក្នុងគោលបំណង។ វាត្រូវបានបង្កើតឡើងដើម្បីធ្វើឲ្យការទាញយក, មេតាដាតា, និងការដកស្រង់យោងក menjadiតែងាយស្រួលពិនិត្យមើល។
