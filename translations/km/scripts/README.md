# Scripts

ថតនេះមានស្គ្រីបត្រួតពិនិត្យឃ្លាំងទិន្នន័យ។

## `verify_notebooks.py`

ធ្វើការផ្ទៀងផ្ទាត់តំណភ្ជាប់ Markdown តំបន់ស្រុក, JSON សៀវភៅកំណត់ត្រា, ភាពស្អាតនៃលទ្ធផលសៀវភៅកំណត់ត្រា និងលំនាំសម្ងាត់ដែលមានហានិភ័យខ្ពស់៖

```powershell
python scripts\verify_notebooks.py
```

ដំណើរការសៀវភៅកំណត់ត្រាសាធារណៈទាំងអស់ដែលមានសុវត្ថិភាពតំបន់ស្រុក៖

```powershell
python scripts\verify_notebooks.py --execute
```

កិច្ចការជំហាន GitHub Actions ប្រើស្គ្រីបដូចគ្នា។

សម្ភារៈសង្ខេបនៅក្រោម `drafts/` ត្រូវបានរំលងរហូតដល់វាត្រៀមសម្រាប់បញ្ជីសាធារណៈ។
