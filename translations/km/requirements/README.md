# តម្រូវការ

អត្ថបទអនុវត្តន៍នីមួយៗមានឯកសារតម្រូវការដែលផ្តោតលើវា។

| ឯកសារ | ប្រើដោយ |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | សៀវភៅកំណត់ត្រា RAG ម៉ោង ២ ប្រភពបើក ដែលរួមមានជំនួយកំណត់ Ollama ជាជម្រើស |
| [all.txt](../../../requirements/all.txt) | ការធ្វើតេស្តកម្រិតឃ្លាំង និង CI |

ប្រើឯកសារដែលផ្តោតឡើងវិញពេលរត់សៀវភៅកំណត់តែមួយ។ ប្រើ `all.txt` ពេលផ្ទៀងផ្ទាត់ឃ្លាំងទាំងមូល។

`open-source-rag.txt` និង `all.txt` រួមបញ្ចូល `fastembed` សម្រាប់ការបញ្ចូលក្នុងតំបន់ និង `python-dotenv` ដូច្នេះ ម៉ោង ២ អាចបើកជម្រើសបង្កើត Ollama ពី `.env` ដោយមិនត្រូវបម្លែងស្ពាយយកវិញ។
