# បង្រៀន AI ដើម្បីឆ្លើយសំណួរតាមឯកសាររបស់អ្នក - ផែនការលំដាប់ស៊េរី

ផែនការនេះតាមដានការចេញផ្សាយស៊េរី 1 និង ស៊េរី 2 សាធារណៈ។ ការងារ Azure និងការវាយតម្លៃក្រោយត្រូវបានរក្សាទុកជារូបមន្តរហូតដល់ឧទាហរណ៍ទាំងអស់មានភាពចុងបញ្ចប់ និងត្រូវបានធ្វើអោយប្រាកដ។

កុំប្តូរឬបញ្ចូនការផ្លាស់ប្ដូរឡើយរហូតដល់មានសេចក្ដីណែនាំយ៉ាងច្បាស់។

## វុិច្ឆ័យសាធារណៈ

ការចេញផ្សាយសាធារណៈបច្ចុប្បន្ន៖

- អត្ថបទស៊េរី 1: ការសម្រេចចិត្តស្ថាបត្យកម្ម RAG, ការរៀបចំពី Azure ទល់នឹង open-source និងកន្លែងដែលការ fine-tuning សម្របសម្រួល។
- អត្ថបទស៊េរី 2: មេរៀន RAG open-source ក្នុងតំបន់។
- សៀវភៅតំណរ ស៊េរី 2: បន្ទប់សាកល្បង RAG តំបន់ដែលអាចរត់បានជាមួយ FastEmbed, Qdrant, Ollama, និង Phi-4-mini។
- ទិន្នន័យឧទាហរណ៍: នយោបាយសាលា និងមគ្គុទេសក៍ AI សម្រាប់វគ្គសិក្សា ដែលមានរាង Markdown។

ឯកសារសេចក្តីព្រាង តែ មិនទាន់នៅក្នុងបញ្ជីសាធារណៈ៖

- ការសំរេចឡើងវិញ Azure AI Search និង Azure OpenAI។
- ការវាយតម្លៃ RAG និងការត្រួតពិនិត្យ regression។

## ឈុតពិសោធន៍មេរៀន

ឈុតឧទាហរណ៍រួមគ្នាគឺជាជំនួយនាយកនយោបាយសាលា។

ជំនួយករឆ្លើយសំណួរនេះពីឯកសារតំបន់៖

```text
Can I use generative AI for my final assignment?
```

អាកប្បកិរិយាដែលរំពឹងទុកមានដូចជា៖

1. ផ្ទុកឯកសារ Markdown តំបន់។
2. បំបែក និងបែងចែកពួកវាតាមចំណងជើង។
3. បង្កើត embeddings តំបន់ និងរក្សាទុកតំណាងដែលអាចស្វែងរកបានជាមួយ metadata។
4. ទាញយកប្លុកនយោបាយដែលពាក់ព័ន្ធ។
5. រៀបចំឡើងវិញនៅពេលចាំបាច់។
6. បង្កើតឬបង្កើតចម្លើយដែលមានហេតុផល។
7. ត្រឡប់វិញនូវយោង។
8. កត់ត្រាលទ្ធផលផ្ទៀងផ្ទាត់។

## ការផ្ទៀងផ្ទាត់ស៊េរី 2

បានផ្ទៀងផ្ទាត់ក្នុង Windows ជាមួយ Python 3.12.6។

- ដំឡើង​អ្នកទាមទារ `requirements/open-source-rag.txt` បានជោគជ័យ។
- ប្រតិបត្តិ `notebooks/series-2-open-source-rag.ipynb` ជាមួយ `nbclient`។
- ការផ្ទៀងផ្ទាត់តំបន់ជាប់ៈ ឯកសារឧទាហរណ៍ 2 ដែលបានផ្ទុក, ប្លុក 8 ត្រូវបានបង្កើត, FastEmbed បង្កើត embeddings 384-វិមាត្រតំបន់, ការប្រមូល Qdrant ក្នុងសមាសភាពអង្គចងចាំត្រូវបានចាប់ផ្តើម, និងវ៉ិចទ័រ 8 ត្រូវបានបញ្ចូល។
- សំណួរ​សាកល្បង៖ "តើខ្ញុំអាចប្រើ AI បង្កើតសម្រាប់ការងារសម្រង់ចុងក្រោយរបស់ខ្ញុំទេ?"
- ប្រភពដែលបានដកឡើងចម្បងបន្ទាប់ពីការរៀបចំឡើងវិញស្រាល៖ `school_ai_policy.md`។
- ផ្នែកដែលបានដកឡើងចម្បងបន្ទាប់ពីការរៀបចំឡើងវិញស្រាល៖ `Final Assignments`។
- ផ្លូវចម្លើយលំនាំដើម៖ ប្រព័ន្ធបង្កើតចម្លើយតំបន់ដែលច្បាស់លាស់។
- Ollama ដំឡើងតាម winget; `phi4-mini:3.8b` បានទាញយកដោយជោគជ័យ។
- ផ្លូវបង្កើតចម្លើយ Ollama៖ ហើយបញ្ចប់ជាមួយ `phi4-mini:3.8b`។
- ទំហំឯកសារគំរូ Ollama៖ ប្រហាក់ប្រហែល 2.49GB លើថាស។
- ទំហំគំរូ Ollama ផ្ទុក៖ 3.3GB ត្រូវបានរាយការណ៍ដោយ `ollama ps`។
- ការផ្ទុកចេញ GPU៖ 100% GPU ត្រូវបានរាយការណ៍ដោយ `ollama ps` លើ RTX 3060 Laptop GPU។
- អង្គចងចាំ GPU នៅក្រោយការបង្កើត៖ ប្រហាក់ប្រហែល 3.5GB ពី 6GB។
- ការប្រតិបត្តិការសៀវភៅតំណរក្នុងអំឡុងពេលប្រើម៉ូដែល FastEmbed ដែលបានបន្ទុក និង Ollama បង្កើតបានឆ្លងកាត់សាកល្បងប្រហែល 34 វិនាទីតាមស្គ្រីបផ្ទៀងផ្ទាត់។
- ការសង្កេត៖ ជំហានផ្ទុកឯកសារដំបូងកម្រងឯកសារមួយបានបញ្ចូល `sample_data/README.md` ដោយចៃដន្យ; សៀវភៅតំណរ ឥឡូវនេះផ្ទុកឯកសារឧទាហរណ៍ពីរតែប៉ុណ្ណោះយ៉ាងច្បាស់។

## ការផ្ទៀងផ្ទាត់ឃ្លាំងទិន្នន័យ

- `scripts/verify_notebooks.py` អះអាងតំណភ្ជាប់ Markdown តំបន់, JSON សៀវភៅតំណរ, ភាពស្អាតនៃលទ្ធផលសៀវភៅតំណរ, និងលំនាំសម្ងាត់ហានិភ័យខ្ពស់។
- `scripts/verify_notebooks.py --execute` រត់សៀវភៅតំណរសាធារណៈពីឫសឃ្លាំងទិន្នន័យ។
- សម្ភារៈព្រាងក្រោម `drafts/` ត្រូវបានរំលងការត្រួតពិនិត្យដោយអាក្រក់។
