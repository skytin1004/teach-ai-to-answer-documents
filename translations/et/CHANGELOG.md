# Muudatuste logi

## Välja andmata

Esialgne avalik väljalase ulatus jaoks **Õpeta AI-d vastama küsimustele sinu dokumentide põhjal**.

### Lisatud

- Seeria 1 artikkel RAG arhitektuuriliste otsuste, Azure ja avatud lähtekoodiga kompromisside ning fine-tuning'i asukoha kohta.
- Seeria 2 artikkel ja märkmik lokaalsele avatud lähtekoodi RAG töövoole, kasutades Qdrant kohalikku režiimi, FastEmbed kohalikke manuseid, kerget ümberjärjestamist, Ollama ja Phi-4-mini.
- Seeria 2 samm-sammuline lõpp-lõpuni õpetus Python'i koodilõikude ja täidetud märkmiku kinnitustemärkustega.
- Valikuline Seeria 2 vastuste genereerimise rada Ollama ja Phi-4-mini abil, jättes kohaliku CPU-sõbraliku päringu vaikimisi rajaks.
- Kohalik Ollama kontroll Seeria 2 jaoks, kasutades `phi4-mini:3.8b` RTX 3060 sülearvuti GPU-l.
- Näidandmed koolipoliitika ja kursuse AI juhendamise jaoks.
- Avaliku märkmiku ja hoidla taseme kinnituse nõuete failid.
- Hoidla kinnitamise skript kohalike Markdown linkide ja märkmiku valideerimise/täideviimise jaoks.
- GitHub Actions töövoog märkmiku kontrollimiseks.
- `.env.example` valikulise kohaliku Ollama genereerimise seadistuse jaoks ilma kohaliku konfiguratsiooni käivitamiseta.
- Kaustade tasemel README failid artiklitele, märkmikele, nõuetele, näidandmetele ja skriptidele.
- Avaliku turvalisuse ja kinnituse avaldamise kontrollnimekiri.
- Mustandi töölava tulevaste Azure ja hindamiste sisude jaoks.

### Kinnitatud

- Kohalike Markdown linkide valideerimine õnnestub.
- Seeria 2 märkmik kinnitatakse edukalt.
- Seeria 2 märkmik täidetakse edukalt kohaliku kinnituskeskkonnas.
- Märkmikufailid jäetakse ilma salvestatud väljundite või täideviimisarvudeta.
- Ühtegi tõelist saladust pole salvestatud.
