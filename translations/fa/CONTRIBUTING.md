# مشارکت

این مخزن به صورت یک سری بلاگ به همراه مثال‌های قابل اجرا در دفترچه یادداشت سازماندهی شده است.

## قبل از بازکردن درخواست پول

اسکریپت اعتبارسنجی محلی را اجرا کنید:

```powershell
python scripts\verify_notebooks.py
```

برای تغییرات پیاده‌سازی یا دفترچه یادداشت، اجرای ایمن محلی دفترچه را اجرا کنید:

```powershell
python scripts\verify_notebooks.py --execute
```

## دستورالعمل‌های دفترچه یادداشت

- دفترچه‌ها را خوانا و متمرکز بر مقاله مربوطه نگه دارید.
- خروجی‌های ذخیره شده یا شمارش‌های اجرای دفترچه را کامیت نکنید.
- از داده نمونه کوچک در `sample_data/` استفاده کنید مگر اینکه مقاله نیاز به منبع خارجی خاصی داشته باشد.
- نتایج تأیید را هنگام تغییر رفتار در مقاله مربوطه ثبت کنید.

## اسرار و اطلاعات محرمانه

- کلیدهای API، توکن‌ها، رمز عبور، نقاط پایانی خصوصی یا فایل‌های `.env` را کامیت نکنید.
- از `.env.example` فقط برای مقادیر نگهدارنده استفاده کنید.
- برای آزمایش‌های محلی اختیاری Ollama از متغیرهای محیطی استفاده کنید.

## مستندات

- لینک‌های ناوبری مقاله را به‌روز نگه دارید.
- هنگام اضافه کردن مقاله جدید، دفترچه، فایل نیازمندی‌ها یا فایل داده نمونه، `README.md` را به‌روز کنید.
- قبل از انتشار به‌روزرسانی قابل مشاهده مخزن، `CHANGELOG.md` را به‌روز کنید.

## اعتبارسنجی

گردش کار GitHub Actions اجرا می‌شود:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

محتوای پیش‌نویس در `drafts/` تا زمانی که برای نمایه‌سازی عمومی آماده نشود، توسط اعتبارسنجی مخزن نادیده گرفته می‌شود.

## مسائل

برای اصلاحات مقاله از قالب بازخورد مقاله و برای مشکلات اجرای دفترچه از قالب مشکل دفترچه استفاده کنید.
