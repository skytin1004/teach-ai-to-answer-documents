# اسکریپت‌ها

این پوشه شامل اسکریپت‌های بررسی مخزن است.

## `verify_notebooks.py`

پیوندهای محلی مارک‌داون، JSON دفترچه یادداشت، پاکیزگی خروجی دفترچه یادداشت و الگوهای محرمانه پرخطر را تأیید می‌کند:

```powershell
python scripts\verify_notebooks.py
```

تمام دفترچه‌های یادداشت عمومی و محلی امن را اجرا می‌کند:

```powershell
python scripts\verify_notebooks.py --execute
```

جریان کاری GitHub Actions از همین اسکریپت استفاده می‌کند.

محتوای پیش‌نویس تحت `drafts/` تا زمانی که برای فهرست عمومی آماده شود، رد می‌شود.
