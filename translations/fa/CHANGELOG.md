# تغییرات

## منتشرنشده

دامنه انتشار اولیه برای **آموزش هوش مصنوعی به پاسخ‌گویی بر اساس مدارک شما**.

### اضافه شده

- مقاله سری ۱ درباره تصمیمات معماری RAG، مزایا و معایب Azure در مقابل متن‌باز، و جایگاه تنظیم دقیق.
- مقاله و دفترچه یادداشت سری ۲ برای یک جریان کاری RAG محلی متن‌باز با استفاده از حالت محلی Qdrant، تعبیه‌های محلی FastEmbed، رتبه‌بندی مجدد سبک، Ollama، و Phi-4-mini.
- آموزش مرحله‌به‌مرحله پایان به پایان سری ۲ با قطعات کد پایتون و یادداشت‌های تأیید از دفترچه اجرا شده.
- مسیر تولید پاسخ اختیاری سری ۲ با Ollama و Phi-4-mini در حالی که بازیابی محلی سازگار با CPU به عنوان مسیر پیش‌فرض حفظ شده است.
- تأیید محلی Ollama برای سری ۲ با استفاده از `phi4-mini:3.8b` روی RTX 3060 لپ‌تاپ GPU.
- داده نمونه برای سیاست مدرسه و راهنمایی هوش مصنوعی دوره.
- فایل‌های نیازمندی برای دفترچه عمومی و تأیید سطح مخزن.
- اسکریپت تأیید مخزن برای لینک‌های محلی Markdown و اعتبارسنجی/اجرای دفترچه یادداشت.
- جریان کاری GitHub Actions برای تأیید دفترچه.
- `.env.example` برای تنظیم اختیاری تولید محلی Ollama بدون تعهد پیکربندی محلی.
- فایل‌های README سطح پوشه برای مقالات، دفترچه‌ها، نیازمندی‌ها، داده نمونه، و اسکریپت‌ها.
- چک‌لیست انتشار برای ایمنی و تأیید عمومی.
- فضای کاری پیش‌نویس برای محتوای آینده Azure و ارزیابی.

### تأیید شده

- اعتبارسنجی لینک محلی Markdown با موفقیت انجام شده است.
- دفترچه سری ۲ با موفقیت اعتبارسنجی شده است.
- دفترچه سری ۲ با موفقیت در محیط تأیید محلی اجرا شده است.
- فایل‌های دفترچه بدون خروجی‌های ذخیره‌شده یا شمارش اجرای حفظ شده‌اند.
- هیچ راز واقعی وارد نشده است.
