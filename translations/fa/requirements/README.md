# نیازمندی‌ها

هر مقاله پیاده‌سازی دارای یک فایل نیازمندی متمرکز است.

| فایل | استفاده‌شده توسط |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | دفترچه یادداشت RAG منبع‌باز سری ۲، شامل کمک‌های اختیاری تولید اولاما |
| [all.txt](../../../requirements/all.txt) | بررسی سطح مخزن و CI |

هنگام اجرای یک دفترچه یادداشت از فایل متمرکز استفاده کنید. هنگام اعتبارسنجی کل مخزن از `all.txt` استفاده کنید.

`open-source-rag.txt` و `all.txt` شامل `fastembed` برای جاسازی‌های محلی و `python-dotenv` هستند تا سری ۲ بتواند به‌طور اختیاری تولید اولاما را از `.env` بدون تغییر در خط بازیابی فعال کند.
