# آموزش هوش مصنوعی برای پاسخ به سوالات بر اساس اسناد شما - برنامه مجموعه

این برنامه انتشار عمومی سری ۱ و سری ۲ را دنبال می‌کند. کارهای آژور و ارزیابی به صورت پیش‌نویس باقی می‌مانند تا مثال‌ها به‌طور کامل از ابتدا تا انتها تکمیل و تأیید شوند.

تا دستور صریح داده نشده است، تغییرات را ارسال یا تعهد ندهید.

## دامنه عمومی

انتشار عمومی فعلی:

- مقاله سری ۱: تصمیمات معماری RAG، مقایسه آژور و منبع باز، و جایگاه تنظیم دقیق.
- مقاله سری ۲: آموزش RAG منبع باز محلی.
- دفترچه سری ۲: آزمایشگاه قابل اجرا RAG محلی با FastEmbed، Qdrant، Ollama، و Phi-4-mini.
- نمونه داده: فایل‌های Markdown سیاست مدرسه و راهنمای هوش مصنوعی دوره.

پیش‌نویس شده اما هنوز در فهرست عمومی نیست:

- بازسازی جستجوی هوش مصنوعی آژور و Azure OpenAI.
- ارزیابی RAG و بررسی‌های پس‌رگرسیون.

## سناریوی آموزشی

سناریوی مشترک یک دستیار سیاست مدرسه است.

دستیار این سوال را بر اساس اسناد محلی پاسخ می‌دهد:

```text
Can I use generative AI for my final assignment?
```

رفتار مورد انتظار به شرح زیر است:

1. بارگذاری اسناد Markdown محلی.
2. تجزیه و قطعه‌بندی بر اساس عناوین.
3. ایجاد تعبیه‌های محلی و ذخیره نمایه‌های قابل جستجو با فراداده.
4. بازیابی بخش مربوط به سیاست.
5. رتبه‌بندی مجدد در صورت نیاز.
6. تولید یا ترکیب پاسخ مبتنی بر داده.
7. بازگرداندن استنادات.
8. ثبت نتایج تأیید.

## تأیید سری ۲

تأیید شده روی ویندوز با Python 3.12.6.

- فایل `requirements/open-source-rag.txt` با موفقیت نصب شد.
- اجرای `notebooks/series-2-open-source-rag.ipynb` با `nbclient`.
- اعتبارسنجی محلی موفق: 2 سند نمونه بارگذاری شد، 8 قطعه ایجاد شد، FastEmbed تعبیه‌های محلی ۳۸۴ بعدی تولید کرد، مجموعه Qdrant در حافظه راه‌اندازی شد و 8 بردار وارد شد.
- سوال آزمون: «آیا می‌توانم از هوش مصنوعی مولد برای تکلیف نهایی‌ام استفاده کنم؟»
- منبع بازیابی شده برتر پس از رتبه‌بندی مجدد سبک: `school_ai_policy.md`.
- بخش بازیابی شده برتر پس از رتبه‌بندی مجدد سبک: «تکالیف نهایی».
- مسیر پاسخ پیش‌فرض: مولف پاسخ شفاف محلی.
- Ollama از طریق winget نصب شد؛ `phi4-mini:3.8b` با موفقیت بارگیری شد.
- مسیر تولید پاسخ Ollama: با `phi4-mini:3.8b` تکمیل شد.
- اندازه فایل مدل Ollama: حدود ۲.۴۹ گیگابایت روی دیسک.
- اندازه مدل بارگذاری شده Ollama: ۳.۳ گیگابایت طبق گزارش `ollama ps`.
- بارگذاری GPU: ۱۰۰٪ GPU گزارش شده توسط `ollama ps` روی GPU لپ‌تاپ RTX 3060.
- حافظه GPU مشاهده شده پس از تولید: حدود ۳.۵ گیگابایت از ۶ گیگابایت.
- اجرای دفترچه با مدل FastEmbed کش‌شده و فعال بودن تولید Ollama در حدود ۳۴ ثانیه از طریق اسکریپت اعتبارسنجی موفق بود.
- مشاهده: یک بارگذاری اولیه تصادفی سند شامل `sample_data/README.md` شده بود؛ اکنون دفترچه فقط دو سند نمونه مورد نظر را به صراحت بارگذاری می‌کند.

## اعتبارسنجی مخزن

- `scripts/verify_notebooks.py` لینک‌های Markdown محلی، JSON دفترچه، پاکیزگی خروجی دفترچه و الگوهای مخفی پُرخطر را اعتبارسنجی می‌کند.
- `scripts/verify_notebooks.py --execute` دفترچه‌های عمومی را از ریشه مخزن اجرا می‌کند.
- مواد پیش‌نویس زیر `drafts/` عمداً نادیده گرفته می‌شوند.

## کار بعدی

- بازسازی همان سناریو با جستجوی هوش مصنوعی آژور و Azure OpenAI به عنوان بخشی از سری آینده.
- افزودن بازیابی و ارزیابی پاسخ هنگامی که پیاده‌سازی‌های محلی و آژور هر دو پایدار باشند.
