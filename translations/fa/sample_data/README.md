# داده نمونه

دفترچه‌ها از یک مجموعه نمونه عمومی کوچک استفاده می‌کنند تا مثال‌ها بدون اسناد خصوصی یا اعتبارنامه‌های ابری اجرا شوند.

| فایل | هدف |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | یک سند سیاست مدرسه با بخش‌هایی درباره تکالیف نهایی، امتحانات، پروژه‌های تحقیقاتی و تغییرات مدرس |
| [course_ai_guidance.md](./course_ai_guidance.md) | یک سند راهنمای دوره با بخش‌هایی درباره استفاده‌های مجاز، افشا، انتظارات ارجاع، و کار گروهی |

اسناد نمونه به طور عمد کوچک هستند. هدف آنها آسان کردن بررسی بازیابی، فراداده، و استنادها است.
