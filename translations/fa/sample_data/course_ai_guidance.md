# راهنمای دوره: استفاده مسئولانه از هوش مصنوعی

## استفاده‌های مجاز

دانش‌آموزان می‌توانند از ابزارهای هوش مصنوعی برای مقایسه ایده‌ها، مرور پیش‌نویس‌ها، بهبود خوانایی، و تمرین توضیح دادن مفاهیم به روش‌های مختلف استفاده کنند.

## افشای مورد نیاز

وقتی از ابزارهای هوش مصنوعی در انجام یک تکلیف استفاده می‌شود، دانش‌آموز باید یادداشتی درباره استفاده از هوش مصنوعی در پایان ارسال اضافه کند. این یادداشت باید شامل نام ابزار، نوع کمک، و اینکه آیا متنی تولید شده وارد شده است یا خیر باشد.

## انتظارات ارجاع‌دهی

خلاصه‌های تولید شده توسط هوش مصنوعی منابع اصلی نیستند. دانش‌آموزان باید به‌جای ارجاع به خود ابزار هوش مصنوعی، به کتاب‌ها، مقالات، مجموعه داده‌ها یا اسناد رسمی اصلی اشاره کنند.

## کار گروهی

تیم‌ها باید قبل از شروع کار گروهی توافق کنند که چگونه از ابزارهای هوش مصنوعی استفاده خواهند کرد. هر عضو تیم مسئول درک و توضیح نسخه نهایی ارسال شده است.
