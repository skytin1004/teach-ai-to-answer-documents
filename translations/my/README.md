# သင်တန်း AI ကို သင့်စာရွက်စာတမ်းအခြေခံပြီး မေးခွန်းများကို ဖြေဆိုနိုင်စေပါ

ဤ repository သည် RAG, Azure AI ဝန်ဆောင်မှုများ၊ open-source ရွေးချယ်စရာများနှင့် စစ်ဆေးပုံလုပ်ငန်းစဉ်များနှင့်အတူ စာရွက်စာတမ်းအခြေခံ AI စနစ်များကို တည်ဆောက်ခြင်းအကြောင်း 2026 ခုနှစ် ဘလော့ဂ်စီးရီးကိုစုစည်းထားသည်။

## နောက်ခံ

2023 ခုနှစ်တွင် 나는 Azure AI Search နှင့် Azure OpenAI ကို အသုံးပြု၍ PDF စာရွက်စာတမ်းများမှ မေးခွန်းများကို ဖြေကြားပေးရန် ChatGPT ကိုသင်ကြားပုံအကြောင်း tutorial နှစ်ပုဒ်ကို လုပ်ကိုင်ခဲ့ပါသည်။ "ChatGPT ကို သင့်ဒေတာပေါ်တွင် အသုံးပြုခြင်း" ဆိုသော ထင်ရှားသံကို အဲဒီအချိန်တွင် သစ်စက်စက် ဖြစ်နေခဲ့ပြီး၊ ရည်ရွယ်ချက်မှာ လက်တွေ့အသုံးပြုနိုင်သည့် workflow တစ်ခုကို ပြသရန်ဖြစ်ခဲ့သည်။ စာရွက်စာတမ်းများကို သိမ်းဆည်း၊ အညွှန်းပြု၊ သက်ဆိုင်ရာအကြောင်းအရာများကို ရယူပြီး ထိုရရှိသောအချက်အလက်မှ ဖြေကြားချက်များကို ဖန်တီးရာ ဖော်ပြရန်ဖြစ်သည်။

2026 ခုနှစ်တွင် RAG ecosystem က ပိုမိုကြီးမားလာသည်။ Azure AI Search သည် ခေတ်မီ Vector နှင့် Hybrid Retrieval ပုံစံများကို ပံ့ပိုးပေးပြီး၊ Azure OpenAI သည် Microsoft Foundry Models ecosystem ၏ တစ်စိတ်တစ်ပိုင်းဖြစ်သည်။ LangGraph, LlamaIndex, Haystack, Qdrant, Milvus, Weaviate, Chroma, Ollama, နှင့် vLLM ကဲ့သို့သော open-source ကိရိယာများသည် အမှန်တကယ် အသုံးဝင်နိုင်သောရွေးချယ်စရာများဖြစ်လာကြသည်။

ဒါ့ကြောင့် ဤဘာသာရပ်ကို ပြန်လည်ကြည့်ရှုလိုခဲ့သည်။ မေးခွန်းမှာ "RAG ကို ဘယ်လို တည်ဆောက်မလဲ?" သာမက အခုတော့ အမျိုးမျိုးသော နည်းလမ်းများရှိပြီး၊ အရေးပါဆုံးမေးခွန်းမှာ "ငါ့အခြေအနေအတွက် ဘယ်ဖွဲ့စည်းမှုပုံစံကို ရွေးသင့်မလဲ?" ဖြစ်လာသည်။

ဤစီးရီးသည် ဆုံးဖြတ်ချက်ချခြင်းအဆင့်တွင် စတင်သည်။ အကောင်အထည်ဖော်ခြင်းထဲသို့ နက်နဲစွာ ဝင်မည့်အချက်များ မတိုင်မီ AI ဝန်ဆောင်မှုများကို ဘာကြောင့် retrieval လိုအပ်သလဲ၊ Azure အခြေပြု managed services များသည် ဘယ်အချိန်တွင် သင့်တော်သလဲ၊ open-source ရွေးချယ်စရာများက ဘယ်အခါပိုကောင်းသလဲ၊ နှင့် fine-tuning ဘယ်နေရာမှာ သင့်တော်သလဲ ဆိုတာကို ဆန်းစစ်ကြည့်သည်။

>
> ဤ repository သည် ဘာသာစကား ၅၀ ကျော်နဲ့အတူ ပါရှိပြီး ဒေါင်းလုပ်အရွယ်အစားကို တော်တော်များများ တိုးစေသည်။ ဘာသာပြန်ချက်များ မပါဘဲ ကူးယူလိုပါက sparse checkout ကို အသုံးပြုပါ။
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> ၎င်းဖြင့် သင်သည် အတန်းကို ပိုမိုမြန်ဆန်စွာ ပြီးမြောက်စေရန် လိုအပ်သည့် အားလုံးကို ရယူနိုင်ပါသည်။
