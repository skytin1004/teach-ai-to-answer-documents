# လိုအပ်ချက်များ

အသုံးပြုမှုဆောင်းပါးတိုင်းတွင် အာရုံစိုက်ထားသော လိုအပ်ချက်ဖိုင်တစ်ခုရှိသည်။

| ဖိုင် | အသုံးပြုသူ |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Series 2 open-source RAG မှတ်စုစာအုပ်၊ အတွဲအလျားအဖြစ် Ollama ထုတ်လုပ်ရေး ကူညီတဲ့အရာများပါဝင်သည် |
| [all.txt](../../../requirements/all.txt) | ဂိုဏ်းစာရင်း အဆင့်အတန်း များသက်သေအောင်လုပ်ခြင်းနှင့် CI |

တစ်ခုတည်းသော မှတ်စုစာအုပ်ကို လည်ပတ်စဉ်တွင် အာရုံစိုက်ထားသော ဖိုင်ကို အသုံးပြုပါ။ ဂိုဏ်းစာရင်း နေရာတစ်ခုလုံးကို စစ်ဆေးခြင်းအတွက် `all.txt` ကို အသုံးပြုပါ။

`open-source-rag.txt` နှင့် `all.txt` တွင် ဒေသဆိုင်ရာ လက္ဗွည်းများအတွက် `fastembed` နှင့် Series 2 မှ `.env` မှ Ollama ထုတ်လုပ်မှုကို ရွေးချယ် ဖွင့်နိုင်ရန် `python-dotenv` ပါဝင်သည်။ ထိုမှတဆင့် ရယူခြင်း စနစ်ကို မပြောင်းလဲဘဲ အသုံးပြုနိုင်သည်။
