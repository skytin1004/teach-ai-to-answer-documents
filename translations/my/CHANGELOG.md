# Changelog

## Unreleased

**Teach AI to Answer Questions Based on Your Documents** အတွက် စိတ်ကြိုက်ပြည်သူထံ တရားဝင်ထုတ်ပြန်မှု အကွာအဝေး။

### Added

- RAG architecture ဆောက်လုပ်မှုပြဋ္ဌာန်းချက်များ၊ Azure နှင့် open-source ကွာခြားချက်များ၊ နှင့် fine-tuning အနေအထားကို ရေးသားထားသော Series 1 ဆောင်းပါး။
- Qdrant local mode၊ FastEmbed local embeddings၊ အလွယ်တကူ reranking၊ Ollama နှင့် Phi-4-mini ကို အသုံးပြုသော ဒေသန္တရ open-source RAG workflow အတွက် Series 2 ဆောင်းပါးနှင့် notebook။
- Python snippets နှင့် တင်ထားသော notebook မှ စစ်ဆေးချက်မှတ်တမ်းများ ပါဝင်သော Series 2 အဆင့်စဉ်အားလုံးလမ်းညွှန်လက်ဖတ်နည်း။
- ဒေသန္တရ CPU အဆင်ပြေသော retrieval ကို ပုံမှန်လမ်းကြောင်းအဖြစ် ထားရှိပြီး Ollama နှင့် Phi-4-mini ဖြင့် ရွေးချယ်စရာ Series 2 အဖြေထုတ်လမ်းကြောင်း။
- RTX 3060 Laptop GPU တွင် `phi4-mini:3.8b` သုံး၍ Series 2 အတွက် ဒေသန္တရ Ollama စစ်ဆေးမှု။
- ကျောင်းမူဝါဒနှင့် သင်ရိုး AI လမ်းညွှန်ရေးသားမှုအတွက် နမူနာဒေတာ။
- ပြည်သူ notebook နှင့် repository အဆင့်စစ်ဆေးမှုအတွက် လိုအပ်ချက်ဖိုင်များ။
- ဒေသန္တရ Markdown link များနှင့် notebook စစ်ဆေးမှု/လုပ်ဆောင်မှုအတွက် repository စစ်ဆေးရေး script။
- Notebook စစ်ဆေးမှုအတွက် GitHub Actions workflow။
- ဒေသန္တရ Ollama ထုတ်လုပ်မှုတွင် တင်သွင်းထားခြင်းမလိုအပ်သော `.env.example` ဖိုင်။
- ဆောင်းပါးများ၊ notebook များ၊ လိုအပ်ချက်များ၊ နမူနာဒေတာများနှင့် script များအတွက် ဖိုล်ဒါအဆင့် README ဖိုင်များ။
- ပြည်သူလုံခြုံမှုနှင့် စစ်ဆေးမှုအတွက် ထုတ်ဝေရန် စာရင်းစစ်စစ်နှုန်းစာရင်း။
- ယခုအချိန်မှ ယာဇာနှင့် အကဲဖြတ် ချိတ်ဆက်မှုအတွက် ရေးဆွဲနေသော ခုံရုံ။

### Verified

- ဒေသန္တရ Markdown link စစ်ဆေးမှု ဖြတ်တောက်မှု။
- Series 2 notebook အောင်မြင်စွာ စစ်ဆေးရမည်။
- Series 2 notebook ဒေသန္တရ စစ်ဆေးရေးပတ်ဝန်းကျင်တွင် အောင်မြင်စွာ လုပ်ဆောင်ခြင်း။
- Notebook ဖိုင်များတွင် ထုတ်ယူမှုများသိုလှောင်ခြင်း မရှိ၊ လုပ်ဆောင်မှုအရေအတွက် မရှိ။
- လက်ရှိတွင် လျှို့ဝှက်ချက်များ မရှိဘဲ ထည့်သွင်းထားခြင်း မရှိ။
