# စမ်းသပ်မှု ဒေတာ

အဆိုပါ notebook များတွင် နမူနာအဖြစ် အသုံးပြုနိုင်သော အသေးစား အများသဘောတူ စာတမ်းတစ်စုကို အသုံးပြုထားပြီး ဥပမာများကို ပုဂ္ဂိုလ်ရေးစာရွက်စာတမ်းများ သို့မဟုတ် cloud အကောင့်အချက်အလက်များမလိုဘဲ ရောထွေးစွာ လည်ပတ်နိုင်ပါသည်။

| ဖိုင် | ရည်ရွယ်ချက် |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | နောက်ဆုံး အပ်နှင်းစာမေးပေးမှု၊ စာမေးပွဲများ၊ သုတေသနစီမံကိန်းများနှင့် တာဝန်ရှိသူ ထောက်ခံချက်များ အကြောင်းပါသော ကျောင်း ပေါ်လစီစာရွက်စာတမ်း |
| [course_ai_guidance.md](./course_ai_guidance.md) | အသုံးပြုခွင့်ရှိမှုများ၊ ဖော်ပြချက်၊ ကိုးကားချက် မျှော်မှန်းချက်များနှင့် အုပ်စုလုပ်ငန်းများ အကြောင်းပါသော သင်တန်းလမ်းညွှန်စာရွက်စာတမ်း |

နမူနာ အစီအစဉ်စာရွက်စာတမ်းများကို ရည်ရွယ်ချက်အရ သေးငယ်စွာ စုဆောင်းထားပါသည်။ ၎င်းတို့သည် ရယူမှု၊ မီတာဒေတာနှင့် ကိုးကားချက်များကို လွယ်ကူစွာ စစ်ဆေးနိုင်ရန် ရည်ရွယ်ထားပါသည်။
