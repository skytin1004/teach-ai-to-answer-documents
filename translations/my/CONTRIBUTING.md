# Contributing

ဒီရေပေါ်ဇာတ်အစီအစဉ်ကို ဘလော့ဂ်စီးရီးနဲ့ ပြေးနိုင်တဲ့ notebook ဥပမာတွေ အဖြစ် စီစဉ်ထားပါတယ်။

## Before Opening a Pull Request

ဒေသခံ အတည်ပြု စာရင်းစစ် စာရွက်ကို run ပါ-

```powershell
python scripts\verify_notebooks.py
```

ဆောင်ရွက်မှု သို့မဟုတ် notebook ပြင်ဆင်မှုများအတွက် လုပ်ဆောင်ရန် ဒေသခံ-safe notebook စမ်းသပ်မှုကို ပြုလုပ်ပါ-

```powershell
python scripts\verify_notebooks.py --execute
```

## Notebook Guidelines

- Notebook များကို ဖတ်ရှုရန်လွယ်ကူပြီး ဆောင်းပါးနှင့် ဆက်စပ်မှုရှိအောင် ထိန်းသိမ်းပါ။
- သိမ်းဆည်းပြီးသော notebook ထုတ်လွှင့်ချက်များ သို့မဟုတ် အပြုအမူရေတွက်ချက်များ commit မလုပ်ပါနှင့်။
- ဆောင်းပါး၌ အသီးသီး ရှိတဲ့ အပြင်အရင်းအမြစ်လိုအပ်ချက် မရှိမှသာ `sample_data/` မှ သေးငယ်သည့် သရုပ်ပြ ဒေတာများကို အသုံးပြုပါ။
- အပြုအမူ ပြောင်းလဲမှုများ ရှိသည်ဆိုပါက ဆောင်းပါးတွင် အတည်ပြုရလဒ်ကို မှတ်တမ်းတင်ပါ။

## Secrets and Credentials

- API key များ၊ token များ၊ စကားဝှက်များ၊ ပုဂ္ဂလိက ကွန်ရက် လိပ်စာများ သို့မဟုတ် `.env` ဖိုင်များကို commit မလုပ်ပါနှင့်။
- `.env.example` ကို placeholder တန်ဖိုးများအတွက်သာ အသုံးပြုပါ။
- ရွေးချယ်အဆင်ပြေသော ဒေသခံ Ollama စမ်းသပ်မှုများအတွက် Περιβαλλοντικές μεταβλητές ကိုအသုံးပြုပါ။

## Documentation

- ဆောင်းပါး လမ်းညွှန်လင့်များကို အချိန်ရောက်တိုင်း ပြင်ဆင်ထားပါ။
- ဆောင်းပါး အသစ်၊ notebook၊ လိုအပ်ချက် ဖိုင် သို့မဟုတ် sample data ဖိုင်အသစ် ထည့်သွင်းသောအခါ `README.md` ကို ပြင်ဆင်ပါ။
- မျက်မှောက်တွင် Repository အသစ် ထွက်ရှိမှသာ `CHANGELOG.md` ကို update လုပ်ပါ။

## Verification

GitHub Actions workflow သည် အောက်ပါအတိုင်း အလုပ်လုပ်ပါသည်-

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/`အောက်ရှိ မူကြမ်းစာတမ်းများသည် အများသိအောင် စာရင်းသွင်းရန် အသင့်ဖြစ်သည်အထိ Repository အတည်ပြုမှုမှ ကျော်လွှားထားသည်။

## Issues

ဆောင်းပါး သို့ပြင်ဆင်မှုများအတွက် ဆောင်းပါးမှတ်ချက်နမူနာကို၊ notebook အလုပ်လုပ်မူ လုပ်ငန်းဆိုင်ရာ ပြဿနာများအတွက် notebook ပြဿနာနမူနာကို အသုံးပြုပါ။
