# Scripts

ဒီဖိုလ်ဒါထဲမှာ repository သက်သေခံ script တွေ ပါဝင်ပါတယ်။

## `verify_notebooks.py`

ဒေသခံ Markdown linkများ၊ notebook JSON၊ notebook output သန့်ရှင်းမှု နှင့် အန္တရာယ်များတဲ့ secret ပုံစံများကို စစ်ဆေးသည်-

```powershell
python scripts\verify_notebooks.py
```

အားလုံး၏ အများပြည်သူ ဒေသခံ-လုံခြုံသော notebook များကို အလုပ်လုပ်ဆောင်သည် -

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions workflow မှလည်း ဤ script ကို အသုံးပြုသည်။

`drafts/` အောက်ရှိ draft စာရွက်များကို အများပြည်သူစာရင်းဝင်ရန် အသင့်မဖြစ်မှီ အဆင့်ဆင်းထားသည်။
