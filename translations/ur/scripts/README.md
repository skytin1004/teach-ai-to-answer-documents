# Scripts

یہ فولڈر ذخیرہ کی تصدیقی اسکرپٹس پر مشتمل ہے۔

## `verify_notebooks.py`

مقامی مارک ڈاؤن لنکس، نوٹ بک JSON، نوٹ بک آؤٹ پٹ کی صفائی، اور اعلیٰ خطرے والے خفیہ پیٹرنز کی تصدیق کرتا ہے:

```powershell
python scripts\verify_notebooks.py
```

تمام عوامی مقامی محفوظ نوٹ بکس کو چلاتا ہے:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions ورک فلو بھی اسی اسکرپٹ کو استعمال کرتا ہے۔

`drafts/` کے تحت مسودہ مواد کو عوامی فہرست کے لیے تیار ہونے تک چھوڑ دیا جاتا ہے۔
