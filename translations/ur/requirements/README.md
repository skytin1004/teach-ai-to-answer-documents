# ضروریات

ہر نفاذی مضمون کے ساتھ ایک مرکوز ضروریات فائل ہوتی ہے۔

| فائل | استعمال کنندہ |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | سیریز 2 اوپن سورس RAG نوٹ بک، بشمول اختیاری Ollama جنریشن مددگار |
| [all.txt](../../../requirements/all.txt) | مخزن کی سطح کی تصدیق اور CI |

جب ایک نوٹ بک چلائیں تو مرکوز فائل استعمال کریں۔ پورے مخزن کی تصدیق کرتے وقت `all.txt` استعمال کریں۔

`open-source-rag.txt` اور `all.txt` میں `fastembed` شامل ہے جو مقامی اینبیڈنگز کے لیے اور `python-dotenv` تاکہ سیریز 2 اختیاری طور پر `.env` سے Ollama جنریشن فعال کر سکے بغیر بازیابی کے پائپ لائن کو تبدیل کیے۔
