# تبدیلی کی فہرست

## غیر جاری شدہ

**اپنے دستاویزات کی بنیاد پر سوالات کا جواب دینے کے لیے AI کو تعلیم دینے** کی ابتدائی عوامی رہائی کا دائرہ کار۔

### شامل کریں

- RAG آرکیٹیکچر کے فیصلوں، Azure بمقابلہ اوپن سورس کے موازنہ، اور جہاں فائن ٹیوننگ فٹ بیٹھتی ہے، پر سیریز 1 کا مضمون۔
- Qdrant لوکل موڈ، FastEmbed لوکل ایمبیڈنگز، ہلکی پھلکی ری رینکنگ، Ollama، اور Phi-4-mini استعمال کرتے ہوئے ایک لوکل اوپن سورس RAG ورک فلو کے لیے سیریز 2 کا مضمون اور نوٹ بک۔
- Python ٹکڑوں اور اجرا شدہ نوٹ بک کے تصدیقی نوٹس کے ساتھ سیریز 2 کا مرحلہ وار اختتام سے اختتام تک ٹیوٹوریل فارمٹ۔
- سیریز 2 کا آپشنل جواب تخلیق کا راستہ Ollama اور Phi-4-mini کے ساتھ، جبکہ ڈیفالٹ راستہ کے طور پر لوکل CPU-دوست بازیابی کو برقرار رکھنا۔
- RTX 3060 لیپ ٹاپ GPU پر `phi4-mini:3.8b` کا استعمال کرتے ہوئے سیریز 2 کے لیے لوکل Ollama تصدیق۔
- اسکول کی پالیسی اور کورس AI رہنمائی کے لیے نمونہ ڈیٹا۔
- عوامی نوٹ بک اور ریپوزیٹری سطح کی تصدیق کے لیے ضروری فائلیں۔
- لوکل Markdown لنکس اور نوٹ بک کی تصدیق/اجراء کے لیے ریپوزیٹری تصدیقی اسکرپٹ۔
- نوٹ بک تصدیق کے لیے GitHub Actions ورک فلو۔
- لوکل کنفیگریشن کو کمیٹ کیے بغیر اختیاری لوکل Ollama تخلیق کے لیے `.env.example`۔
- مضامین، نوٹ بکس، ضروریات، نمونہ ڈیٹا، اور اسکرپٹس کے لیے فولڈر سطح کے README فائلیں۔
- عوامی حفاظت اور تصدیق کے لیے اشاعت کی چیک لسٹ۔
- آئندہ Azure اور تشخیصی مواد کے لیے ڈرافٹ ورک اسپیس۔

### تصدیق شدہ

- لوکل Markdown لنک کی توثیق کامیابی سے گزر گئی۔
- سیریز 2 کی نوٹ بک کامیابی سے توثیق کی گئی۔
- سیریز 2 کی نوٹ بک لوکل تصدیقی ماحول میں کامیابی سے چلائی گئی۔
- نوٹ بک فائلیں بغیر محفوظ شدہ آؤٹ پٹ یا اجرا کے شمار کے رکھی گئی ہیں۔
- کوئی اصل خفیہ معلومات کمیٹ نہیں کی گئی ہیں۔
