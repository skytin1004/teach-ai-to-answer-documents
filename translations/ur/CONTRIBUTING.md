# تعاون کرنا

یہ ذخیرہ بلاگ سیریز کے طور پر منظم ہے اور چلائے جانے والے نوٹ بک مثالوں پر مشتمل ہے۔

## پل ریکویسٹ کھولنے سے پہلے

مقامی تصدیقی اسکرپٹ چلائیں:

```powershell
python scripts\verify_notebooks.py
```

عملدرآمد یا نوٹ بک میں تبدیلیوں کے لیے، مقامی-محفوظ نوٹ بک اجرا چلائیں:

```powershell
python scripts\verify_notebooks.py --execute
```

## نوٹ بک رہنما اصول

- نوٹ بکس کو پڑھنے کے قابل اور متعلقہ مضمون پر مرکوز رکھیں۔
- محفوظ شدہ نوٹ بک آؤٹ پٹ یا اجرا کی گنتی کو کمیٹ نہ کریں۔
- `sample_data/` سے چھوٹے سیمپل ڈیٹا استعمال کریں جب تک کہ مضمون کو کسی مخصوص خارجی وسیلے کی ضرورت نہ ہو۔
- جب رویہ میں تبدیلی آئے تو تصدیقی نتائج متعلقہ مضمون میں درج کریں۔

## راز اور اسناد

- API کلیدیں، ٹوکن، پاس ورڈز، نجی اینڈ پوائنٹس، یا `.env` فائلیں کمیٹ نہ کریں۔
- صرف پلیس ہولڈر اقدار کے لیے `.env.example` استعمال کریں۔
- مقامی Ollama تجربات کے لیے ماحول کی متغیرات استعمال کریں۔

## دستاویزات

- مضمون کے نیویگیشن لنکس کو تازہ رکھیں۔
- نیا مضمون، نوٹ بک، ضروریات کی فائل، یا سیمپل ڈیٹا فائل شامل کرنے پر `README.md` اپ ڈیٹ کریں۔
- مرئی ذخیرہ اپ ڈیٹ شائع کرنے سے پہلے `CHANGELOG.md` اپ ڈیٹ کریں۔

## تصدیق

GitHub Actions ورک فلو چلتا ہے:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` کے تحت مسودہ مواد کو ذخیرہ کی تصدیق سے اس وقت تک چھوڑ دیا جاتا ہے جب تک وہ عوامی انڈیکسنگ کے لیے تیار نہ ہو۔

## مسائل

مضمون کی اصلاحات کے لیے مضمون تاثرات کے ٹیمپلیٹ اور نوٹ بک اجرا کے مسائل کے لیے نوٹ بک مسئلہ ٹیمپلیٹ استعمال کریں۔
