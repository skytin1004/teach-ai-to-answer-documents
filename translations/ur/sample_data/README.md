# نمونہ ڈیٹا

| فائل | مقصد |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | ایک اسکول کی پالیسی دستاویز جس میں آخری اسائنمنٹس، امتحانات، تحقیقی پروجیکٹس، اور انسٹرکٹر کی طرف سے تبدیلیاں شامل ہیں |
| [course_ai_guidance.md](./course_ai_guidance.md) | ایک کورس گائیڈ دستاویز جس میں اجازت شدہ استعمال، انکشاف، حوالہ جات کی توقعات، اور گروپ ورک کے سیکشن شامل ہیں |
