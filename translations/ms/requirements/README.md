# Keperluan

Setiap artikel pelaksanaan mempunyai fail keperluan yang fokus.

| Fail | Digunakan oleh |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Siri 2 buku nota RAG sumber terbuka, termasuk pembantu penjanaan Ollama pilihan |
| [all.txt](../../../requirements/all.txt) | Pengesahan tahap repositori dan CI |

Gunakan fail fokus apabila menjalankan satu buku nota. Gunakan `all.txt` apabila mengesahkan keseluruhan repositori.

`open-source-rag.txt` dan `all.txt` termasuk `fastembed` untuk penggabungan tempatan dan `python-dotenv` supaya Siri 2 boleh secara pilihan mengaktifkan penjanaan Ollama dari `.env` tanpa mengubah saluran pengambilan.
