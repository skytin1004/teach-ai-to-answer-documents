# Course Guide: Responsableng Paggamit ng AI

## Pinapayagang Paggamit

Maaaring gamitin ng mga estudyante ang mga AI tool upang ihambing ang mga ideya, repasuhin ang mga draft, pagandahin ang nababasang teksto, at magsanay sa pagpapaliwanag ng mga konsepto sa iba't ibang paraan.

## Kinakailangang Pagpapahayag

Kapag ginamit ang mga AI tool para sa isang takdang-aralin, dapat maglagay ang estudyante ng tala ng paggamit ng AI sa dulo ng pagsusumite. Dapat kasama sa tala ang pangalan ng tool, uri ng tulong na nakuha, at kung may kasamang teksto na nalikha ng AI.

## Mga Inaasahang Pagbanggit

Ang mga buod na nilikha ng AI ay hindi pangunahing sanggunian. Dapat banggitin ng mga estudyante ang orihinal na mga libro, artikulo, dataset, o opisyal na dokumento sa halip na ang AI tool mismo.

## Output ng Grupo

Dapat pag-usapan ng mga miyembro ng grupo kung paano gagamitin ang mga AI tool bago simulan ang gawaing panggrupo. Mananatiling responsable ang bawat miyembro sa pag-unawa at pagpapaliwanag ng panghuling isinumite.
