# Скрипты

Эта папка содержит скрипты проверки репозитория.

## `verify_notebooks.py`

Проверяет локальные Markdown-ссылки, JSON ноутбуков, чистоту вывода ноутбуков и паттерны секретов с высоким риском:

```powershell
python scripts\verify_notebooks.py
```

Выполняет все публичные безопасные для локального запуска ноутбуки:

```powershell
python scripts\verify_notebooks.py --execute
```

Рабочий процесс GitHub Actions использует тот же скрипт.

Черновики в папке `drafts/` пропускаются до тех пор, пока не будут готовы для публичного индекса.
