# Вклад

Этот репозиторий организован как серия блогов и примеры с запускаемыми ноутбуками.

## Перед созданием pull-запроса

Запустите локальный скрипт проверки:

```powershell
python scripts\verify_notebooks.py
```

Для изменений реализации или ноутбуков выполните безопасный локальный запуск ноутбука:

```powershell
python scripts\verify_notebooks.py --execute
```

## Руководство по ноутбукам

- Держите ноутбуки читаемыми и сфокусированными на соответствующей статье.
- Не коммитьте сохранённые выводы ноутбуков или количество выполнений.
- Используйте небольшие тестовые данные из `sample_data/`, если только статья не требует конкретного внешнего ресурса.
- Записывайте результаты проверки в соответствующей статье при изменении поведения.

## Секреты и учетные данные

- Не коммитьте API-ключи, токены, пароли, приватные конечные точки или файлы `.env`.
- Используйте `.env.example` только для значений-заполнителей.
- Используйте переменные окружения для необязательных локальных экспериментов с Ollama.

## Документация

- Поддерживайте навигационные ссылки в статьях в актуальном состоянии.
- Обновляйте `README.md` при добавлении новой статьи, ноутбука, файла зависимостей или файла с тестовыми данными.
- Обновляйте `CHANGELOG.md` перед публикацией заметного обновления репозитория.

## Проверка

Рабочий процесс GitHub Actions выполняет:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

Черновой материал в `drafts/` пропускается проверкой репозитория до тех пор, пока он не будет готов к публичному индексированию.

## Вопросы

Используйте шаблон отзывов по статье для исправлений статьи и шаблон проблем по ноутбукам для проблем с выполнением ноутбуков.
