# Обучение ИИ отвечать на вопросы на основе ваших документов - план серии

Этот план отслеживает публичные релизы Серии 1 и Серии 2. Позднее работа с Azure и оценкой сохраняется в виде черновиков до тех пор, пока примеры не будут полностью отлажены и проверены.

Не выполняйте коммиты или пуши изменений без явного указания.

## Публичный охват

Текущий публичный релиз:

- Статья серии 1: решения архитектуры RAG, сравнение Azure и открытого ПО, и место для дообучения.
- Статья серии 2: учебное пособие по локальному RAG на открытом ПО.
- Тетрадь серии 2: исполняемая локальная лаборатория RAG с FastEmbed, Qdrant, Ollama и Phi-4-mini.
- Пример данных: файлы Markdown с политиками школы и указаниями по ИИ для курсов.

Черновики, пока не попавшие в публичный индекс:

- Перестройка Azure AI Search и Azure OpenAI.
- Оценка RAG и проверки регрессии.

## Сценарий учебного пособия

Общий сценарий — помощник по политике школы.

Помощник отвечает на вопрос из локальных документов:

```text
Can I use generative AI for my final assignment?
```

Ожидаемое поведение:

1. Загрузить локальные документы в формате Markdown.
2. Проанализировать и разбить их на части по заголовкам.
3. Создать локальные эмбеддинги и сохранить поисковые представления с метаданными.
4. Получить релевантный раздел политики.
5. При необходимости провести переоценку ранжирования.
6. Сгенерировать или составить обоснованный ответ.
7. Вернуть ссылки на источники.
8. Записать результаты проверки.
