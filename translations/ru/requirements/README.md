# Требования

Каждая статья по реализации содержит специализированный файл требований.

| Файл | Используется в |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Серия 2 открытого исходного кода блокнота RAG, включая необязательные помощники генерации Ollama |
| [all.txt](../../../requirements/all.txt) | Проверка и CI на уровне репозитория |

Используйте специализированный файл при запуске одного блокнота. Используйте `all.txt` при проверке всего репозитория.

`open-source-rag.txt` и `all.txt` включают `fastembed` для локальных вложений и `python-dotenv`, чтобы Серия 2 могла при необходимости включать генерацию Ollama из `.env` без изменения конвейера извлечения.
