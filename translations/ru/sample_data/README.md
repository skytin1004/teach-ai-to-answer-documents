# Пример данных

Блокноты используют небольшой публичный пример корпуса, чтобы примеры могли работать без приватных документов или облачных учетных данных.

| Файл | Назначение |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Документ политики школы с разделами о финальных заданиях, экзаменах, исследовательских проектах и исключениях для преподавателей |
| [course_ai_guidance.md](./course_ai_guidance.md) | Руководство по курсу с разделами о разрешенных использованиях, раскрытии информации, требованиях к цитированию и групповой работе |

Примерные документы намеренно малы. Они предназначены для облегчения проверки поиска, метаданных и цитирования.
