# Обучение ИИ отвечать на вопросы на основе ваших документов

Этот репозиторий собирает серию блогов 2026 года о построении систем ИИ, основанных на документах, с использованием RAG, сервисов Azure AI, альтернатив с открытым исходным кодом и рабочих процессов, ориентированных на оценку.

## Контекст

В 2023 году я работал над парой учебных материалов о том, как научить ChatGPT отвечать на вопросы из PDF-документов с использованием Azure AI Search и Azure OpenAI. Идея "ChatGPT на ваших данных" тогда казалась новой, и цель состояла в том, чтобы показать практический рабочий процесс: хранение документов, их индексирование, извлечение релевантного контента и генерация ответов на основе извлеченного контекста.

В 2026 году экосистема RAG значительно выросла. Azure AI Search поддерживает современные векторные и гибридные паттерны поиска, Azure OpenAI стал частью более широкой экосистемы Microsoft Foundry Models, а инструменты с открытым исходным кодом, такие как LangGraph, LlamaIndex, Haystack, Qdrant, Milvus, Weaviate, Chroma, Ollama и vLLM, стали практическими вариантами для реальных систем.

Вот почему я решил вернуться к этой теме. Вопрос теперь уже не только "Как построить RAG?" Теперь существует много способов построения, и более важный вопрос — "Какую архитектуру выбрать для моей ситуации?"

Эта серия начинается с уровня принятия решений. Прежде чем углубляться в реализацию, рассматривается, почему сервисам ИИ необходим поиск, когда имеет смысл использовать управляемые сервисы на базе Azure, когда предпочтительнее альтернативы с открытым исходным кодом и где встраивается дообучение.
