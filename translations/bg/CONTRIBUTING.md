# Принос

Това хранилище е организирано като серия от блогове плюс изпълними примери с тетрадки.

## Преди да отворите заявка за изтегляне

Стартирайте локалния скрипт за валидация:

```powershell
python scripts\verify_notebooks.py
```

За промени в имплементацията или тетрадките, стартирайте локално безопасното изпълнение на тетрадката:

```powershell
python scripts\verify_notebooks.py --execute
```

## Насоки за тетрадки

- Дръжте тетрадките четливи и фокусирани върху съответната статия.
- Не комитвайте запазените изходи от тетрадките или броя на изпълненията.
- Използвайте малки примерни данни от `sample_data/`, освен ако статията не изисква конкретен външен ресурс.
- Записвайте резултатите от проверката в съответната статия при промяна на поведението.

## Тайни и данни за достъп

- Не комитвайте API ключове, токени, пароли, частни крайни точки или `.env` файлове.
- Използвайте `.env.example` само за стойности-заместители.
- Използвайте променливи на средата за опционални локални експерименти с Ollama.

## Документация

- Поддържайте актуални връзките за навигация в статиите.
- Актуализирайте `README.md` при добавяне на нова статия, тетрадка, файл с изисквания или примерен данни.
- Актуализирайте `CHANGELOG.md` преди публикуване на видима актуализация на хранилището.

## Проверка

Работният поток на GitHub Actions стартира:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

Черновите под `drafts/` се пропускат от проверката на хранилището, докато не са готови за публично индексиране.

## Проблеми

Използвайте шаблона за обратна връзка за статия за корекции в статии и шаблона за проблем с тетрадките за проблеми с изпълнението на тетрадките.
