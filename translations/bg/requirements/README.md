# Изисквания

Всяка статия за имплементация има фокусиран файл с изисквания.

| Файл | Използван от |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Серия 2 open-source RAG тетрадка, включително опционални помощници за генериране с Ollama |
| [all.txt](../../../requirements/all.txt) | Верификация на ниво репозитория и CI |

Използвайте фокусирания файл при стартиране на една тетрадка. Използвайте `all.txt` при валидиране на целия репозиторий.

`open-source-rag.txt` и `all.txt` включват `fastembed` за локални вграждания и `python-dotenv`, за да може Серия 2 опционално да активира генериране с Ollama от `.env` без да променя pipeline за извличане.
