# Скриптове

Тази папка съдържа скриптове за проверка на хранилището.

## `verify_notebooks.py`

Проверява локални Markdown връзки, notebook JSON, чистотата на изхода на notebook и модели на високорискови тайни:

```powershell
python scripts\verify_notebooks.py
```

Изпълнява всички публични local-safe notebooks:

```powershell
python scripts\verify_notebooks.py --execute
```

Работният процес на GitHub Actions използва същия скрипт.

Чернови в `drafts/` се пропускат, докато не са готови за публичния индекс.
