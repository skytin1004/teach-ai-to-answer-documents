# Scripts

यस फोल्डरमा रिपोजिटोरी प्रमाणीकरण स्क्रिप्टहरू छन्।

## `verify_notebooks.py`

स्थानीय मार्कडाउन लिङ्कहरू, नोटबुक JSON, नोटबुक आउटपुट सफाइ, र उच्च-जोखिम गोप्य ढाँचाहरूको प्रमाणीकरण गर्दछ:

```powershell
python scripts\verify_notebooks.py
```

सबै सार्वजनिक स्थानीय-सुरक्षित नोटबुकहरू सञ्चालन गर्दछ:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions वर्कफ्लोले पनि त्यहि स्क्रिप्ट प्रयोग गर्दछ।

`drafts/` अन्तर्गतको मस्यौदा सामग्री तबसम्म छोडिन्छ जबसम्म यो सार्वजनिक सूचकांकको लागि तयार हुँदैन।
