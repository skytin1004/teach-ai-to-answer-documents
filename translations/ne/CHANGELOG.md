# परिवर्तनलेख

## अप्रकाशित

**तपाईंको कागजातहरूमा आधारित प्रश्नहरूको उत्तर दिन AI सिकाउन** को लागि प्रारम्भिक सार्वजनिक विमोचन क्षेत्र।

### थपिएको

- RAG वास्तुकला निर्णयहरू, Azure बनाम खुला-स्रोत ट्रेडअफहरू, र फाइन-ट्युनिङ कहाँ फिट हुन्छ भनी श्रृंखला १ लेख।
- Qdrant स्थानीय मोड, FastEmbed स्थानीय एम्बेडिङहरू, हलुका पुनःरैंकिङ, Ollama, र Phi-4-mini प्रयोग गरी स्थानीय खुला-स्रोत RAG वर्कफ्लोका लागि श्रृंखला २ लेख र नोटबुक।
- Python कोड स्निपेटहरू र सञ्चालन गरिएको नोटबुकबाट प्रमाणीकरण नोटहरूसहित श्रृंखला २ चरणबद्ध अन्त्य-देखि-अन्त समग्र ट्युटोरियल ढाँचा।
- स्थानीय CPU-अनुकूल पुनःप्राप्तिलाई पूर्वनिर्धारित मार्ग राख्दै Ollama र Phi-4-mini सहित वैकल्पिक श्रृंखला २ उत्तर-उत्पादन मार्ग।
- RTX 3060 ल्यापटप GPU मा `phi4-mini:3.8b` प्रयोग गरी श्रृंखला २ को लागि स्थानीय Ollama प्रमाणीकरण।
- स्कूल नीति र कोर्स AI मार्गदर्शनका लागि नमूना डाटा।
- सार्वजनिक नोटबुक र रिपोजिटरी-स्तर प्रमाणीकरणका लागि आवश्यकताहरू फाइलहरू।
- स्थानीय Markdown लिंक र नोटबुक प्रमाणीकरण/सञ्चालनको लागि रिपोजिटरी प्रमाणीकरण स्क्रिप्ट।
- नोटबुक प्रमाणीकरणका लागि GitHub Actions वर्कफ्लो।
- स्थानीय कन्फिगरेसन कमिट नगरी वैकल्पिक स्थानीय Ollama उत्पादन सेटअपका लागि `.env.example`।
- लेख, नोटबुक, आवश्यकताहरू, नमूना डाटा, र स्क्रिप्टहरूका लागि फोल्डर-स्तर README फाइलहरू।
- सार्वजनिक सुरक्षा र प्रमाणीकरणका लागि प्रकाशन चेकलिस्ट।
- भविष्यका Azure र मुल्यांकन सामग्रीका लागि प्रारूप कार्यक्षेत्र।

### प्रमाणीकरण गरिएको

- स्थानीय Markdown लिंक प्रमाणीकरण सफल भयो।
- श्रृंखला २ नोटबुक सफलतापूर्वक प्रमाणीकरण भयो।
- श्रृंखला २ नोटबुक स्थानीय प्रमाणीकरण वातावरणमा सफलतापूर्वक सञ्चालन भयो।
- नोटबुक फाइलहरू सुरक्षित गरिएका आउटपुट वा सञ्चालन गणना बिना राखिएका छन्।
- कुनै वास्तविक रहस्यहरू कमिट गरिएको छैन।
