# आवश्यकताहरू

हरेक कार्यान्वयन लेखसँग एक केन्द्रित आवश्यकताहरू फाइल हुन्छ।

| फाइल | द्वारा प्रयोग गरिएको |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | सिरिज २ ओपन-सोर्स RAG नोटबुक, वैकल्पिक Ollama निर्माण सहायकहरूसहित |
| [all.txt](../../../requirements/all.txt) | भण्डारणस्तर प्रमाणिकरण र CI |

एक नोटबुक चलाउँदा केन्द्रित फाइल प्रयोग गर्नुहोस्। सम्पूर्ण भण्डारण प्रमाणित गर्दा `all.txt` प्रयोग गर्नुहोस्।

`open-source-rag.txt` र `all.txt` मा स्थानीय एम्बेडिङहरूको लागि `fastembed` र सिरिज २ ले वैकल्पिक रूपमा `.env` बाट Ollama निर्माण सक्षम गर्न `python-dotenv` समावेश गरिएको छ जसले प्राप्ति पाइपलाइनलाई परिवर्तन नगरी काम गर्दछ।
