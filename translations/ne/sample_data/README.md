# नमुना डाटा

नोटबुकहरूले साना सार्वजनिक नमुना सामग्री प्रयोग गर्छन् ताकि उदाहरणहरू निजी दस्तावेजहरू वा क्लाउड प्रमाणपत्रहरू बिना चल्न सकून्।

| फाइल | उद्देश्य |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | अन्तिम असाइन्मेन्ट, परीक्षा, अनुसन्धान परियोजनाहरू, र प्रशिक्षक ओभरराइडहरू सम्बन्धी खण्डहरू भएको विद्यालय नीति दस्तावेज |
| [course_ai_guidance.md](./course_ai_guidance.md) | अनुमति प्राप्त प्रयोगहरू, प्रकटीकरण, उद्धरण अपेक्षाहरू, र समूह कार्य सम्बन्धी खण्डहरू भएको पाठ्यक्रम मार्गदर्शन दस्तावेज |

नमुना दस्तावेजहरू जानवरूपमा साना छन्। तिनीहरूलाई पुनःप्राप्ति, मेटाडाटा, र उद्धरणहरू सजिलै निरीक्षण गर्नका लागि बनाइएको हो।
