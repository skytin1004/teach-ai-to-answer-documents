# प्रकाशन जाँच सूची

सार्वजनिक अपडेटहरू प्रतिबद्ध गर्नु वा पुश गर्नु अघि यो जाँच सूची प्रयोग गर्नुहोस्।

## सुरक्षा

- Markdown फाइलहरू, नोटबुकहरू, नमूना डाटा वा स्क्रिप्टहरूमा कुनै API कुञ्जीहरू, टोकनहरू, पासवर्डहरू वा निजी अन्त बिन्दुहरू लेखिएको छैन भनेर पुष्टि गर्नुहोस्।
- प्रमाणपत्रहरू वातावरणीय चरहरू वा प्रबन्धित पहिचानमा राख्नुहोस्, प्रतिबद्ध फाइलहरूमा होइन।
- `.env` फाइलहरू वा चलाइएका नोटबुक आउटपुट फाइलहरू प्रतिबद्ध नगर्नुहोस्।
- `.env.example` केवल प्लेसहोल्डरका लागि राख्नुहोस्।

## प्रमाणीकरण

रेपो भेरिफिकेसन स्क्रिप्ट चलाउनुहोस्:

```powershell
python scripts\verify_notebooks.py
```

कार्यान्वयन परिवर्तनहरू प्रकाशित गर्नु अघि पूर्ण स्थानीय-सुरक्षित नोटबुक कार्यान्वयन चलाउनुहोस्:

```powershell
python scripts\verify_notebooks.py --execute
```

अपेक्षित जाँचहरू:

- स्थानीय Markdown लिंकहरू सफल हुन्छन्
- नोटबुक JSON प्रमाणीकरण सफल हुन्छ
- नोटबुकहरूमा सुरक्षित गरेको आउटपुट वा कार्यान्वयन गणना समावेश छैन
- उच्च जोखिम गोप्य ढाँचा स्क्यान सफल हुन्छ
- सार्वजनिक नोटबुकहरू स्थानीय रूपमा चल्छन्
- `drafts/` अन्तर्गत ड्राफ्ट सामग्री अनिच्छित रूपमा छोडिएको छ

## समीक्षा

- README लेख लिंकहरूले लक्षित फाइलहरूलाई संकेत गर्छन् भनेर पुष्टि गर्नुहोस्।
- प्रत्येक लेखमा रेपो नेभिगेसन र सम्बन्धित नोटबुक लिंकहरू छन् भनेर पुष्टि गर्नुहोस्।
- ड्राफ्टहरू सार्वजनिक सूचीहरूबाट लिंक नभएका छन् जबसम्म ती प्रकाशित गर्न तयार छैनन्।
- GitHub मुद्दा र पुल अनुरोध ढाँचाहरू रेपो कार्यप्रवाहसँग मेल खान्छन् भनेर पुष्टि गर्नुहोस्।
- लेखमा प्रमाणीकरण परिणामहरूले पछिल्लो नोटबुक आउटपुटसँग मेल खान्छन् भनेर पुष्टि गर्नुहोस्।
- GitHub Actions कार्यप्रवाह पुश पछि चल्ने अपेक्षा गरिएको छ भनेर निश्चित गर्नुहोस्।
- `CHANGELOG.md` प्रकाशित हुँदै गरेको अपडेटको प्रतिबिम्ब गर्दछ भनेर पुष्टि गर्नुहोस्।
- `CONTRIBUTING.md` अझै रेपो कार्यप्रवाहसँग मेल खान्छ भनेर सुनिश्चित गर्नुहोस्।

## Git

- `git status --short --branch` समीक्षा गर्नुहोस्।
- `git diff --stat` समीक्षा गर्नुहोस्।
- स्पष्ट रूपमा तयार हुँदा मात्र कमिट र पुश गर्नुहोस्।
