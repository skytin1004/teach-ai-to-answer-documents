# योगदान

यो भण्डारलाई ब्लग श्रृंखला र चलाउन मिल्ने नोटबुक उदाहरणहरूको रूपमा व्यवस्थित गरिएको छ।

## पुल अनुरोध खोल्नु अघि

स्थानीय प्रमाणीकरण स्क्रिप्ट चलाउनुहोस्:

```powershell
python scripts\verify_notebooks.py
```

कार्यान्वयन वा नोटबुक परिवर्तनहरूको लागि, स्थानीय-सुरक्षित नोटबुक कार्यान्वयन चलाउनुहोस्:

```powershell
python scripts\verify_notebooks.py --execute
```

## नोटबुक दिशानिर्देशहरू

- नोटबुकहरू पढ्न लायक र सम्बन्धित लेखमा केन्द्रित राख्नुहोस्।
- सुरक्षित नोटबुक आउटपुटहरू वा कार्यान्वयन गणनाहरू कमिट नगर्नुहोस्।
- `sample_data/` बाट सानो नमूना डेटा प्रयोग गर्नुहोस् जबसम्म लेखले विशेष बाह्य स्रोत आवश्यक नगरोस्।
- व्यवहारमा परिवर्तन हुँदा सम्बन्धित लेखमा प्रमाणीकरण परिणामहरू रेकर्ड गर्नुहोस्।

## रहस्यहरू र प्रमाणपत्रहरू

- API कुञ्जीहरू, टोकेनहरू, पासवर्डहरू, निजी अन्तबिन्दुहरू, वा `.env` फाइलहरू कमिट नगर्नुहोस्।
- `.env.example` लाई मात्र प्लेसहोल्डर मानहरूका लागि प्रयोग गर्नुहोस्।
- वैकल्पिक स्थानीय Ollama प्रयोगहरूको लागि वातावरण चरहरू प्रयोग गर्नुहोस्।

## दस्तावेजीकरण

- लेख नेभिगेसन लिङ्कहरू अद्यावधिक राख्नुहोस्।
- नयाँ लेख, नोटबुक, आवश्यकताहरू फाइल, वा नमूना डेटा फाइल थप्दा `README.md` अपडेट गर्नुहोस्।
- द्रश्य भण्डार अद्यावधिक प्रकाशित गर्नु अघि `CHANGELOG.md` अपडेट गर्नुहोस्।

## प्रमाणीकरण

GitHub Actions वर्कफ्लो चलाउँछ:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` अन्तर्गत मस्यौदा सामग्री भण्डार प्रमाणीकरणबाट तबसम्म छोडिन्छ जबसम्म यो सार्वजनिक अनुक्रमणका लागि तयार हुँदैन।

## समस्याहरू

लेख सुधारका लागि लेख प्रतिक्रिया टेम्प्लेट प्रयोग गर्नुहोस् र नोटबुक कार्यान्वयन समस्याहरूका लागि नोटबुक समस्या टेम्प्लेट प्रयोग गर्नुहोस्।
