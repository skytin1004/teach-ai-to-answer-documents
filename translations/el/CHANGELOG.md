# Αρχείο αλλαγών

## Μη κυκλοφόρησε

Αρχικό πεδίο δημόσιας κυκλοφορίας για το **Teach AI to Answer Questions Based on Your Documents**.

### Προστέθηκε

- Άρθρο Σειράς 1 σχετικά με τις αποφάσεις αρχιτεκτονικής RAG, τις ανταλλαγές Azure έναντι ανοιχτού κώδικα και πού ταιριάζει η βελτιστοποίηση.
- Άρθρο Σειράς 2 και σημειωματάριο για μια τοπική ροή εργασίας ανοιχτού κώδικα RAG χρησιμοποιώντας τοπική λειτουργία Qdrant, τοπικές ενσωματώσεις FastEmbed, ελαφρύ επανακατάταξη, Ollama και Phi-4-mini.
- Μορφή βήμα προς βήμα ολοκληρωμένου μαθήματος Σειράς 2 με αποσπάσματα Python και σημειώσεις επαλήθευσης από το εκτελεσμένο σημειωματάριο.
- Προαιρετική διαδρομή παραγωγής απαντήσεων Σειράς 2 με Ollama και Phi-4-mini διατηρώντας την τοπική φιλική προς CPU ανάκτηση ως προεπιλεγμένη διαδρομή.
- Τοπική επαλήθευση Ollama για Σειρά 2 χρησιμοποιώντας `phi4-mini:3.8b` σε RTX 3060 Laptop GPU.
- Δείγματα δεδομένων για πολιτική σχολείου και καθοδήγηση AI μαθημάτων.
- Αρχεία απαιτήσεων για το δημόσιο σημειωματάριο και επαλήθευση επιπέδου αποθετηρίου.
- Σενάριο επαλήθευσης αποθετηρίου για τοπικούς συνδέσμους Markdown και επικύρωση/εκτέλεση σημειωματαρίου.
- Ροή εργασίας GitHub Actions για επαλήθευση σημειωματαρίου.
- `.env.example` για προαιρετική τοπική ρύθμιση παραγωγής Ollama χωρίς να δεσμεύεται η τοπική ρύθμιση.
- Αρχεία README ανά φάκελο για άρθρα, σημειωματάρια, απαιτήσεις, δείγματα δεδομένων και σενάρια.
- Λίστα ελέγχου δημοσίευσης για δημόσια ασφάλεια και επαλήθευση.
- Πρόχειρος χώρος εργασίας για μελλοντικό περιεχόμενο Azure και αξιολόγησης.

### Επαληθεύτηκε

- Η επικύρωση τοπικών συνδέσμων Markdown περνάει.
- Το σημειωματάριο Σειράς 2 επικυρώνεται επιτυχώς.
- Το σημειωματάριο Σειράς 2 εκτελείται επιτυχώς στο τοπικό περιβάλλον επαλήθευσης.
- Τα αρχεία σημειωματαρίου διατηρούνται χωρίς αποθηκευμένα αποτελέσματα ή μετρήσεις εκτέλεσης.
- Δεν έχουν δεσμευτεί πραγματικά μυστικά.
