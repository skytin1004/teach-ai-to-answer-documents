# Διδάξτε στην ΤΝ να Απαντά σε Ερωτήσεις Βασισμένες στα Έγγραφά σας

![Επισκόπηση συστήματος ΤΝ RAG με βάση έγγραφα](../../assets/images/readme-hero.svg)

Αυτό το αποθετήριο συγκεντρώνει μια σειρά ιστολογίων του 2026 σχετικά με την κατασκευή συστημάτων ΤΝ με βάση έγγραφα με RAG, υπηρεσίες Azure AI, ανοιχτού κώδικα εναλλακτικές και ροές εργασίας προσανατολισμένες στην αξιολόγηση.

## Ιστορικό

Το 2023, εργάστηκα σε ένα ζευγάρι εκπαιδευτικών μαθημάτων για το πώς να διδάξουμε στο ChatGPT να απαντά σε ερωτήσεις από έγγραφα PDF χρησιμοποιώντας το Azure AI Search και το Azure OpenAI. Η ιδέα του «ChatGPT στα δεδομένα σας» φαινόταν τότε ακόμη νέα, και ο στόχος ήταν να δείξω μια πρακτική ροή εργασίας: αποθήκευση εγγράφων, ευρετηρίαση, ανάκτηση σχετικού περιεχομένου και δημιουργία απαντήσεων από το ανακτημένο πλαίσιο.

Το 2026, το οικοσύστημα RAG είναι πολύ μεγαλύτερο. Το Azure AI Search υποστηρίζει σύγχρονα μοτίβα ανάκτησης vector και υβριδικά, το Azure OpenAI αποτελεί μέρος του ευρύτερου οικοσυστήματος μοντέλων Microsoft Foundry, και εργαλεία ανοιχτού κώδικα όπως LangGraph, LlamaIndex, Haystack, Qdrant, Milvus, Weaviate, Chroma, Ollama και vLLM έχουν γίνει πρακτικές επιλογές για πραγματικά συστήματα.

Γι' αυτό ήθελα να επανεξετάσω αυτό το θέμα. Το ερώτημα δεν είναι πλέον μόνο «Πώς χτίζω RAG;» Υπάρχουν πλέον πολλοί τρόποι για να το χτίσετε, και το πιο σημαντικό ερώτημα είναι «Ποια αρχιτεκτονική πρέπει να επιλέξω για την περίπτωσή μου;»

Αυτή η σειρά ξεκινά από αυτό το επίπεδο λήψης αποφάσεων, και στη συνέχεια το μετατρέπει σε πρακτικά σεμινάρια. Η πρώτη πορεία υλοποίησης κατασκευάζει ένα τοπικό σύστημα RAG ανοιχτού κώδικα που μπορεί ο καθένας να τρέξει με δείγμα δεδομένων, Qdrant, Ollama και Phi-4-mini.

## Τοπική Δημιουργία Ollama

Το σημειωματάριο της Σειράς 2 είναι τοπικά ασφαλές από προεπιλογή. Για να ενεργοποιήσετε τη τοπική δημιουργία Ollama, αντιγράψτε το [.env.example](../../.env.example) σε `.env` και συμπληρώστε τις τιμές της Σειράς 2.

Για το Ollama της Σειράς 2, ξεσχολιάστε:

```text
SERIES2_OLLAMA_BASE_URL=http://localhost:11434
SERIES2_OLLAMA_MODEL=phi4-mini:3.8b
```

Το σημειωματάριο της Σειράς 2 φορτώνει αυτόματα το `.env` από τη ρίζα του αποθετηρίου χρησιμοποιώντας `python-dotenv`.

> [!IMPORTANT]
> Μην ανεβάζετε αρχεία `.env`, κλειδιά API, ιδιωτικά endpoints ή τιμές ειδικές για tenant. Το αποθετήριο αποφεύγει σκόπιμα να βάζει μυστικά σε αρχεία Markdown και σημειωματάρια.

Τα αρχεία απαιτήσεων είναι τεκμηριωμένα στο [requirements/README.md](./requirements/README.md).

Για να επαληθεύσετε συνδέσμους, δομή σημειωματαρίου, καθαρότητα εξόδου σημειωματαρίου και μοτίβα μυστικών υψηλού κινδύνου:
