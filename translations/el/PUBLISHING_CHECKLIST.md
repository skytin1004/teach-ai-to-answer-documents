# Λίστα Ελέγχου Δημοσίευσης

Χρησιμοποιήστε αυτή τη λίστα ελέγχου πριν από την επιβεβαίωση ή την αποστολή δημόσιων ενημερώσεων.

## Ασφάλεια

- Επιβεβαιώστε ότι δεν έχουν γραφτεί κλειδιά API, διακριτικά, κωδικοί πρόσβασης ή ιδιωτικά endpoints σε αρχεία Markdown, τετράδια, δείγματα δεδομένων ή σενάρια.
- Κρατήστε τα διαπιστευτήρια σε μεταβλητές περιβάλλοντος ή διαχειριζόμενη ταυτότητα, όχι σε αρχεία που έχουν δεσμευτεί.
- Μην κάνει commit αρχεία `.env` ή αρχεία αποτελεσμάτων εκτέλεσης τετραδίων.
- Κρατήστε το `.env.example` μόνο με δείγματα (placeholder).

## Επαλήθευση

Εκτελέστε το script επαλήθευσης αποθετηρίου:

```powershell
python scripts\verify_notebooks.py
```

Εκτελέστε την πλήρη τοπική ασφαλή εκτέλεση τετραδίου πριν από τη δημοσίευση αλλαγών υλοποίησης:

```powershell
python scripts\verify_notebooks.py --execute
```

Αναμενόμενοι έλεγχοι:

- περνούν οι τοπικοί σύνδεσμοι Markdown
- περνά η επικύρωση JSON των τετραδίων
- τα τετράδια δεν περιέχουν αποθηκευμένα αποτελέσματα ή μετρήσεις εκτέλεσης
- περνά η σάρωση προτύπου υψηλού κινδύνου για μυστικά
- τα δημόσια τετράδια εκτελούνται τοπικά
- παραλείπονται σκόπιμα υλικά δοκιμών υπό το `drafts/`

## Ανασκόπηση

- Επιβεβαιώστε ότι οι σύνδεσμοι άρθρων στο README δείχνουν στα προοριζόμενα αρχεία.
- Επιβεβαιώστε ότι κάθε άρθρο έχει πλοήγηση αποθετηρίου και συνδέσμους σχετικών τετραδίων.
- Επιβεβαιώστε ότι τα σχέδια δεν είναι συνδεδεμένα από δημόσσιους καταλόγους εκτός εάν είναι έτοιμα για δημοσίευση.
- Επιβεβαιώστε ότι τα πρότυπα ζητήσεων GitHub issues και pull request ταιριάζουν ακόμα με τη ροή εργασίας του αποθετηρίου.
- Επιβεβαιώστε ότι τα αποτελέσματα επαλήθευσης στο άρθρο ταιριάζουν με την τελευταία έξοδο τετραδίου.
- Επιβεβαιώστε ότι η ροή εργασίας GitHub Actions αναμένεται να εκτελεστεί μετά το push.
- Επιβεβαιώστε ότι το `CHANGELOG.md` αντικατοπτρίζει την ενημέρωση που δημοσιεύεται.
- Επιβεβαιώστε ότι το `CONTRIBUTING.md` εξακολουθεί να ταιριάζει με τη ροή εργασίας του αποθετηρίου.

## Git

- Εξετάστε την `git status --short --branch`.
- Εξετάστε την `git diff --stat`.
- Κάντε commit και push μόνο όταν είστε ρητά έτοιμοι.
