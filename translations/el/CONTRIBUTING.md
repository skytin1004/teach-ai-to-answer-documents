# Συνεισφορά

Αυτό το αποθετήριο είναι οργανωμένο ως σειρά άρθρων συν παραδείγματα εκτελέσιμων σημειωματάριων.

## Πριν ανοίξετε ένα Pull Request

Τρέξτε το τοπικό σενάριο επικύρωσης:

```powershell
python scripts\verify_notebooks.py
```

Για αλλαγές στην υλοποίηση ή στα σημειωματάρια, τρέξτε την τοπικά ασφαλή εκτέλεση σημειωματαρίου:

```powershell
python scripts\verify_notebooks.py --execute
```

## Οδηγίες Σημειωματαρίων

- Κρατήστε τα σημειωματάρια αναγνώσιμα και εστιασμένα στο σχετικό άρθρο.
- Μην κάνετε commit αποθηκευμένες εξόδους σημειωματαρίου ή μετρήσεις εκτέλεσης.
- Χρησιμοποιείτε μικρά δείγματα δεδομένων από το `sample_data/` εκτός εάν το άρθρο απαιτεί συγκεκριμένο εξωτερικό πόρο.
- Καταγράψτε τα αποτελέσματα επαλήθευσης στο σχετικό άρθρο όταν αλλάζει η συμπεριφορά.

## Μυστικά και Πιστοποιητικά

- Μην κάνετε commit κλειδιά API, tokens, κωδικούς πρόσβασης, ιδιωτικά endpoints ή αρχεία `.env`.
- Χρησιμοποιήστε το `.env.example` μόνο για τις τιμές θέσεων.
- Χρησιμοποιήστε μεταβλητές περιβάλλοντος για προαιρετικά τοπικά πειράματα Ollama.

## Τεκμηρίωση

- Κρατήστε τους συνδέσμους πλοήγησης άρθρων ενημερωμένους.
- Ενημερώστε το `README.md` όταν προσθέτετε νέο άρθρο, σημειωματάριο, αρχείο απαιτήσεων ή δείγμα δεδομένων.
- Ενημερώστε το `CHANGELOG.md` πριν τη δημοσίευση μιας ορατής ενημέρωσης αποθετηρίου.

## Επαλήθευση

Το workflow του GitHub Actions εκτελεί:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

Το προσχέδιο υλικό κάτω από το `drafts/` παρακάμπτεται από την επαλήθευση αποθετηρίου μέχρι να είναι έτοιμο για δημόσια ευρετηρίαση.

## Θέματα

Χρησιμοποιήστε το πρότυπο σχολίων άρθρου για διορθώσεις άρθρων και το πρότυπο θεμάτων σημειωματαρίου για προβλήματα εκτέλεσης σημειωματαρίου.
