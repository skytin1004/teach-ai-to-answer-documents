# Scripts

Αυτός ο φάκελος περιέχει σενάρια επαλήθευσης αποθετηρίου.

## `verify_notebooks.py`

Επαληθεύει τοπικούς συνδέσμους Markdown, JSON σημειωματάριων, καθαρότητα εξόδου σημειωματάριων και πρότυπα μυστικών υψηλού κινδύνου:

```powershell
python scripts\verify_notebooks.py
```

Εκτελεί όλα τα δημόσια τοπικά ασφαλή σημειωματάρια:

```powershell
python scripts\verify_notebooks.py --execute
```

Η ροή εργασίας GitHub Actions χρησιμοποιεί το ίδιο σενάριο.

Το υλικό πρόχειρου στο `drafts/` παραλείπεται μέχρι να είναι έτοιμο για το δημόσιο ευρετήριο.
