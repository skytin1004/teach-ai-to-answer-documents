# Δείγμα Δεδομένων

Τα τετράδια χρησιμοποιούν ένα μικρό δημόσιο δείγμα σώματος κειμένων ώστε τα παραδείγματα να μπορούν να τρέξουν χωρίς ιδιωτικά έγγραφα ή διαπιστευτήρια σύννεφου.

| Αρχείο | Σκοπός |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Ένα έγγραφο πολιτικής σχολείου με ενότητες για τις τελικές εργασίες, τις εξετάσεις, τα ερευνητικά έργα και τις υπερισχύσεις εκπαιδευτή |
| [course_ai_guidance.md](./course_ai_guidance.md) | Ένα έγγραφο οδηγού μαθήματος με ενότητες για επιτρεπτές χρήσεις, αποκαλύψεις, προσδοκίες παραπομπών και ομαδική εργασία |

Τα δείγματα των εγγράφων είναι σκόπιμα μικρά. Έχουν σκοπό να κάνουν την ανάκτηση, τα μεταδεδομένα και τις παραπομπές εύκολες στην επιθεώρηση.
