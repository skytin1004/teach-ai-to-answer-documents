# Απαιτήσεις

Κάθε άρθρο υλοποίησης έχει ένα εστιασμένο αρχείο απαιτήσεων.

| Αρχείο | Χρησιμοποιείται από |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Σημειωματάριο Series 2 open-source RAG, συμπεριλαμβανομένων προαιρετικών βοηθητικών εργαλείων δημιουργίας Ollama |
| [all.txt](../../../requirements/all.txt) | Επιβεβαίωση επιπέδου αποθετηρίου και CI |

Χρησιμοποιήστε το εστιασμένο αρχείο όταν εκτελείτε ένα σημειωματάριο. Χρησιμοποιήστε το `all.txt` για επαλήθευση ολόκληρου του αποθετηρίου.

Τα `open-source-rag.txt` και `all.txt` περιλαμβάνουν το `fastembed` για τοπικές ενσωματώσεις και το `python-dotenv` ώστε η Series 2 να μπορεί προαιρετικά να ενεργοποιεί τη δημιουργία Ollama από το `.env` χωρίς να αλλάζει η ροή ανάκτησης.
