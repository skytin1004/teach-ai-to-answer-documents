# ללמד בינה מלאכותית לענות על שאלות בהתבסס על המסמכים שלך - תוכנית הסדרה

תוכנית זו עוקבת אחר שחרור ציבורי של סדרה 1 וסדרה 2. עבודות עתידיות על Azure והערכות נשמרות כתבניות עד שהדוגמאות יהיו מקצה לקצה ומאומתות במלואן.

לא לבצע commit או push לשינויים עד להוראה מפורשת.

## תחום ציבורי

שחרור ציבורי נוכחי:

- מאמר סדרה 1: החלטות אדריכליות ב-RAG, דילמות Azure לעומת קוד פתוח, ואיפה כוונון מדויק מתאים.
- מאמר סדרה 2: הדרכה על RAG מבוסס קוד פתוח מקומי.
- פנקס סדרה 2: מעבדה מקומית להרצת RAG עם FastEmbed, Qdrant, Ollama, ו-Phi-4-mini.
- נתוני דוגמה: קבצי Markdown של מדיניות בית ספר והדרכה על בינה מלאכותית בקורס.

טיוטות שלא נכנסו עדיין לאינדקס הציבורי:

- בניית מחדש של Azure AI Search ו-Azure OpenAI.
- הערכות RAG ובדיקות רגרסיה.

## תרחיש הדרכה

התרחיש המשותף הוא עוזר מדיניות בית ספר.

העוזר עונה לשאלה זו מתוך מסמכים מקומיים:

```text
Can I use generative AI for my final assignment?
```

ההתנהגות הצפויה היא:

1. טעינת מסמכי Markdown מקומיים.
2. ניתוח ופיצול לפי כותרות.
3. יצירת הטמעות מקומיות ואחסון ייצוגים לחיפוש עם מטא-נתונים.
4. שליפת הסעיף הרלוונטי במדיניות.
5. דירוג מחדש בעת צורך.
6. יצירת או הרכבת תשובה מבוססת.
7. החזרת הפניות.
8. הקלטת תוצאות אימות.

## אימות סדרה 2

אומת על Windows עם Python 3.12.6.

- התקנת `requirements/open-source-rag.txt` בוצעה בהצלחה.
- הרצת `notebooks/series-2-open-source-rag.ipynb` עם `nbclient`.
- האימות המקומי עבר: נטענו 2 מסמכי דוגמה, נוצרו 8 חלקים, FastEmbed ייצר הטמעות מקומיות ב-384 ממדים, הושק אוסף בזיכרון של Qdrant, ו-8 וקטורים הוכנסו.
- שאלה לדוגמה: "האם אני יכול להשתמש בבינה מלאכותית יצירתית למשימת הגמר שלי?"
- המקור המדורג גבוה לאחר דירוג מחדש קל: `school_ai_policy.md`.
- הסעיף המדורג גבוה לאחר דירוג מחדש קל: `Final Assignments`.
- נתיב תשובה ברירת מחדל: מלחין תשובה מקומי ושקוף.
- Ollama הותקן דרך winget; `phi4-mini:3.8b` הורד בהצלחה.
- נתיב יצירת תשובה ב-Ollama: הושלם עם `phi4-mini:3.8b`.
- גודל קובץ המודל של Ollama: כ-2.49GB בדיסק.
- גודל מודל שנโหลด ב-Ollama: 3.3GB כפי שדווח ב-`ollama ps`.
- ייצוא GPU: 100% GPU כפי שדווח ב-`ollama ps` על RTX 3060 Laptop GPU.
- זיכרון GPU שנצפה לאחר יצירה: כ-3.5GB מתוך 6GB.
- הפעלת פנקס עם מודל FastEmbed משוחזר ויצירת Ollama אפשרית הושלמה בכ-34 שניות באמצעות סקריפט האימות.
- תצפית: מעבר ראשוני של טעינת מסמכים כלל בטעות את `sample_data/README.md`; כעת הפנקס טוען רק במפורש את שני מסמכי הדוגמה המיועדים.

## אימות המאגר

- `scripts/verify_notebooks.py` מאמת קישורי Markdown מקומיים, JSON הפנקס, ניקיון הפלט של הפנקס, ותבניות סודיות בסיכון גבוה.
- `scripts/verify_notebooks.py --execute` מריץ פנקסים ציבוריים משורש המאגר.
- חומר טיוטה תחת `drafts/` מדולג במכוון.
