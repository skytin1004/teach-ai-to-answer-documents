# סקריפטים

תיקיה זו מכילה סקריפטים לאימות הריפוזיטורי.

## `verify_notebooks.py`

מאמת קישורים מקומיים במארקדאון, JSON של פנקס המחברת, ניקיון הפלט של פנקס המחברת, ודפוסי סודות בסיכון גבוה:

```powershell
python scripts\verify_notebooks.py
```

מריץ את כל פנקסי המחברת הציבוריים והבטוחים מקומית:

```powershell
python scripts\verify_notebooks.py --execute
```

תהליך העבודה של GitHub Actions משתמש באותו סקריפט.

חומר טיוטה תחת `drafts/` מוותר עליו עד שהוא מוכן לאינדקס הציבורי.
