# יומן שינויים

## לא שוחרר

היקף השחרור הציבורי הראשוני עבור **ללמד AI לענות על שאלות בהתבסס על המסמכים שלך**.

### נוסף

- מאמר סדרה 1 על החלטות ארכיטקטורת RAG, התפשרויות Azure מול קוד פתוח, והיכן מתאימה כוונון עדין.
- מאמר וסדרת פנקסים של סדרה 2 עבור תהליך RAG קוד פתוח מקומי המשתמש במצב מקומי של Qdrant, הטמעות מקומיות של FastEmbed, דירוג מחדש קל משקל, Ollama, ו-Phi-4-mini.
- פורמט הדרכה שלב אחר שלב מקצה לקצה לסדרה 2 עם קטעי קוד פייתון והערות אימות מהפנקס שבוצע.
- מסלול יצירת תשובות אופציונלי בסדרה 2 עם Ollama ו-Phi-4-mini תוך שמירה על שליפה מקומית המכבדת CPU כנתיב ברירת המחדל.
- אימות Ollama מקומי לסדרה 2 באמצעות `phi4-mini:3.8b` על RTX 3060 Laptop GPU.
- נתוני דוגמה למדיניות בית ספר והנחיית קורס AI.
- קבצי דרישות לפנקס הציבורי ולאימות ברמת הרפוזיטורי.
- סקריפט אימות רפוזיטורי עבור קישורי Markdown מקומיים ואימות/ביצוע פנקס.
- תהליך GitHub Actions לאימות פנקס.
- `.env.example` להגדרת יצירת Ollama מקומית אופציונלית ללא התחייבות לקונפיגורציה מקומית.
- קבצי README ברמת התיקיה עבור מאמרים, פנקסים, דרישות, נתוני דוגמה, וסקריפטים.
- רשימת בדיקה לפרסום עבור בטיחות ואימות ציבורי.
- סביבת עבודה טיוטה לתכנים עתידיים של Azure והערכה.

### אומת

- אימות קישורי Markdown מקומי עובר בהצלחה.
- הפנקס של סדרה 2 מאומת בהצלחה.
- הפנקס של סדרה 2 מבוצע בהצלחה בסביבת האימות המקומית.
- קבצי הפנקס נשמרים ללא פלטים שמורים או ספירת ביצועים.
- לא הוחסנו סודות אמיתיים.
