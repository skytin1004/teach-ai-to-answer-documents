# רשימת בדיקה לפרסום

השתמש ברשימת הבדיקה הזו לפני ביצוע קומיט או דחיפת עדכונים ציבוריים.

## בטיחות

- אשר שאין מפתחות API, אסימונים, סיסמאות או נקודות קצה פרטיות כתובים בקבצי Markdown, מחברות, דוגמאות נתונים או סקריפטים.
- שמור את האישורים במשתני סביבה או זהות מנוהלת, לא בקבצים שהוקומיטו.
- אל תבצע קומיט לקבצי `.env` או לקבצי פלט של מחברות מופעלות.
- שמור את `.env.example` רק כאחראי לממלא מקום.

## אימות

הרץ את סקריפט האימות של המאגר:

```powershell
python scripts\verify_notebooks.py
```
  
הרץ את ההפעלה המלאה והבטוחה מקומית של המחברת לפני פרסום שינויים ביישום:

```powershell
python scripts\verify_notebooks.py --execute
```
  
בדיקות צפויות:

- קישורי Markdown מקומיים עוברים
- אימות JSON של המחברת עובר
- המחברות אינן מכילות פלט שמור או ספירות הפעלה
- סריקת דפוסי סודות בעלי סיכון גבוה עוברת
- מחברות ציבוריות מתבצעות מקומית
- חומרים טיוטות תחת `drafts/` נבדלים במתכוון

## סקירה

- אשר שקישורי המאמר ב-README מפנים לקבצים הנכונים.
- אשר שלכל מאמר יש ניווט למאגר וקישורים למחברות קשורות.
- אשר שהטיוטות אינן מקושרות מאינדקסים ציבוריים אלא אם כן הן מוכנות לפרסום.
- אשר שתבניות נושאי GitHub והבקשות משיכה עדיין תואמות את תהליך העבודה של המאגר.
- אשר שתוצאות האימות במאמר תואמות את פלט המחברת האחרון.
- אשר שתהליך העבודה של GitHub Actions צפוי לרוץ לאחר הדחיפה.
- אשר ש-`CHANGELOG.md` משקף את העדכון שמתפרסם.
- אשר ש-`CONTRIBUTING.md` עדיין תואם את תהליך העבודה של המאגר.

## Git

- סקור את הפקודה `git status --short --branch`.
- סקור את הפקודה `git diff --stat`.
- בצע קומיט ודחיפה רק כאשר אתה מוכן במפורש.
