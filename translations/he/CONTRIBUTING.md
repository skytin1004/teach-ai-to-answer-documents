# תרומה

מאגר זה מאורגן כסדרת בלוגים בנוסף לדוגמאות פנקסיות הרצות.

## לפני פתיחת בקשת משיכה

הרץ את סקריפט האימות המקומי:

```powershell
python scripts\verify_notebooks.py
```

בשינויים של יישום או פנקס, הרץ את ההפעלה הבטוחה המקומית של הפנקס:

```powershell
python scripts\verify_notebooks.py --execute
```

## קווי הנחיה לפנקסים

- שמור על הפנקסים קריאים וממוקדים במאמר הרלוונטי.
- אל תבצע קומיט לפלטים שמורים של הפנקס או למספרי הרצה.
- השתמש בנתוני דוגמה קטנים מתוך `sample_data/` אלא אם כן המאמר דורש משאב חיצוני ספציפי.
- רשום תוצאות אימות במאמר הרלוונטי כאשר ההתנהגות משתנה.

## סודות ואישורים

- אל תבצע קומיט למפתחות API, טוקנים, סיסמאות, נקודות קצה פרטיות או קבצי `.env`.
- השתמש ב- `.env.example` רק לערכי מייצג.
- השתמש במשתני סביבה לניסויים מקומיים אופציונליים ב-Ollama.

## תיעוד

- שמור על קישורי הניווט במאמרים מעודכנים.
- עדכן את `README.md` בעת הוספת מאמר חדש, פנקס, קובץ דרישות, או קובץ נתוני דוגמה.
- עדכן את `CHANGELOG.md` לפני פרסום עדכון גלוי של המאגר.

## אימות

זרימת העבודה של GitHub Actions מריצה:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

חומר טיוטה בתיקיית `drafts/` מוּתַּג מעבר עליו על ידי אימות המאגר עד שהוא מוכן לאינדוקס פומבי.

## בעיות

השתמש בתבנית המשוב למאמר לתיקוני מאמר ובתבנית הבעיה של הפנקס לבעיות הרצה.
