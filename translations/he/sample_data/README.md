# נתונים לדוגמה

המחברות משתמשות בקורפוס ציבורי קטן לדוגמה כדי שהדוגמאות יוכלו לפעול ללא מסמכים פרטיים או אישורי ענן.

| קובץ | מטרה |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | מסמך מדיניות בית ספר עם קטעים על מטלות סופיות, בחינות, פרויקטים מחקריים, והחלפות מדריך |
| [course_ai_guidance.md](./course_ai_guidance.md) | מסמך מדריך קורס עם קטעים על שימושים מותרות, גילוי, ציפיות ציטוט, ועבודת צוות |

המסמכים לדוגמה קטנים בכוונה. המטרה שלהם היא להקל על בדיקה של אחזור, מטא-דטה, וציטוטים.
