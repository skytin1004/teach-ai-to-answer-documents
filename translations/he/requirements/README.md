# דרישות

לכל מאמר יישום יש קובץ דרישות ממוקד.

| קובץ | משומש על ידי |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | מחברת RAG קוד פתוח של סידרה 2, כולל עזרי יצירה אופציונליים של Ollama |
| [all.txt](../../../requirements/all.txt) | אימות ברמת המאגר ו-CI |

השתמש בקובץ הממוקד כאשר מפעילים מחברת אחת. השתמש ב-`all.txt` כאשר מאמתים את כל המאגר.

`open-source-rag.txt` ו-`all.txt` כוללים את `fastembed` לאמבדים מקומיים ואת `python-dotenv` כדי שסידרה 2 תוכל לאפשר אופציונלית יצירה של Ollama מ-`.env` ללא שינוי בצינור ההשלכה.
