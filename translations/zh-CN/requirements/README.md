# 要求

每个实现文章都有一个专注的要求文件。

| 文件 | 使用者 |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | 第二系列开源 RAG 笔记本，包括可选的 Ollama 生成辅助 |
| [all.txt](../../../requirements/all.txt) | 仓库级别验证和 CI |

运行单个笔记本时使用专注文件。验证整个仓库时使用 `all.txt`。

`open-source-rag.txt` 和 `all.txt` 包含用于本地嵌入的 `fastembed` 以及用于第二系列可选地从 `.env` 启用 Ollama 生成而无需更改检索管道的 `python-dotenv`。
