# ನಿಮ್ಮ ದಾಖಲೆಗಳ ಆಧಾರದ ಮೇಲೆ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸುವಂತೆ AI ಅನ್ನು ತರಬೇತು ಮಾಡಿ - ಸರಣಿ ಯೋಜನೆ

ಈ ಯೋಜನೆ ಸಾರ್ವಜನಿಕ ಸರಣಿ 1 ಮತ್ತು ಸರಣಿ 2 ಬಿಡುಗಡೆಗಳನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡುತ್ತದೆ. ನಂತರದ Azure ಮತ್ತು ಮೌಲ್ಯಮಾಪನ ಕೆಲಸವನ್ನು ಉದಾಹರಣೆಗಳು ಸಂಪೂರ್ಣ ಅಂತಿಮ-ತುದಿಗೆ ಹಾಗೂ ಪರಿಶೀಲನೆ ಮಾಡಲಾಗುವವರೆಗೆ ಡ್ರಾಫ್ಟ್ ಆಗಿ ಇಡಲಾಗಿದೆ.

ಸ್ಪಷ್ಟವಾಗಿ ಸೂಚಿಸುವವರೆಗೆ ಬದಲಾವಣೆಗಳನ್ನು ಕಮಿಟ್ ಅಥವಾ ಪುಷ್ ಮಾಡಬೇಡಿ.

## ಸಾರ್ವಜನಿಕ ವ್ಯಾಪ್ತಿ

ಪ್ರಸ್ತುತ ಸಾರ್ವಜನಿಕ ಬಿಡುಗಡೆ:

- ಸರಣಿ 1 ಲೇಖನ: RAG معماريಗೆ ಸಂಬಂಧಿಸಿದ ನಿರ್ಧಾರಗಳು, Azure ಮತ್ತು ಮುಕ್ತ ಮೂಲ ವ್ಯಾಪ್ತಿಗಳ ವ್ಯವಹಾರಗಳು, ಮತ್ತು ಸೂಕ್ಷ್ಮಸೂಕ್ಷ್ಮತೆಯ ಸ್ಥಳ.
- ಸರಣಿ 2 ಲೇಖನ: ಸ್ಥಳೀಯ ಮುಕ್ತ ಮೂಲ RAG ಟ್ಯುಟೋರಿಯಲ್.
- ಸರಣಿ 2 ನೋಟ್ ಬುಕ್: FastEmbed, Qdrant, Ollama, ಮತ್ತು Phi-4-mini ಜೊತೆ ರನ್ನೇಬಲ್ ಸ್ಥಳೀಯ RAG ಪ್ರಯೋಗಶಾಲೆ.
- ಮಾದರಿ ಡೇಟಾ: ಶಾಲಾ ನೀತಿ ಮತ್ತು ಕೋರ್ಸ್ AI ಮಾರ್ಗದರ್ಶನ Markdown ಫೈಲುಗಳು.

ಡ್ರಾಫ್ಟ್ ಆಗಿದ್ದು, ಇನ್ನೂ ಸಾರ್ವಜನಿಕ ಸೂಚ್ಯಂಕದಲ್ಲಿ ಇಲ್ಲ:

- Azure AI Search ಮತ್ತು Azure OpenAI ಮರುನಿರ್ಮಾಣ.
- RAG ಮೌಲ್ಯಮಾಪನ ಮತ್ತು ರಿಗ್ರೆಷನ್ ಪರಿಶೀಲನೆಗಳು.

## ಟ್ಯುಟೋರಿಯಲ್ ದೃಶ್ಯ

ಹಂಚಿಕೊಂಡಿರುವ ದೃಶ್ಯವು ಶಾಲಾ ನೀತಿ ಸಹಾಯಕನಾಗಿದೆ.

ಸಹಾಯಕನು ಸ್ಥಳೀಯ ದಾಖಲೆಗಳಿಂದ ಈ ಪ್ರಶ್ನೆಗೆ ಉತ್ತರಿಸುತ್ತಾನೆ:

```text
Can I use generative AI for my final assignment?
```
  
ನಿರೀಕ್ಷಿತ ನಡವಳಿ:

1. ಸ್ಥಳೀಯ Markdown ದಾಖಲೆಗಳನ್ನು ಲೋಡ್ ಮಾಡುವುದು.  
2. ಶೀರ್ಷಿಕೆಗಳ ಪ್ರಕಾರ ಅವುಗಳನ್ನು ಪಾರ್ಸ್ ಮತ್ತು ಚಂಕ್ ಮಾಡುವುದು.  
3. ಸ್ಥಳೀಯ ಎम्बೆಡ್ಡಿಂಗ್ಸ್ ರಚಿಸಿ ಮತ್ತು ಮೆಟಾಡೇಟಾ ಸಹಿತ ಹುಡುಕಬಹುದಾದ ಪ್ರತಿನಿಧಿಗಳನ್ನು ಸಂಗ್ರಹಿಸುವುದು.  
4. ಸಂಬಂಧಿತ ನೀತಿ ವಿಭಾಗವನ್ನು ಪುನಃಆಹರಿಸುವುದು.  
5. ಅಗತ್ಯವಿದ್ದಾಗ ಪುನಃರ‍್ಯಾಂಕ್ ಮಾಡುವುದು.  
6. ಆಧಾರದ ಮೇಲೆ ಉತ್ತರವನ್ನು ರಚಿಸುವುದು ಅಥವಾ ಸಂಯೋಜಿಸುವುದು.  
7. ಉಲ್ಲೇಖಗಳನ್ನು ಹಿಂತಿರುಗಿಸುವುದು.  
8. ಪರಿಶೀಲನೆ ಫಲಿತಾಂಶಗಳನ್ನು ದಾಖಲಿಸುವುದು.

## ಸರಣಿ 2 ಪರಿಶೀಲನೆ

Python 3.12.6 ಜೊತೆ Windows ನಲ್ಲಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ.

- `requirements/open-source-rag.txt` ಯಶಸ್ವಿಯಾಗಿ ಸ್ಥಾಪಿಸಲಾಗಿದೆ.  
- `notebooks/series-2-open-source-rag.ipynb` ಅನ್ನು `nbclient` ಜೊತೆ ಕಾರ್ಯನಿರ್ವಹಿಸಲಾಗಿದೆ.  
- ಸ್ಥಳೀಯ ಪರಿಶೀಲನೆ ಉತಿಯಿಂದ: 2 ಮಾದರಿ ದಾಖಲೆಗಳು ಲೋಡ್, 8 ಚಂಕ್‌ಗಳು ರಚನೆ, FastEmbed ಮೂಲಕ 384-ಮಾಪಕ ಸ್ಥಳೀಯ ಎम्बೆಡ್ಡಿಂಗ್ಸ್ ರಚನೆ, Qdrant ಸ್ಮರಣೆ ಸಂಗ್ರಹಣಾ ಸಂಗ್ರಹಣೆ ಪ್ರಾರಂಭ, ಮತ್ತು 8 ವೆಕ್ಟರ್‌ಗಳು ಸೇರಿಸಲಾಗಿದೆ.  
- ಪರೀಕ್ಷಾ ಪ್ರಶ್ನೆ: "ನಾನು ನನ್ನ ಅಂತಿಮ ನಿಯೋಜನೆಗೆ ಜನರೇಟಿವ್ AI ಬಳಸಬಹುದಾ?"  
- ತೂಕಮಟ್ಟದಲ್ಲಿ ಪುನಃರ‍್ಯಾಂಕಿಂಗ್ ನಂತರ ಅಗ್ರ ದರ್ಜೆಯ ಮೂಲ: `school_ai_policy.md`.  
- ತೂಕಮಟ್ಟದಲ್ಲಿ ಪುನಃರ‍್ಯಾಂಕಿಂಗ್ ನಂತರ ಅಗ್ರ ವಿಭಾಗ: `Final Assignments`.  
- ಡೀಫಾಲ್ಟ್ ಉತ್ತರ ಮಾರ್ಗ: ಸ್ಥಳೀಯ ಪಾರದರ್ಶಕ ಉತ್ತರ ರಚನಕಾರ.  
- Ollama ಅನ್ನು winget ಮೂಲಕ ಸ್ಥಾಪಿಸಲಾಗಿದೆ; `phi4-mini:3.8b` ಯಶಸ್ವಿಯಾಗಿ ಪತ್ತೆಯಾಗಿತ್ತಿದೆ.  
- Ollama ಉತ್ತರ-ಉತ್ಪಾದನಾ ಮಾರ್ಗ: `phi4-mini:3.8b` ಮೂಲಕ ಪೂರ್ಣಗೊಂಡಿತು.  
- Ollama ಮಾದರಿ ಫೈಲ್ ಗಾತ್ರ: ಡಿಸ್ಕ್‌ನಲ್ಲಿ ಸುಮಾರು 2.49GB.  
- Ollama ಲೋಡ್ ಮಾಡಲಾದ ಮಾದರಿ ಗಾತ್ರ: `ollama ps` ನಿಂದ ವರದಿ ಮಾಡಿದಂತೆ 3.3GB.  
- GPU ಡಿಸ್ಫೋಲ್ಡ್: RTX 3060 ಲ್ಯಾಪ್‌ಟಾಪ್ GPU ಮೇಲೆ `ollama ps` ನಿಂದ 100% GPU ವರದಿ.  
- ಉತ್ಪಾದನೆಯ ನಂತರ GPU ಸ್ಮೃತಿ ಗಮನಿಸಲಾಯಿತು: 6GB ನಲ್ಲಿ ಸುಮಾರು 3.5GB.  
- ಕ್ಯಾಶೆ ಮಾಡಲಾದ FastEmbed ಮಾದರಿ ಮತ್ತು Ollama ಉತ್ಪಾದನೆಯೊಂದಿಗೆ ನೋಟ್ ಬುಕ್ ನ ಕಾರ್ಯಾಚರಣೆ ಪರಿಶೀಲನೆ ಸ್ಕ್ರಿಪ್ಟ್ ಮೂಲಕ ಸುಮಾರು 34 ಸೆಕೆಂಡುಗಳಲ್ಲಿ ಯಶಸ್ವಿಯಾಗಿ ಮುಗಿದಿದೆ.  
- ಗಮನಿಸಲು: ಪ್ರಾರಂಭಿಕ ದಾಖಲೆ ಲೋಡಿಂಗ್ ಸಮಯದಲ್ಲಿ ತಪ್ಪಾಗಿ `sample_data/README.md` ಸೇರಲಾಯಿತು; ಈಗ ನೋಟ್ ಬುಕ್ ಸ್ಪಷ್ಟವಾಗಿ ಸರ್ವೆ ದಾಖಲಾತಿಗಳನ್ನು ಮಾತ್ರ ಲೋಡ್ ಮಾಡುತ್ತದೆ.

## ರೆಪೊಸಿಟರಿ ಪರಿಶೀಲನೆ

- `scripts/verify_notebooks.py` ಸ್ಥಳೀಯ Markdown ಲಿಂಕ್‌ಗಳು, ನೋಟ್ ಬುಕ್ JSON, ನೋಟ್ಬುಕ್ ನಿಷ್ಕರ್ಷಾ ಶುದ್ಧತೆ, ಮತ್ತು ಅಪಾಯದ ಉನ್ನತ ರಹಸ್ಯ ಮಾದರಿಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ.  
- `scripts/verify_notebooks.py --execute` ಸಾರ್ವಜನಿಕ ನೋಟ್ ಬುಕ್‌ಗಳನ್ನು ರೆಪೊಸಿಟರಿ ರೂಟ್‌ನಿಂದ ನಡೆಸುತ್ತದೆ.  
- `drafts/` ಅಡಿಯಲ್ಲಿ ಇರುವ ಡ್ರಾಫ್ಟ್ ವಸ್ತುಗಳನ್ನು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಹೊರಗಾಗಿಸಲಾಗಿದೆ.

## ಮುಂದಿನ ಕೆಲಸ

- ನಂತರದ ಸರಣಿ ಭಾಗವಾಗಿ Azure AI Search ಮತ್ತು Azure OpenAI ಜೊತೆ ಇದೇ ದೃಶ್ಯವನ್ನು ಮರುನಿರ್ಮಿಸುವುದು.  
- ಸ್ಥಳೀಯ ಮತ್ತು Azure ಜಾರಿಗೆ ಸ್ಥಿರವಾಗುವಾಗ ರಿಟ್ರೀವಲ್ ಮತ್ತು ಉತ್ತರ ಮೌಲ್ಯಮಾಪನವನ್ನು ಸೇರಿಸುವುದು.
