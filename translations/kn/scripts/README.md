# Scripts

ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ರೆಪೊಸಿಟರಿ ಪರಿಶೀಲನೆ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ఉన్నాయి.

## `verify_notebooks.py`

ಸ್ಥಳೀಯ ಮಾರ್ಕ್‌ಡೌನ್ ಲಿಂಕ್‌ಗಳು, ನೋಟ್‌ಬుక్ JSON, ನೋಟ್‌ಬುಕ್ ಫಲಿತಾಂಶದ ಶುದ್ಧತೆ ಮತ್ತು ಉನ್ನತ-ಧರ್ಮ खतellijಿಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ:

```powershell
python scripts\verify_notebooks.py
```

ಎಲ್ಲಾ ಸಾರ್ವಜನಿಕ ಸ್ಥಳೀಯ-ಬೇಸರದ ನೋಟ್‌ಬುಕ್‌ಗಳನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುತ್ತದೆ:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub ಕ್ರಮಗಳು ಕಾರ್ಯನಿರ್ವಹಿಸಲು ಇದೇ ಸ್ಕ್ರಿಪ್ಟ್ ಬಳಕೆಮಾಡಲಾಗುತ್ತದೆ.

`drafts/` ಅಡಿಯಲ್ಲಿ ಪ್ರಕ್ರಿಯೆಯ ಸರಕಳನ್ನು ಜಾರಿಗೆ ಬಂದ ನಂತರ ಪಬ್ಲಿಕ್ ಸೂಚಕಿಗೆ ಸಿದ್ಧವಾಗುವವರೆಗೆ ಬಿಟ್ಟಿಡಲಾಗುತ್ತದೆ.
