# ಅವಶ್ಯಕತೆಗಳು

ಪ್ರತಿ ಅನುಷ್ಠಾನ հոդվածದಲ್ಲಿ ಕೇಂದ್ರೀಕೃತ ಅಗತ್ಯಗಳ ಫೈಲ್ ಇರುತ್ತದೆ.

| ಫೈಲ್ | ಬಳಕೆದಾರರು |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | ಸರಣೀ 2 मुक्त ಮೂಲ RAG ನೋಟ್ ಬುಕ, ಆಯ್ಕೆಯಾಜ್ಞಾಮೂಲಕ ಒಲ್ಲಾಮಾ ನಿರ್ಮಾಣ ಸಹಾಯಕರೊಂದಿಗೆ |
| [all.txt](../../../requirements/all.txt) | ಸಂಗ್ರಹಾಲಯ-ಮಟ್ಟದ ಪರಿಶೀಲನೆ ಮತ್ತು CI |

ಎರಡು ಮಧ್ಯೆ ಇರುವ ಫೈಲ್ ಅನ್ನು ಒಂದು ನೋಟ್ ಬುಕ್ ಓಡಿಸುವಾಗ ಬಳಸಿ. ಸಕಲ ಸಂಗ್ರಹಾಲಯವನ್ನು ಮಾನ್ಯಗೊಳಿಸಲು `all.txt` ಅನ್ನು ಬಳಸಿ.

`open-source-rag.txt` ಮತ್ತು `all.txt` ನಲ್ಲಿ ಸ್ಥಳೀಯ ಎಮ್ಬೆಡ್ಡಿಂಗ್ಸ್ ಗೆ `fastembed` ಮತ್ತು ಸೀರೀಸ್ 2 ಆಯ್ಕೆಯಾಗಿ `.env` ಮೂಲಕ ಒಲ್ಲಾಮಾ ನಿರ್ಮಾಣವನ್ನು ಅನುಮತಿಸಲು `python-dotenv` ಅನ್ನು ಸೇರಿಸಿರುವುದು ಇದೆ, ಇದು ರಿಟ್ರೀವಲ್ ಪೈಪ್ಲೈನ್ ಗೆ ಬದಲಾವಣೆ ಮಾಡದೆ ಸಾಧ್ಯವಾಗುತ್ತದೆ.
