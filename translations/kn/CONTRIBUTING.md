# ಕೊಡುಗೆ ನೀಡುವುದು

ಈ ಸಂಗ್ರಹವು ಒಂದು ಬ್ಲಾಗ್ ಸರಣಿಯಾಗಿ ಮತ್ತು ಚಾಲನೆ ಮಾಡಬಹುದಾದ ನೋಟ್ಬುಕ್ ಉದಾಹರಣೆಗಳಾಗಿ ಆಯೋಜಿಸಲಾಗಿದೆ.

## ಪుల్ ರಿಕೆಸ್ಟ್ ತೆರೆಯುವ ಮೊದಲು

ಸ್ಥಳೀಯ ತಪಾಸಣೆ ಸ್ಕ್ರಿಪ್ಟ್ ಅನ್ನು ಚಲಾಯಿಸಿ:

```powershell
python scripts\verify_notebooks.py
```

ನಿರ್ವಹಣೆ ಅಥವಾ ನೋಟ್ಬುಕ್ ಬದಲಾವಣೆಗಳಿಗೆ, ಸ್ಥಳೀಯ-ಭದ್ರ ನೋಟ್ಬುಕ್ ನಿರ್ವಹಣೆಯನ್ನು ಚಲಾಯಿಸಿ:

```powershell
python scripts\verify_notebooks.py --execute
```

## ನೋಟ್ಬುಕ್ ಮಾರ್ಗಸೂಚಿಗಳು

- ನೋಟ್ಬುಕ್‌ಗಳನ್ನು ಓದಲು ಸಾಧ್ಯವಾಗುವಂತೆಯೂ ಸಂಬಂಧಿತ ಲೇಖನದ ಮೇಲೆ ಕೆಂದ್ರಿತವಾಗಿಯೂ ಇಡಿರಿ.
- ಸಂರಕ್ಷಿಸಲಾದ ನೋಟ್ಬುಕ್ ಔಟ್‌ಪುಟ್‌ಗಳು ಅಥವಾ ಕಾರ್ಯಾಚರಣಾ ಎಣಿಕೆಗಳನ್ನು ಸಮರ್ಪಿಸಬೇಡಿ.
- `sample_data/` ನಿಂದ ಸಣ್ಣ ಮಾದರಿ ಡೇಟಾವನ್ನು ಬಳಸಿ, ಲೇಖನವು ನಿರ್ದಿಷ್ಟ ಹೊರಗಿನ ಸಂಪನ್ಮೂಲವನ್ನು ಬೇಡಿಕೊಳ್ಳದಿದ್ದರೆ ಮಾತ್ರ.
- ವರ್ತನೆ ಬದಲಾದಾಗ ಪರಿಶೋಧನಾ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಬಂಧಿತ ಲೇಖನದಲ್ಲಿ ದಾಖಲಿಸಿ.

## ರಹಸ್ಯங்கள் ಮತ್ತು ಪ್ರಮಾಣಪತ್ರಗಳು

- API ಕೀಲಿಗಳು, ಟೋಕನ್‌ಗಳು, ಪಾಸ್‌ವರ್ಡ್‌ಗಳು, ಖಾಸಗಿ ಅಂತಿಮ ಬಿಂದುಗಳು ಅಥವಾ `.env` ಕಡತಗಳನ್ನು ಸಮರ್ಪಿಸಬೇಡಿ.
- `.env.example` ಅನ್ನು ಮಾತ್ರ ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್ ಮೌಲ್ಯಗಳಿಗಾಗಿ ಬಳಸಿ.
- ಐಚ್ಛಿಕ ಸ್ಥಳೀಯ Ollama ಪ್ರಯೋಗಗಳಿಗೆ ಪರಿಸರ ಚರಗಳನ್ನೇ ಬಳಸಿ.

## ಡಾಕ್ಯುಮೆಂಟೇಶನ್

- ಲೇಖನ ನಾವಿಗೇಶನ್ ಲಿಂಕುಗಳನ್ನು ನವೀಕರಿಸಿ ಇಡಿ.
- ಹೊಸ ಲೇಖನ, ನೋಟ್ಬುಕ್, ಅವಶ್ಯಕತೆಗಳ ಕಡತ ಅಥವಾ ಮಾದರಿ ಡೇಟಾ ಕಡತ ಸೇರಿಸಿದಾಗ `README.md` ನವೀಕರಿಸಿ.
- ಕಣ್ತುಂಬುರುವ ಸಂಗ್ರಹ ನವೀಕರಣವನ್ನು ಪ್ರಕಟಿಸುವ ಮೊದಲು `CHANGELOG.md` ನವೀಕರಿಸಿ.

## ಪರಿಶೀಲನೆ

GitHub Actions ವರ್ಕ್‌ಫ್ಲೋ ಈ ಕೆಳಗಿನಂತೆ ಚಾಲನೆಮಾಡುತ್ತದೆ:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` ಅಡಿಯಲ್ಲಿ ಇರುವ ರುಕ್ವಾಳದ ಸಾಮಗ್ರಿ ಸಾರ್ವಜನಿಕ ಸೂಚ್ಯಂಕಕ್ಕಾಗಿ ಸಿದ್ಧವಾಗುವ ತನಕ ಸಂಗ್ರಹ ಪರಿಶೀಲನೆ ಮಾಡುವಾಗ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ.

## ಸಮಸ್ಯೆಗಳು

ಲೇಖನ ತಿದ್ದುಪಡಿ ಗಾಗಿ ಲೇಖನ ಪ್ರತಿಕ್ರಿಯಾ ನಮೂನೆಯನ್ನು ಮತ್ತು ನೋಟ್ಬುಕ್ ನಿರ್ವಹಣಾ ಸಮಸ್ಯೆಗಳಿಗೆ ನೋಟ್ಬುಕ್ ಸಮಸ್ಯೆ ನಮೂನೆಯನ್ನು ಬಳಸಿ.
