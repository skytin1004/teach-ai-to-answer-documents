# ನಿಮ್ಮ ಡಾಕ್ಯುಮೆಂಟ್‌ಗಳ ಆಧಾರದ ಮೇಲೆ AI ಯಿಂದ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸುವಂತೆ ಕಲಿಸು

![ದಾಖಲೆ-ನಿರ್ಮಿತ AI RAG ವ್ಯವಸ್ಥೆಯ ಅವಲೋಕನ](../../assets/images/readme-hero.svg)

ಈ ರೆಪೊಸಿಟರಿ RAG, Azure AI ಸರ್ವೀಸ್‌ಗಳು, ಓಪನ್-ಸೋರ್ಸ್ ಪರ್ಯಾಯಗಳು ಮತ್ತು ಮೌಲ್ಯಮಾಪನ-ಕೇಂದ್ರೀಕೃತ ಕೆಲಸದ ನಡವಳಿಕೆಗಳೊಂದಿಗೆ ಡಾಕ್ಯುಮೆಂಟ್-ನಿರ್ಮಿತ AI ವ್ಯವಸ್ಥೆಗಳನ್ನು ನಿರ್ಮಿಸುವ ಬಗ್ಗೆ 2026 ರಲ್ಲಿ ಪ್ರಕಟಿತ ಬ್ಲಾಗ್ ಸರಣಿಯನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ.

## ಹಿನ್ನೆಲೆ

2023 ರಲ್ಲಿ, ನಾನು Azure AI Search ಮತ್ತು Azure OpenAI ಬಳಸಿ PDF ದಾಖಲೆಗಳಿಂದ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸುವಂತೆ ChatGPT ಅನ್ನು ಕಲಿಸುವ ಎರಡು ಟ್ಯುಟೋರಿಯಲ್‌ಗಳ ಮೇಲೆ ಕೆಲಸ ಮಾಡಿದ್ದೆ. "ನಿನ್ನ ಡೇಟಾದ ಮೇಲಿನ ChatGPT" ಎಂದು ಆ ಕಲ್ಪನೆ ಆಗಾಗೆ ಹೊಸದಾಗಿ ಭಾಸವಾಗಿತ್ತು, ಮತ್ತು ಗುರಿ ಪ್ರಾಯೋಗಿಕ ಕೆಲಸದನಡವಳಿಕೆಯನ್ನು ತೋರಿಸುವುದು: ದಾಖಲೆಗಳನ್ನು ಸಂಗ್ರಹಿಸು, ಅವುಗಳನ್ನು ಸೂಚೀಪತ್ರ (index) ಮಾಡು, ಸಂಬಂಧಿತ ವಿಷಯವನ್ನು ಪಡೆಯು ಮತ್ತು ಆ ಪಡೆದಿರುವ ಸಾಂದರ್ಭದಿಂದ ಉತ್ತರಗಳನ್ನು ರಚಿಸು.

2026 ರಲ್ಲಿ, RAG ಪರಿಸರ ವ್ಯಾಪಕವಾಗಿದೆ. Azure AI Search ಆಧುನಿಕ ವೆಕ್ಟರ್ ಮತ್ತು ಸಂಯುಕ್ತ ವಾಪಾಸು ಮಾದರಿಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ, Azure OpenAI Microsoft Foundry Models ಪರಿಸರದ ಒಂದು ಭಾಗವಾಗಿದೆ, ಮತ್ತು LangGraph, LlamaIndex, Haystack, Qdrant, Milvus, Weaviate, Chroma, Ollama, ಮತ್ತು vLLM ಮುಂತಾದ ಓಪನ್-ಸೋರ್ಸ್ ಉಪಕರಣಗಳು ನಿಜವಾದ ವ್ಯವಸ್ಥೆಗಳಿಗೆ ಪ್ರಾಯೋಗಿಕ ಆಯ್ಕೆಯಾಗಿ ಬದಲಾಗಿದೆ.

ಆದಕ್ಕಾಗಿ ನಾನು ಈ ವಿಷಯವನ್ನು ಮರುಪರಿಶೀಲಿಸಲು ಬಯಸಿದೆ. ಪ್ರಶ್ನೆ ಈಗ "ನಾನು ಹೇಗೆ RAG ನಿರ್ಮಿಸಬಹುದು?" ಮಾತ್ರವಲ್ಲ. ಈಗ ಅದನ್ನು ನಿರ್ಮಿಸಲು ಅನೇಕ ಮಾರ್ಗಗಳಿವೆ, ಮತ್ತು ಪ್ರಮುಖವಾದ ಪ್ರಶ್ನೆ "ನನ್ನ ಪರಿಸ್ಥಿತಿಗೆ ಯಾವ ವಿನ್ಯಾಸ ಸರಿಹೊಂದುತ್ತದೆ?" ಎಂಬುದು.

ಈ ಸರಣಿ ಆ ನಿರ್ಧಾರ ತೆಗೆದುಕೊಳ್ಳುವ ಹಂತದಿಂದ ಆರಂಭಿಸಿ, ನಂತರ ಅದನ್ನು ಕೈಗೆ ಕೈ ಅನುಷ್ಠಾನಗಳಾಗಿ ರೂಪಿಸುತ್ತದೆ. ಮೊದಲ ಅನುಷ್ಠಾನ ಮಾರ್ಗವು ಸ್ಥಳೀಯ ಓಪನ್-ಸೋರ್ಸ್ RAG ವ್ಯವಸ್ಥೆಯನ್ನು ನಿರ್ಮಿಸುತ್ತದೆ, ಇದನ್ನು ಯಾರೂ ಬೇಕಾದರೆ ಮಾದರಿ ಡೇಟಾ, Qdrant, Ollama ಮತ್ತು Phi-4-mini ಬಳಸಿ ಸಂಚಾಲಿಸಬಹುದು.

## ಸ್ಥಳೀಯ ಪರಿಶೀಲನೆ ಸಮ್ಮೇಳಿ

ಪರಿಶೀಲನೆ ಫಲಿತಾಂಶಗಳನ್ನು ಪ್ರತಿ ಲೇಖನದಲ್ಲಿಯೂ ಮತ್ತು [SERIES_PLAN.md](./SERIES_PLAN.md) ನಲ್ಲಿ ದಾಖಲಿಸಲಾಗುತ್ತದೆ.

| ವಲಯ | ಫಲಿತಾಂಶ |
| --- | --- |
| ಸರಣಿ 2 ಓಪನ್-ಸೋರ್ಸ್ ಮಾರ್ಗ | FastEmbed 384-ಆಯಾಮದ ಸ್ಥಳೀಯ ಎम्बೆಡಿಂಗ್‌ಗಳನ್ನು ನಿರ್ಮಿಸಿದೆ, Qdrant ನಲ್ಲಿ 8 ವೆಕ್ಟರ್‌ಗಳು ಸಂಗ್ರಹಿಸಲ್ಪಟ್ಟವು, ಲಘು-ತೂಕ ಮರುವರ್ಗೀಕರಣ ನಿರೀಕ್ಷಿತ ವಿಭಾಗವನ್ನು ಪಡೆದುಕೊಂಡಿತು; ಐಚ್ಛಿಕ Ollama ಉತ್ಪಾದನೆ `phi4-mini:3.8b` ಬಳಸಿ ಪೂರ್ಣಗೊಂಡಿತು |

## ಸ್ಥಳೀಯ Ollama ಉತ್ಪಾದನೆ

ಸರಣಿ 2 ನೋಟ್ಬುಕ್ ಡಿಫಾಲ್ಟ್ ಮೂಲಕ ಸ್ಥಳೀಯವಾಗಿ ಸುರಕ್ಷಿತವಾಗಿದೆ. ಸ್ಥಳೀಯ Ollama ಉತ್ಪಾದನೆಗೆ, [.env.example](../../.env.example) ಅನ್ನು `.env` ಗೆ ನಕಲಿಸಿ, ಸರಣಿ 2 ಯ ಮೌಲ್ಯಗಳನ್ನು ಭರ್ತಿ ಮಾಡಿ.

ಸರಣಿ 2 Ollama ಉತ್ಪಾದನೆಗೆ, ಕಾಮೆಂಟ್ ತೆರವುಗೊಳಿಸಿ:

```text
SERIES2_OLLAMA_BASE_URL=http://localhost:11434
SERIES2_OLLAMA_MODEL=phi4-mini:3.8b
```

ಸರಣಿ 2 ನೋಟ್ಬುಕ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ರೆಪೊ ರೋಟ್ನಿಂದ `.env` ಅನ್ನು `python-dotenv` ಬಳಸಿ ಲೋಡ್ ಮಾಡುತ್ತದೆ.

> [!IMPORTANT]
> `.env` ಫೈಲ್‌ಗಳು, API ಕೀಗಳು, ಖಾಸಗಿ ಅಂತಿಮತೆಗಳು ಅಥವಾ ಟೆನಂಟ್-ವಿಶೇಷ ಮೌಲ್ಯಗಳನ್ನು ಕಮಿಟ್ ಮಾಡಬೇಡಿ. ಈ ರೆಪೊ ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ Markdown ಫೈಲ್‌ಗಳ ಮತ್ತು ನೋಟ್ಬುಕ್‌ಗಳ ರಹಸ್ಯಗಳನ್ನು ಹೊರತಾಗಿರಿಸುತ್ತದೆ.

ಆವಶ್ಯಕತೆಗಳ ಫೈಲ್‌ಗಳು [requirements/README.md](./requirements/README.md) ನಲ್ಲಿ ದಾಖಲಾಗಿದೆ.

ಲಿಂಕುಗಳು, ನೋಟ್ಬುಕ್ ರಚನೆ, ನೋಟ್ಬುಕ್ ಔಟ್‌ಪುಟ್ ಸ್ವಚ್ಛತೆ ಮತ್ತು ಹೆಚ್ಚಿನ-ರಿಸ್ಕ್ ರಹಸ್ಯ ಆಕಾರಗಳನ್ನು ಮಾನ್ಯಮಾಡಲು:

```powershell
python -m venv .venv-verify
.\.venv-verify\Scripts\activate
python -m pip install -r requirements\all.txt
python scripts\verify_notebooks.py
```

ಪರಿಶೀಲನಾ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು [scripts/README.md](./scripts/README.md) ನಲ್ಲಿ ದಾಖಲಾಗಿವೆ.

ಒಂದು ಪರಿಸರದಲ್ಲಿ ಎಲ್ಲಾ ಸ್ಥಳೀಯ ಸುರಕ್ಷಿತ ನೋಟ್ಬುಕ್‌ಗಳನ್ನು ನಡೆಸಲು:

```powershell
python scripts\verify_notebooks.py --execute
```

ಈ ಪರಿಕ್ಷಣ ಪ್ರಕ್ರಿಯೆ GitHub Actions ನಲ್ಲಿ ಪುಷ್‌ಗಳು, ಪುಲ್‌ ವಿನಂತಿಗಳು ಮತ್ತು ಕೈಯಿಂದ ಕಾರ್ಯಾಚರಣೆಗಳನ್ನು ವೈದ್ಯವಾದಂತೆ ನಡೆಸುತ್ತದೆ. ಪ್ರಾರಂಭಿಕ ಲೇಖನಗಳು ಮತ್ತು ನೋಟ್ಬುಕ್‌ಗಳನ್ನು ಸಾರ್ವಜನಿಕ ಪರಿಶೀಲನಾ ಮಾರ್ಗದಿಂದ ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಹೊರತುಪಡಿಸಲಾಗಿದೆ.

ನವೀಕರಣಗಳನ್ನು ಪ್ರಕಟಿಸುವ ಮೊದಲು [PUBLISHING_CHECKLIST.md](./PUBLISHING_CHECKLIST.md) ಅನ್ನು ಬಳಸಿ.

> **ಸ್ಥಳೀಯವಾಗಿ ಕ್ಲೋನ್ ಮಾಡಬೇಕೆ?**
>
> ಈ ರೆಪೊ 50+ ಭಾಷಾ ಅನುವಾದಗಳನ್ನು ಒಳಗೊಂಡಿದೆ, ಇದು ಡೌನ್‌ಲೋಡ್ ಗಾತ್ರವನ್ನು ಬಹಳ ಹೆಚ್ಚಿಸುತ್ತದೆ. ಅನುವಾದಗಳಿಲ್ಲದೆ ಕ್ಲೋನ್ ಮಾಡಲು sparse checkout ಅನ್ನು ಬಳಸಿ:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> ಇದರಿಂದ ನಿಮಗೆ ಕೋರ್ಸ್ ಮುಗಿಸಲು ಬೇಕಾದ ಎಲ್ಲವೂ ಲಭ್ಯವಿರುತ್ತದೆ ಮತ್ತು ಡೌನ್‌ಲೋಡ್ ವೇಗವೂ ಹೆಚ್ಚು.
