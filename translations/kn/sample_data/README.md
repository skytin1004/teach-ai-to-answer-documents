# ಮಾದರಿ ಡೇಟಾ

ಮಾಹಿತಿ ಪತ್ರಿಕೆಗಳು ಖಾಸಗಿ ದಾಖಲೆಗಳು ಅಥವಾ ಕ್ಲೌಡ್ ಪರಿಶೀಲನೆಗಳಿಲ್ಲದೇ ಉದಾಹರಣೆಗಳು ನಡೆಯಲು ಅಲ್ಪ ಪ್ರಮಾಣದ ಸಾರ್ವಜನಿಕ ಮಾದರಿ ಸಂಗ್ರಹವನ್ನು ಬಳಸುತ್ತವೆ.

| ಕಡತ | ಉದ್ದೇಶ |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | ಅಂತಿಮ ಕೆಲಸಗಳು, ಪರೀಕ್ಷೆಗಳು, ಸಂಶೋಧನಾ ಯೋಜನೆಗಳು ಮತ್ತು ಶಿಕ್ಷಕನ ಮರುನಿರ್ಣಯಗಳ ಕುರಿತು ವಿಭಾಗಗಳಿರುವ ಶಾಲಾ ನೀತಿ ದಾಖಲೆ |
| [course_ai_guidance.md](./course_ai_guidance.md) | ಅನುಮತಿಸಲ್ಪಟ್ಟ ಬಳಕೆ, ಬಹಿರಂಗಪಡಿಸುವಿಕೆ, ಉಲ್ಲೇಖ ನಿರೀಕ್ಷೆಗಳು ಮತ್ತು ಗುಂಪು ಕೆಲಸದ ಬಗ್ಗೆ ವಿಭಾಗಗಳಿರುವ ಕೋರ್ಸ್ ಮಾರ್ಗದರ್ಶಕ ದಾಖಲೆ |

ಮಾದರಿ ದಾಖಲೆಗಳು ಇಚ್ಛಾಯಿತವಾಗಿ ಸಣ್ಣ ಪ್ರಮಾಣದಲ್ಲಿವೆ. ಅವು ಸಂಗ್ರಹಣೆ, ಮೆಟಾಡೇಟಾ ಮತ್ತು ಉಲ್ಲೇಖಗಳನ್ನು ಸುಲಭವಾಗಿ ಪರಿಶೀಲಿಸಲು ಉದ್ದೇಶಿಸಲಾಗಿದೆ.
