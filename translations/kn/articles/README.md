# ಲೇಖನಗಳು

ಈ ಫೋಲ್ಡರ್ ಮಾರ್ಕ್‌ಡೌನ್ ಲೇಖನ ಸರಣಿಯನ್ನು ಒಳಗೊಂಡಿದೆ.

| ಸರಣಿ | ಲೇಖನ | ಗಮನಾಲಯ |
| --- | --- | --- |
| ಸರಣಿ 1 | [RAG, ಅಜೂರ್ vs ಓಪನ್-ಸೋರ್ಸ್ ಪರ್ಯಾಯಗಳು, ಮತ್ತು ಫೈನ್-ಟೂನಿಂಗ್ ಎಡೆಗೆ ಸಾಧ್ಯವಾಗುವಾಗ](./series-1-rag-azure-open-source-fine-tuning.md) | ಡಾಕ್ಯುಮೆಂಟ್-ಆಧಾರಿತ AI ವ್ಯವಸ್ಥೆಗಳ ನಿರ್ಧಾರ ಚಟುವಟಿಕೆ |
| ಸರಣಿ 2 | [ಸ್ಥಳೀಯ ಓಪನ್-ಸೋರ್ಸ್ RAG ವ್ಯವಸ್ಥೆಯನ್ನು ಆರಂಭದಿಂದ ಮುಗಿಸಿದಾಗ](./series-2-open-source-rag-end-to-end.md) | ಸ್ಥಳೀಯ ಮಾದರಿ ಡಾಕ್ಯುಮೆಂಟ್‌ಗಳು, Qdrant ಸ್ಥಳೀಯ ಮೋಡ್, ಪುನರ್ ಪಡೆದುಕೊಳ್ಳುವುದು, ಮರುಶ್ರೇಣೀಕರಣ, ಮತ್ತು ಮೂಲ ಸಂಪರ್ಕ |

ಸರಣಿ 3 ಮತ್ತು ಬಳಿಕದ ಭಾಗಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಅಭಿವೃದ್ಧಿಪಡಿಸಲಾಗುತ್ತಿದೆ ಮತ್ತು ಅವು ಈಗಾಗಲೇ ಪ್ರಸ್ತುತ ಸಾರ್ವಜನಿಕ ಸೂಚಿಯಲ್ಲಿ ಭಾಗವಿಲ್ಲ.
