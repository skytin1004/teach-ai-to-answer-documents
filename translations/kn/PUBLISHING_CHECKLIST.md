# ಪ್ರಕಟಿಸುವ ಪರಿಶೀಲನಾ ಪಟ್ಟಿ

ಸರಕಾರಿ ನವೀಕರಣಗಳನ್ನು ನೇಮಕಮಾಡುವುದಕ್ಕೂ ಅಥವಾ ತಳ್ಳುವುದಕ್ಕೂ ಮುಂಚೆ ಈ ಪರಿಶೀಲನಾ ಪಟ್ಟಿಯನ್ನು ಬಳಸಿ.

## ಸುರಕ್ಷತೆ

- ಯಾವುದೇ API ಕಿಗಳು, ಟೋಕನ್‌ಗಳು, ಗುಪ್ತಪದಗಳಾಗಿರುವುದು ಅಥವಾ ಖಾಸಗಿ ಅಂತಿಮಬಿಂದುಗಳು Markdown ಕಡತಗಳಲ್ಲಿ, ನೋಟ್‌ಬುಕ್‌ಗಳಲ್ಲಿ, ಮಾದರಿ ಡೇಟಾ ಅಥವಾ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳಲ್ಲಿ ಬರೆಯಲಾಗಿಲ್ಲವೆ ಎಂದು ದೃಢೀಕರಿಸಿ.
- ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಪರಿಸರ ಚರಗಳು ಅಥವಾ ನಿರ್ವಹಿತ ಗುರುತಿನಲ್ಲಿ ಇರಿಸಿ, ನೇಮಕಾಯಿತ ಕಡತಗಳಲ್ಲಿ ಇರಿಸಬೇಡಿ.
- `.env` ಕಡತಗಳನ್ನು ಅಥವಾ ನಿರ್ವಹಿತ ನೋಟ್‌ಬುಕ್ ಪ್ರಕಾಶನ ಫಲಿತಗಳನ್ನು ನೇಮಕಮಾಡಬೇಡಿ.
- `.env.example` ಅನ್ನು ಕೇವಲ ಸ್ಥಾನಪಕ ಪರಿಗಣಿಸಿ.

## ಪರಿಶೀಲನೆ

Repositories ಪರಿಶೀಲನಾ ಸ್ಕ್ರಿಪ್ಟ್ ನಡೆಯಿಸಿ:

```powershell
python scripts\verify_notebooks.py
```

ಕಾರ್ಯಗತಗೊಳಿಸುವ ಬದಲಾವಣೆಗಳನ್ನು ಪ್ರಕಟಿಸುವ ಮುಂಚೆ ಪೂರ್ಣ ಸ್ಥಳೀಯ ಸುರಕ್ಷಿತ ನೋಟ್‌ಬುಕ್ ರನ್ ಮಾಡಿ:

```powershell
python scripts\verify_notebooks.py --execute
```

ನಿರೀಕ್ಷಿತ ಪರಿಶೀಲನೆಗಳು:

- ಸ್ಥಳೀಯ Markdown ಲಿಂಕಗಳು ಸರಿ ಇರಬೇಕು
- ನೋಟ್‌ಬುಕ್ JSON ಮಾನ್ಯತೆ ಪಾಸಾಗಿರಬೇಕು
- ನೋಟ್‌ಬುಕ್‌ಗಳಲ್ಲಿ ಉಳಿಸಿದ ಔಟ್‌ಪುಟ್‌ಗಳು ಅಥವಾ ಕಾರ್ಯಗತಗೊಳಿಸುವ ಎಣಿಕೆಗಳಿದ್ದ ಇಲ್ಲ
- ಹೆಚ್ಚಿನ-ಪರಿಸರ ಗುಪ್ತ ಮಾದರಿ ಸ್ಕ್ಯಾನ್ ಪಾಸಾಗಿರಬೇಕು
- ಸಾರ್ವಜನಿಕ ನೋಟ್‌ಬುಕ್‌ಗಳು ಸ್ಥಳೀಯವಾಗಿ ಕಾರ್ಯಗತಗೊಳ್ಳುತ್ತವೆ
- `drafts/` ಒಳಗಿನ ಕರಡು ವಸ್ತು ಉದ್ದೇಶಿಸಿದಂತೆ ಬಿಟ್ಟುಕೊಡಲಾಗಿದೆ

## ವಿಮರ್ಶೆ

- README ಲೇಖನ ಲಿಂಕ್‌ಗಳು ಗುರಿ ಫೈಲ್‌ಗಳನ್ನು ಸೂಚಿಸುತ್ತಿವೆ ಎಂದು ದೃಢೀಕರಿಸಿ.
- ಪ್ರತಿ ಲೇಖನಕ್ಕೆ ಸಮೂಹ ನಾವಿಗೇಶನ್ ಮತ್ತು ಸಂಬಂಧಿತ ನೋಟ್‌ಬುಕ್ ಲಿಂಕ್‌ಗಳು ಇದ್ದವು ಎಂದು ಖಾತ್ರಿಪಡಿಸಿಕೊಳ್ಳಿ.
- ಕರಡು ವಸ್ತುಗಳು ಇನ್ನೂ ಪ್ರಕಟಣೆಗೆ ಸಿದ್ದವಿಲ್ಲದಿದ್ದರೆ ಸಾರ್ವಜನಿಕ ಸೂಚಿಗಳನ್ನು ಲಿಂಕ್ ಮಾಡಬೇಡಿ.
- GitHub ಸಮಸ್ಯೆಗಳ ಮತ್ತು ಪುಲ್ ವಿನಂತಿಗಳ ಮಾದರಿಗಳು ಇನ್ನೂ ಸಂಗ್ರಹ ಕಾರ್ಯಪ್ರವಾಹಕ್ಕೆ ತಕ್ಕಮಟ್ಟಿಗೆ ಇದ್ದವು ಎಂದು ದೃಢೀಕರಿಸಿ.
- ಲೇಖನದಲ್ಲಿ ಪರಿಶೀಲನೆಯ ಫಲಿತಾಂಶಗಳು ಇತ್ತೀಚಿನ ನೋಟ್‌ಬುಕ್ ಔಟ್‌ಪುಟ್‌ಗೆ ಹೊಂದಿಕೊಂಡಿವೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.
- GitHub Actions ಕಾರ್ಯಪ್ರವಾಹವು ತಳ್ಳುವ ನಂತರ ನಡೆಯುವನೆಂದು ನಿರೀಕ್ಷಿಸಬಹುದು ಎಂದು ದೃಢೀಕರಿಸಿ.
- `CHANGELOG.md` ಪ್ರಕಟಗೊಳಿಸುವ ನವೀಕರಣವನ್ನು ಪ್ರತಿಬಿಂಬಿಸುತ್ತಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಿ.
- `CONTRIBUTING.md` ಇನ್ನೂ ಸಂಗ್ರಹ ಕಾರ್ಯಪ್ರವಾಹಕ್ಕೆ ತಕ್ಕಂತೆ ಇರುತ್ತದೆ ಎಂದು ದೃಢೀಕರಿಸಿ.

## Git

- `git status --short --branch` ಪರಿಶೀಲಿಸಿ.
- `git diff --stat` ಪರಿಶೀಲಿಸಿ.
- ಸ್ಪಷ್ಟವಾಗಿ ಸಿದ್ಧವಾಗಿದ್ದಾಗ ಮಾತ್ರ ನೇಮಕ ಮಾಡಿ ಮತ್ತು ತಳ್ಳಿರಿ.
