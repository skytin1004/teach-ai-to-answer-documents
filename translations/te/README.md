# మీ డాక్యుమెంట్ల ఆధారంగా ప్రశ్నలకు సమాధానం చెప్పడానికి AI నేర్పించండి

ఈ రిపోజిటరీ 2026 బ్లాగు సిరీస్‌ను సేకరిస్తుంది, ఇది RAG, Azure AI సేవలు, ఓపెన్-సోర్స్ ప్రత్యామ్నాయాలు మరియు అంచనా-కేంద్రిత వర్క్‌ఫ్లోలతో డాక్యుమెంట్-ఆధారిత AI సిస్టమ్‌ల నిర్మాణం గురించి ఉంది.

## నేపథ్యం

2023లో, నేను Azure AI సెర్చ్ మరియు Azure OpenAI ఉపయోగించి PDF డాక్యుమెంట్ల నుండి ప్రశ్నలకు ChatGPT ద్వారా సమాధానం చెప్పడం గురించి ఒక జంట ట్యూటోరియల్స్‌పై పని చేసాను. "మీ డేటాపై ChatGPT" అనే ఆలోచన అప్పుడప్పుడు కొత్తగా అనిపించింది, లక్ష్యం ఒక ప్రాక్టికల్ వర్క్‌ఫ్లో చూపించడం: డాక్యుమెంట్లను నిల్వ చేయడం, వాటిని సూచిక వేయడం, సంబంధిత విషయం తిరిగి తెచ్చుకోవడం మరియు ఆ తిరిగి తెచ్చుకున్న సందర్భం నుండి సమాధానాలు సృష్టించడం.

2026లో, RAG పరిసర వాతావరణం చాలా పెద్దదైంది. Azure AI సెర్చ్ ఆధునిక వెక్టర్ మరియు హైబ్రిడ్ రికవరీ ప్యాటర్న్లను మద్దతు ఇస్తుంది, Azure OpenAI Microsoft Foundry Models విస్తృత పరిసర వాతావరణంలో భాగంగా ఉందింది, మరియు LangGraph, LlamaIndex, Haystack, Qdrant, Milvus, Weaviate, Chroma, Ollama, మరియు vLLM వంటి ఓపెన్-సోర్స్ సాధనాలు వాస్తవ సిస్టమ్‌లకు ప్రాక్టికల్ ఎంపికలు అయ్యాయి.

కాబట్టి ఈ అంశాన్ని మళ్ళీ పరిశీలించాలనుకున్నాను. ఇప్పుడు ప్రశ్న "నేను RAG ఎలా నిర్మించాలి?" మాత్రమే కాదు. దీనిని నిర్మించడానికి అనేక మార్గాలు ఉన్నాయి, మరియు ముఖ్యమైన ప్రశ్న "నా పరిస్థితికి ఏ ఆర్కిటెక్చర్ సరిపోతుంది?" అనే దానిపై ఉంటుంది.

ఈ సిరీస్ ఆ నిర్ణయం స్థాయితో ప్రారంభమై, అమలు దిశగా లోతుగా వెళ్లే ముందు, AI సేవలకు రికవరీ అవసరం ఎందుకు ఉంటుందని, ఏప్పుడు Azure-ఆధారిత మేనేజ్‌డ్ సేవలు సరైనవో, ఏప్పుడు ఓపెన్-సోర్స్ ప్రత్యామ్నాయాలు బెటర్ అనుకూలమో, మరియు ఫైన్-ట్యూనింగ్ ఎక్కడ సరిపోతుందో చూస్తుంది.

>
> ఈ రిపోజిటరీ 50+ భాషా అనువాదాలు కలిగి ఉంది, అవి డౌన్లోడ్ పరిమాణాన్ని గణనీయంగా పెంచుతాయి. అనువాదాలు లేకుండా క్లోన్ చేయడానికి sparse checkout ఉపయోగించండి:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (విండోస్):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/skytin1004/teach-ai-to-answer-documents.git
> cd teach-ai-to-answer-documents
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> ఇది మీకు కోర్సు పూర్తి చేసుకోవడానికి అవసరమైన వాటినింటిని త్వరితంగా డౌన్లోడ్ చేస్తుంది.
