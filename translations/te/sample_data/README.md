# నమూనా డేటా

నోట్‌బుక్స్ చిన్న ప్రజాప్రయోజన నమూనా కార్పస్‌ను ఉపయోగిస్తాయి కావున ఉదాహరణలు ప్రైవేట్ డాక్యుమెంట్లు లేదా క్లౌడ్ అనుమతులు లేకుండా నడవగలవు.

| ఫైల్ | ఉద్దేశ్యం |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | తుది అసైన్మెంట్లు, పరీక్షలు, పరిశోధన ప్రాజెక్టులు, మరియు శిక్షకుల అధిగమింపుల గురించి విభాగాలతో కూడిన పాఠశాల విధాన పత్రం |
| [course_ai_guidance.md](./course_ai_guidance.md) | అనుమతించబడ్డ వినియోగాలు, వెల్లడింపు, ఉటంకన అభ్యాసాలు, మరియు గుంపు పని గురించి విభాగాలతో కూడిన కోర్సు మార్గదర్శక పత్రం |

నమూనా పత్రాలు జాగ్రత్తగా చిన్నవి. అవి రీట్రీవల్, మెటాడేటా, మరియు ఉటంకనలను సులభంగా పరిశీలించేందుకు ఉద్దేశించబడ్డవి.
