# సహకారం

ఈ రిపోజిటరీని బ్లాగ్ సిరీస్ మరియు నడపగల నోட్బుక్ ఉదాహరణలుగా క్రమబద్ధీకరಿಸಲಾಗಿದೆ.

## పుల్ రిక్వెస్ట్ తెరవడానికి ముందు

స్థానిక ధృవీకరణ స్క్రిప్ట్‌ను నడపండి:

```powershell
python scripts\verify_notebooks.py
```

అమలు లేదా నోட்பుక్ మార్పుల కోసం, స్థానిక-సురక్షిత నోட்பుక్ ఎగ్జిక్యూషన్‌ను నడపండి:

```powershell
python scripts\verify_notebooks.py --execute
```

## నోட்பుక్ మార్గదర్శకాలు

- నోட்பుక్‌లను చదవదగినదిగా మరియు సంబంధిత వ్యాసంపై ఫోకస్ చేయబడినట్లుగా ఉంచండి.
- సేవ్ చేసిన నోட்பుక్ అవుట్పుట్లు లేదా ఎగ్జిక్యూషన్ కౌంట్లను కమిట్ చేయవద్దు.
- వ్యాసం ప్రత్యేక బాహ్య వనరును అడగనంత వరకు `sample_data/` నుండి చిన్న నమూనా డేటా వినియోగించండి.
- ప్రవర్తన మారినపుడు ధృవీకరణ ఫలితాలను సంబంధిత వ్యాసంలో రికార్డు చేయండి.

## రహస్యాలు మరియు చిహ్నాలు

- API కీలు, టోకెన్లు, పాస్వర్డ్లు, ప్రైవేట్ ఎండ్పాయింట్లు, లేదా `.env` ఫైళ్ళను కమిట్ చేయవద్దు.
- ప్లేస్‌హోల్డర్ విలువలకు మాత్రమే `.env.example` వాడండి.
- ఐచ్ఛిక స్థానిక Ollama ప్రయోగాల కోసం వాతావరణ చరిహైల వాడండి.

## డాక్యుమెంటేషన్

- వ్యాస నావిగేషన్ కల్చర్లను తాజా ఉంచండి.
- కొత్త వ్యాసం, నోட்பుక్, అవసరాల ఫైల్ లేదా నమూనా డేటా ఫైల్ చేర్చినప్పుడు `README.md`ను నవీకరించండి.
- కనిష్ఠ పారదర్శక రిపోజిటరీ నవీకరణ ప్రచురించే ముందే `CHANGELOG.md`ను నవీకరించండి.

## ధృవీకరణ

GitHub Actions వర్క్‌ఫ్లో ఈ క్రింది పనులను చేస్తుంది:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` లోపల ఉన్న డ్రాఫ్ట్ సాహిత్యం Repository ధృవీకరణ ద్వారా పబ్లిక్ సూచిక సిద్ధం అయ్యేవరకు తీసివేయబడుతుంది.

## సమస్యలు

వ్యాస సవరణల కోసం వ్యాస అభిప్రాయ నమూనాని, నోட்பుక్ ఎగ్జిక్యూషన్ సమస్యల కోసం నోட்புக் సమస్య నమూనాని ఉపయోగించండి.
