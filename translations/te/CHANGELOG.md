# Changelog

## Unreleased

**Teach AI to Answer Questions Based on Your Documents** కోసం ప్రారంభ ప్రజా విడుదల గరిష్ట పరిధి.

### చేర్చబడింది

- RAG ఆర్కిటెక్చర్ నిర్ణయాలు, Azure vs ఓపెన్-సోర్స్ వ్యాపారాలు, మరియు ఫైన్-ట్యున్ ఎక్కడ సరిపోతుందన్నది గురించి సిరీస్ 1 ఆర్టికల్.
- Qdrant లోకల్ మోడ్, FastEmbed లోకల్ ఎంబెడ్డింగ్స్, లైట్‌వెయిట్ రీర్యాంకింగ్, Ollama మరియు Phi-4-mini ఉపయోగించే స్థానిక ఓపెన్-సోర్స్ RAG వర్క్‌ఫ్లోకి సిరీస్ 2 ఆర్టికల్ మరియు నోట్‌బుక్.
- సిరీస్ 2 స్టెప్-బై-స్టెప్ ఎండ్-టు-ఎండ్ ట్యుటోరియల్ ఫార్మాట్ పైన Python స్నిపెట్లతో మరియు అమలు చేసిన నోట్‌బుక్ నుండి ధృవీకరణ గమనికలతో.
- స్థానిక CPU-ప్రియమైన రిట్రీవల్ ని డిఫాల్ట్ మార్గంగా ఉంచుతూ Ollama మరియు Phi-4-miniతో ఆప్షనల్ సిరీస్ 2 సమాధాన-సృష్టి మార్గం.
- RTX 3060 ల్యాప్‌టాప్ GPUపై `phi4-mini:3.8b` ఉపయోగించి సిరీస్ 2కి స్థానిక Ollama ధృవీకరణ.
- పాఠశాల పాలసీ మరియు కోర్సు AI మార్గదర్శకానికి నమూనా డేటా.
- ప్రజా నోట్‌బుక్ మరియు రిపాజిటరీ-స్థాయి ధృవీకరణ కోసం అవసరాలు ఫైల్స్.
- స్థానిక Markdown లింకులు మరియు నోట్‌బుక్ ధృవీకరణ/అమలు కోసం రిపాజిటరీ ధృవీకరణ స్క్రిప్ట్.
- నోట్‌బుక్ ధృవీకరణ కోసం GitHub Actions వర్క్‌ఫ్లో.
- స్థానిక కాన్ఫిగరేషన్‌ని కమిట్ చేయకుండా ఆప్షనల్ స్థానిక Ollama సృష్టి సెటప్ కోసం `.env.example`.
- ఆర్టికಲ్స్, నోట్‌బుక్స్, అవసరాలు, నమూనా డేటా, మరియు స్క్రిప్ట్‌ల కోసం ఫోల్డర్-స్థాయి README ఫైల్స్.
- ప్రజా భద్రత మరియు ధృవీకరణ కోసం ప్రచురణ చెక్లిస్ట్.
- భవిష్యత్తు Azure మరియు మదింపు విషయాల కోసం డ్రాఫ్ట్ వర్క్‌స్పేస్.

### ధృవీకరించబడింది

- స్థానిక Markdown లింక్ ధృవీకరణ విజయవంతంగా పూర్తయింది.
- సిరీస్ 2 నోట్‌బుక్ విజయవంతంగా ధృవీకరించబడింది.
- స్థానిక ధృవీకరణ పరిసరంలో సిరీస్ 2 నోట్‌బుక్ విజయవంతంగా అమలు అయింది.
- నోట్‌బుక్ ఫైళ్లు సేవ్ చేయబడిన అవుట్‌పుట్‌లు లేకుండా లేదా అమలు పరిమాణాలు లేకుండా ఉంచబడ్డాయి.
- నిజమైన రహస్యాలు ఏవీ కమిట్ చేయబడలేదు.
