# ప్రచురణ చెక్లిస్టు

పబ్లిక్ అప్‌డేట్లను కమిట్ చేయడానికి లేదా పుష్ చేయడానికి ముందు ఈ చెక్లిస్ట్‌ను ఉపయోగించండి.

## భద్రత

- ఏపిఐ కీలు, టోకెన్లు, పాస్వర్డ్లు లేదా ప్రైవేట్ ఎండ్పాయింట్లు మార్క్‌డౌన్ ఫైల్స్, నోటుబుక్స్, నమూనా డేటా లేదా స్క్రిప్ట్‌లలో రాయబడలేదు అని నిర్ధారించుకోండి.
- ధృవీకరణ వివరాలు ప్రదర్శిత ఫైళ్ళలో కాకుండా పరిసర చరాలు లేదా నిర్వహించబడిన గుర్తింపు లో ఉంచండి.
- `.env` ఫైళ్ళను లేదా అమలైన నోటుబుక్ అవుట్‌పుట్ ఫైళ్ళను కమిట్ చేయవద్దు.
- `.env.example` ను ప్లేస్‌హోల్డర్ మాత్రమే ఉంచండి.

## ధృవీకరణ

రిపాజిటరీ ధృవీకరణ స్క్రిప్ట్‌ను నడపండి:

```powershell
python scripts\verify_notebooks.py
```

అమలు మార్పులను ప్రచురించడానికి ముందు పూర్తి స్థానిక-భద్ర నోటుబుక్ అమలు చేయండి:

```powershell
python scripts\verify_notebooks.py --execute
```

నిరీక్షిత తనిఖీలు:

- స్థానిక మార్క్‌డౌన్ లింకులు ఉత్తీర్ణమవుతాయి
- నోటుబుక్ JSON ధ్రువీకరణ ఉత్తీర్ణమవుతుంది
- నోటుబుక్స్ లో సేవ్ చేసిన అవుట్‌పుట్లు లేదా అమలు లెక్కలు ఉండవు
- హై-రిస్క్ సీక్రెట్ ప్యాటర్న్ స్కాన్ ఉత్తీర్ణమవుతుంది
- పబ్లిక్ నోటుబుక్స్ స్థానికంగా అమలు చేయబడతాయి
- `drafts/` కింద డ్రాఫ్ట్ పదార్థాలు ఉద్దేశపూర్వకంగా వదిలివేయబడ్డాయి

## సమీక్ష

- README ఆర్టికల్ లింకులు లక్ష్య ఫైళ్లకు సూచిస్తున్నాయో నిర్ధారించుకోండి.
- ప్రతి ఆర్టికల్ రిపాజిటరీ నావిగేషన్ మరియు సంబంధిత నోటుబుక్ లింకులను కలిగి ఉందో నిర్ధారించుకోండి.
- డ్రాఫ్ట్స్ పబ్లిక్ సూచికల నుండి లింక్ చేయబడలేదు లేదా ప్రచురించడానికి సిద్ధంగా ఉన్నవారిని తప్ప మరేదీ లింక్ చేయవద్దు.
- GitHub ఎష్యూ మరియు పుల్ రిక్వెస్ట్ టెంప్లేట్లు ఇంకా రిపాజిటరీ వర్క్‌ఫ్లో అనుకూలంగా ఉన్నాయా నిర్ధారించుకోండి.
- ఆర్టికల్ లో ధృవీకరణ ఫలితాలు తాజా నోటుబుక్ అవుట్‌పుటుతో బదులవుతాయా చూసుకోండి.
- GitHub Actions వర్క్‌ఫ్లో పుష్ తర్వాత నడవనుంది అని నిర్ధారించుకోండి.
- `CHANGELOG.md` అప్‌డేట్ ప్రచురణను ప్రతిబింబిస్తుంది.
- `CONTRIBUTING.md` ఇంకా రిపాజిటరీ వర్క్‌ఫ్లోకి అనుగుణంగా ఉందా నిశ్చయించుకోండి.
