# Scripts

ఈ ఫోల్డర్ రెపోసిటరీ పరిశీలన స్క్రిప्ट్లను కలిగి ఉంటుంది.

## `verify_notebooks.py`

స్థానిక మార్క్డౌన్ లింకులు, నోట్‌బుక్ JSON, నోట్‌బుక్ అవుట్పుట్ శుభ్రత మరియు గట్టి ప్రమాద గల రహస్య నమూనాలను ధృవీకరిస్తుంది:

```powershell
python scripts\verify_notebooks.py
```

అన్ని పబ్లిక్ స్థానిక-సురక్షిత నోట్‌బుక్స్‌ను అమలుచేస్తుంది:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions వర్క్‌ఫ్లో అదే స్క్రిప్ట్‌ను ఉపయోగిస్తుంది.

`drafts/` కింద ముసాయిదా పదార్థం ప్రజాస్వామ్య సూచిక కోసం సిద్దంగా ఉండేవరకు దాటిచూపబడదు.
