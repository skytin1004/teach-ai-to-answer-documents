# అవసరాలు

ప్రతి అమలు వ్యాసానికి ఒక కేంద్రీకృత అవసరాలు ఫైల్ ఉంటుంది.

| ఫైల్ | ఉపయోగించబడుతుంది |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | సిరీస్ 2 ఓపెన్ సోర్స్ RAG నోట్‌బుక్, ఎంపికపై Ollama జనరేషన్ సహాయకులను కలిగి ఉంది |
| [all.txt](../../../requirements/all.txt) | రిపాజిటరీ స్థాయి ధృవీకరణ మరియు CI |

ఒక నోట్‌బుక్ నడుపుతున్నప్పుడు కేంద్రీకృత ఫైల్‌ను ఉపయోగించండి. మొత్తం రిపాజిటరీను ప్రమాణీకరించేటప్పుడు `all.txt` ఉపయోగించండి.

`open-source-rag.txt` మరియు `all.txt` లో స్థానిక ఎంబెడ్డింగ్స్ కోసం `fastembed` మరియు సిరీస్ 2 Ollama జనరేషన్‌ను `.env` నుండి రీట్రీవల్ పైప్‌లైన్ మార్చకుండా ఆప్షనల్‌గా ఎనేబుల్ చేయడానికి `python-dotenv` ఉంటాయి.
