# Вимоги

Кожна стаття з реалізації має файл з конкретними вимогами.

| Файл | Використовується |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | Open-source RAG ноутбук Серії 2, включно з необов’язковими помічниками генерації Ollama |
| [all.txt](../../../requirements/all.txt) | Перевірка на рівні репозиторію та CI |

Використовуйте конкретний файл під час запуску одного ноутбука. Використовуйте `all.txt` для перевірки усього репозиторію.

`open-source-rag.txt` та `all.txt` включають `fastembed` для локальних вбудовувань і `python-dotenv`, щоб Серія 2 могла необов’язково увімкнути генерацію Ollama з `.env` без зміни конвеєра пошуку.
