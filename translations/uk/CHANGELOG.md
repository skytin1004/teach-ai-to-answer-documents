# Журнал змін

## Невипущено

Початковий обсяг публічного випуску для **Навчіть ШІ відповідати на питання на основі ваших документів**.

### Додано

- Стаття серії 1 про рішення архітектури RAG, компроміси Azure та open-source, а також де підходить тонке налаштування.
- Стаття серії 2 та блокнот для локального open-source RAG робочого процесу з використанням Qdrant локального режиму, FastEmbed локальних векторних подань, легкого переранжування, Ollama та Phi-4-mini.
- Формат покрокового навчального посібника серії 2 з фрагментами Python та нотатками перевірки з виконаного блокнота.
- Опційний шлях генерації відповідей серії 2 з Ollama та Phi-4-mini, зберігаючи при цьому локальний CPU-дружній пошук за замовчуванням.
- Локальна перевірка Ollama для серії 2 з `phi4-mini:3.8b` на RTX 3060 Laptop GPU.
- Приклад даних для політики школи та керівництва з курсу ШІ.
- Файли вимог для публічного блокнота та перевірки на рівні репозиторію.
- Скрипт перевірки репозиторію для локальних посилань Markdown і валідації/виконання блокнотів.
- Робочий процес GitHub Actions для перевірки блокнотів.
- `.env.example` для опційної локальної настройки генерації Ollama без коміту локальної конфігурації.
- README файли на рівні папок для статей, блокнотів, вимог, прикладів даних і скриптів.
- Контрольний список публікації для безпеки та перевірки.
- Чернетка робочого простору для майбутнього контенту Azure та оцінювання.

### Перевірено

- Валідація локальних посилань Markdown пройшла успішно.
- Блокнот серії 2 валідовано успішно.
