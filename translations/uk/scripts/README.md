# Скрипти

Ця папка містить скрипти перевірки репозиторію.

## `verify_notebooks.py`

Перевіряє локальні посилання Markdown, JSON ноутбуків, чистоту виводу ноутбуків та шаблони високоризикових секретів:

```powershell
python scripts\verify_notebooks.py
```

Виконує всі публічні безпечні локальні ноутбуки:

```powershell
python scripts\verify_notebooks.py --execute
```

Workflow GitHub Actions використовує той самий скрипт.

Чернеткові матеріали в папці `drafts/` пропускаються, поки вони не будуть готові для публічного індексу.
