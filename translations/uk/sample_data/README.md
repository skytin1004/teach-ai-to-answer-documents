# Зразок даних

Ноутбуки використовують невеликий публічний зразок корпусу, щоб приклади могли запускатися без приватних документів або облікових даних хмари.

| Файл | Призначення |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Документ політики школи з розділами про завершальні завдання, іспити, дослідницькі проєкти та винятки викладача |
| [course_ai_guidance.md](./course_ai_guidance.md) | Документ керівництва курсу з розділами про дозволені використання, розкриття інформації, очікування щодо цитування та групову роботу |

Зразки документів навмисно невеликі. Вони призначені для того, щоб робити легкою перевірку вилучення, метаданих і цитат.
