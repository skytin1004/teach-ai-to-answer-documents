# Внесок

Цей репозиторій організовано як серія блогів плюс виконавчі приклади у блокнотах.

## Перед відкриттям Pull Request

Запустіть локальний скрипт перевірки:

```powershell
python scripts\verify_notebooks.py
```

Для змін у реалізації або у блокнотах запустіть локальне безпечне виконання блокноту:

```powershell
python scripts\verify_notebooks.py --execute
```

## Керівництво з блокнотів

- Зберігайте блокноти читабельними і сфокусованими на відповідній статті.
- Не комітьте збережені вихідні дані блокнотів або лічильники виконання.
- Використовуйте невеликі приклади даних із `sample_data/`, якщо стаття не вимагає конкретного зовнішнього ресурсу.
- Фіксуйте результати перевірок у відповідній статті при зміні поведінки.

## Секрети і облікові дані

- Не комітьте ключі API, токени, паролі, приватні кінцеві точки або файли `.env`.
- Використовуйте `.env.example` лише для заповнювачів значень.
- Використовуйте змінні середовища для необов’язкових локальних експериментів з Ollama.

## Документація

- Підтримуйте навігаційні посилання статей актуальними.
- Оновлюйте `README.md` при додаванні нової статті, блокноту, файлу вимог або файлу прикладу даних.
- Оновлюйте `CHANGELOG.md` перед публікацією видимого оновлення репозиторію.

## Перевірка

Обробка GitHub Actions запускається:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

Чернетки матеріалів у `drafts/` пропускаються верифікацією репозиторію, поки вони не будуть готові для публічного індексування.

## Проблеми

Використовуйте шаблон відгуків статей для виправлень статей і шаблон проблем з блокнотами для проблем виконання блокнотів.
