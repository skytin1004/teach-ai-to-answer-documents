# المتطلبات

كل مقال تنفيذ يحتوي على ملف متطلبات مركز.

| الملف | المستخدم بواسطة |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | دفتر ملاحظات RAG مفتوح المصدر للسلسلة 2، بما في ذلك مساعدات توليد Ollama الاختيارية |
| [all.txt](../../../requirements/all.txt) | التحقق على مستوى المستودع وCI |

استخدم الملف المركز عند تشغيل دفتر ملاحظات واحد. استخدم `all.txt` عند التحقق من المستودع بأكمله.

يتضمن `open-source-rag.txt` و`all.txt` مكتبة `fastembed` للتضمينات المحلية و`python-dotenv` حتى يمكن للسلسلة 2 اختيارياً تمكين توليد Ollama من `.env` دون تغيير خط أنابيب الاسترجاع.
