# السكربتات

يحتوي هذا المجلد على سكربتات للتحقق من المستودع.

## `verify_notebooks.py`

يتحقق من صحة الروابط المحلية في ملفات Markdown، وملفات JSON الخاصة بالدفاتر، ونظافة مخرجات الدفاتر، وأنماط الأسرار عالية الخطورة:

```powershell
python scripts\verify_notebooks.py
```

ينفذ جميع الدفاتر العامة الآمنة محليًا:

```powershell
python scripts\verify_notebooks.py --execute
```

يستخدم سير عمل GitHub Actions نفس السكربت.

يتم تخطي المواد القيد الإعداد الموجودة تحت `drafts/` حتى تصبح جاهزة للفهرس العام.
