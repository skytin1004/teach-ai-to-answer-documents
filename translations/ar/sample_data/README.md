# بيانات نموذجية

تستخدم دفاتر الملاحظات مجموعة عامة صغيرة من العينات حتى يمكن تشغيل الأمثلة بدون مستندات خاصة أو بيانات اعتماد السحابة.

| الملف | الغرض |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | مستند سياسة المدرسة مع أقسام حول الواجبات النهائية، والامتحانات، ومشاريع البحث، وتجاوزات المدرس |
| [course_ai_guidance.md](./course_ai_guidance.md) | مستند دليل الدورة مع أقسام حول الاستخدامات المسموح بها، والإفصاح، وتوقعات الاستشهاد، والعمل الجماعي |

المستندات النموذجية صغيرة عن عمد. فهي تهدف إلى تسهيل فحص الاسترجاع والبيانات الوصفية والاستشهادات.
