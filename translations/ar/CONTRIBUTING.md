# المساهمة

يتم تنظيم هذا المستودع كسلسلة مدونة بالإضافة إلى أمثلة دفاتر ملاحظات قابلة للتشغيل.

## قبل فتح طلب سحب

شغل نص التحقق المحلي:

```powershell
python scripts\verify_notebooks.py
```

لتنفيذ أو تغييرات دفتر الملاحظات، شغل تنفيذ دفتر الملاحظات المحلي الآمن:

```powershell
python scripts\verify_notebooks.py --execute
```

## إرشادات دفتر الملاحظات

- حافظ على دفاتر الملاحظات قابلة للقراءة ومركزة على المقالة ذات الصلة.
- لا تقم بالتزام نواتج دفاتر الملاحظات أو أعداد التنفيذ المحفوظة.
- استخدم بيانات عينة صغيرة من `sample_data/` إلا إذا كانت المقالة تتطلب مورداً خارجياً معيناً.
- قم بتسجيل نتائج التحقق في المقالة ذات الصلة عند حدوث تغييرات في السلوك.

## الأسرار والاعتمادات

- لا تقم بالتزام مفاتيح API أو الرموز أو كلمات المرور أو نقاط النهاية الخاصة أو ملفات `.env`.
- استخدم `.env.example` للقيم النائبة فقط.
- استخدم متغيرات البيئة لتجارب Ollama المحلية الاختيارية.

## التوثيق

- حافظ على تحديث روابط التنقل للمقالات.
- حدّث `README.md` عند إضافة مقال جديد أو دفتر ملاحظات أو ملف متطلبات أو ملف بيانات عينة.
- حدّث `CHANGELOG.md` قبل نشر تحديث مرئي للمستودع.

## التحقق

يقوم سير عمل GitHub Actions بالتشغيل:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

يتم تخطي المواد المسودة ضمن `drafts/` من قبل التحقق في المستودع حتى تصبح جاهزة للفهرسة العامة.

## المشكلات

استخدم قالب ملاحظات المقالات لتصحيحات المقالات وقالب مشاكل دفاتر الملاحظات لمشاكل تنفيذ دفاتر الملاحظات.
