# 샘플 데이터

| 파일 | 목적 |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | 최종 과제, 시험, 연구 프로젝트, 강사 재량에 관한 섹션이 포함된 학교 정책 문서 |
| [course_ai_guidance.md](./course_ai_guidance.md) | 허용된 사용, 공개, 인용 기대치, 그룹 작업에 관한 섹션이 포함된 강의 안내 문서 |
