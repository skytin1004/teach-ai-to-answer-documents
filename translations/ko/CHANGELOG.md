# 변경 로그

## 미발행

<strong>문서 기반 질문에 대한 답변을 AI에게 교육하기</strong>의 초기 공개 배포 범위.

### 추가됨

- RAG 아키텍처 결정, Azure 대 오픈 소스 트레이드오프, 미세 조정이 어디에 들어가는지에 대한 시리즈 1 기사.
- Qdrant 로컬 모드, FastEmbed 로컬 임베딩, 경량 재순위화, Ollama, Phi-4-mini를 사용하는 로컬 오픈 소스 RAG 워크플로우용 시리즈 2 기사 및 노트북.
- Python 스니펫과 실행된 노트북의 검증 노트를 포함한 단계별 시리즈 2 종단 간 튜토리얼 형식.
- 기본 로컬 CPU 친화적 검색 경로를 유지하면서 Ollama 및 Phi-4-mini로 선택적 시리즈 2 답변 생성 경로.
- RTX 3060 랩탑 GPU에서 `phi4-mini:3.8b`를 이용한 시리즈 2용 로컬 Ollama 검증.
- 학교 정책 및 과정 AI 안내용 샘플 데이터.
- 공개 노트북과 리포지토리 수준 검증을 위한 요구 사항 파일.
- 로컬 Markdown 링크 및 노트북 검증/실행용 리포지토리 검증 스크립트.
- 노트북 검증용 GitHub Actions 워크플로우.
- 로컬 구성을 커밋하지 않고 선택적 로컬 Ollama 생성 설정용 `.env.example`.
- 기사, 노트북, 요구 사항, 샘플 데이터, 스크립트에 대한 폴더 단위 README 파일.
- 공개 안전 및 검증을 위한 게시 체크리스트.
- 향후 Azure 및 평가 콘텐츠용 임시 작업 공간.

### 검증됨

- 로컬 Markdown 링크 검증 통과.
- 시리즈 2 노트북이 성공적으로 검증됨.
- 시리즈 2 노트북이 로컬 검증 환경에서 성공적으로 실행됨.
- 노트북 파일에 저장된 출력이나 실행 횟수가 없음.
- 실제 비밀 정보가 커밋되지 않음.
