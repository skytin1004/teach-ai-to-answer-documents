# Eksempeldatasæt

Notebooks bruger en lille offentlig eksempeltekst, så eksemplerne kan køre uden private dokumenter eller cloud-legitimationsoplysninger.

| Fil | Formål |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | Et skoleregel-dokument med sektioner om afsluttende opgaver, eksamener, forskningsprojekter og underviserens undtagelser |
| [course_ai_guidance.md](./course_ai_guidance.md) | Et kursusvejledningsdokument med sektioner om tilladte anvendelser, oplysning, forventninger til kildehenvisning og gruppearbejde |

Eksempeldokumenterne er bevidst små. De er designet til at gøre søgning, metadata og kildehenvisninger nemme at inspicere.
