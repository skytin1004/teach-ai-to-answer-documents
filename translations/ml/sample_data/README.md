# സാമ്പിൾ ഡാറ്റ

നോട്ട്‌ബുക്കുകൾ സ്വകാര്യ ഡോക്യുമെന്റുകളോ ക്ലൗഡ് ക്രെഡൻഷ്യലുകളോ ഇല്ലാതെ ഉദാഹരണങ്ങൾ പ്രവർത്തിക്കുമ്പോൾ ചെറിയ ഒരു പൊതു സാമ്പിൾ കോർപ്പസ് ഉപയോഗിക്കുന്നു.

| ഫയൽ | ഉദ്ദേശ്യം |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | അന്തിമ അസൈൻമെന്റുകൾ, പരീക്ഷകൾ, ഗവേഷണ പദ്ധതികൾ, ഇൻസ്ട്രക്ടർ ഓവർറൈഡുകൾ എന്നിവയുമായി ബന്ധപ്പെട്ട സെക്ഷനുകൾ ഉള്ള ഒരു സ്കൂൾ നയം ഡോക്യുമെന്റ് |
| [course_ai_guidance.md](./course_ai_guidance.md) | അനുവാദപ്പെട്ട ഉപകരണങ്ങൾ, വെളികെട്ടൽ, ഉദ്ധരണി പ്രതീക്ഷകൾ, ഗ്രൂപ്പ് വർക്ക് എന്നിവയുമായി ബന്ധപ്പെട്ട സെക്ഷനുകൾ ഉള്ള ഒരു കോഴ്സ് മാർഗ്ഗരേഖ ഡോക്യുമെന്റ് |

സാമ്പിൾ ഡോക്യുമെന്റുകൾ അഭിപ്പ്രേതമായും ചെറിയവയാണ്. അവ റിട്ട്രിവൽ, മേറ്റഡേറ്റ, ഉദ്ധരണികൾ എളുപ്പത്തിൽ പരിശോധിക്കാൻ ഉദ്ദേശിച്ചവയാണ്.
