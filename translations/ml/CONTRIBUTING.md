# സംഭാവനകൾ

ഈ റിപോസിറ്ററി ഒരു ബ്ലോഗ് സീരീസ് കൂടാതെ പ്രവർത്തനക്ഷമമായ നോട്ട്‌ബുക്ക് ഉദാഹരണങ്ങളായി ക്രമീകരിച്ചിരിക്കുന്നു.

## ഒരു പുൾ റിക്വസ്റ്റ് തുറക്കുമുമ്പ്

লোকൽ പരിശോധനാ സ്ക്രിപ്റ്റ് പ്രവർത്തിപ്പിക്കുക:

```powershell
python scripts\verify_notebooks.py
```

അമൽപ്പത്രികയിലോ നോട്ട്‌ബുക്ക് മാറ്റങ്ങളിലോ വേണ്ടി, ലോക്കൽ-സേഫ് നോട്ട്‌ബുക്ക് പ്രവർത്തനം നടത്തുക:

```powershell
python scripts\verify_notebooks.py --execute
```

## നോട്ട്‌ബുക്ക് മാർഗ്ഗനിർദേശം

- നോട്ട്‌ബുക്കുകൾ വായിക്കാൻ സുലഭവും ബന്ധപ്പെട്ട ലേഖനത്തിൽ മാത്രമേ ശ്രദ്ധ കേന്ദ്രീകരിച്ചുള്ളതുമായിരിക്കണം.
- സേവ് ചെയ്ത നോട്ട്‌ബുക്ക് ഔട്ട്പുട്ടുകളും പ്രവർത്തന എണ്ണവും കമിറ്റ് ചെയ്യരുത്.
- ലേഖനം ഏതെങ്കിലും പ്രത്യേക ബാഹ്യ വിഭവം ആവശ്യപ്പെടാത്തതിൽ `sample_data/` നിന്ന് ചെറിയ സാമ്പിൾ ഡാറ്റ ഉപയോഗിക്കുക.
- പെരുമാറ്റം മാറ്റം സംഭവിച്ചാൽ ബന്ധപ്പെട്ട ലേഖനത്തിൽ പരിശോധനാ ഫലങ്ങൾ രേഖപ്പെടുത്തുക.

## രഹസ്യങ്ങളും രേഖബാധ്യതകളും

- API കീകൾ, ടോക്കണുകൾ, പാസ്‌വേഡുകൾ, സ്വകാര്യ എന്റ്പോയിന്റുകൾ, അല്ലെങ്കിൽ `.env` ഫയലുകൾ കമിറ്റ് ചെയ്യരുത്.
- പ്ലേയ്സ്ഹോൾഡർ മൂല്യങ്ങള്ക്കായി മാത്രം `.env.example` ഉപയോഗിക്കുക.
- ഐച്ഛികമായ ലോക്കൽ ഒല്ലാമ പരീക്ഷണങ്ങൾക്ക് പരിസ്ഥിതി വ്യത്യസ്തങ്ങൾ ഉപയോഗിക്കുക.

## ഡോക്യുമെന്റേഷൻ

- ലേഖന നാവിഗേഷൻ ലിങ്കുകൾ നവീകരിച്ച നിലയിൽ സൂക്ഷിക്കുക.
- പുതിയ ലേഖനം, നോട്ട്‌ബുക്ക്, ആവശ്യകതകളുടെ ഫയൽ, അല്ലെങ്കിൽ സാമ്പിൾ ഡാറ്റാ ഫയൽ ചേർക്കുമ്പോൾ `README.md` നവീകരിക്കുക.
- ദൃശ്യമായ റിപോസിറ്ററി അപ്ഡേറ്റ് പ്രസിദ്ധീകരിക്കുന്നതിന് മുൻപ് `CHANGELOG.md` പുതുക്കുക.

## പരിശ്രമം

GitHub Actions പ്രവൃത്തി രീതി പ്രവർത്തിക്കും:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` -ൽ ഉള്ള ഡ്രാഫ്റ്റ് മെറ്റീരിയൽ പൊതുവിൽ സൂചിപ്പിക്കുന്നതിനായി സജ്ജമാകുന്നത് വരെ റിപോസിറ്ററിയുടെ സ്ഥിരീകരണത്തിലേക്ക് ഒഴിവാക്കപ്പെടുന്നു.

## പ്രശ്നങ്ങൾ

ലേഖന ശരിയാക്കലിനായി ലേഖന പ്രതികരണ ഫോർമാറ്റും നോട്ട്‌ബുക്ക് പ്രവർത്തന പ്രശ്നങ്ങൾക്ക് നോട്ട്‌ബുക്ക് പ്രശ്ന ഫോർമാറ്റും ഉപയോഗിക്കുക.
