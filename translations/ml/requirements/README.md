# ആവശ്യകതകൾ

പ്രതി ഒരുക്കൽ ലേഖനത്തിനും ഒരു കേന്ദ്രീകരിച്ച ആവശ്യകതകൾ ഫയൽ ഉണ്ട്.

| ഫയൽ | ഉപയോഗിക്കുന്നത് |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | സീരീസ് 2 ഓപ്പൺ-സോర్స్ RAG നോട്ട്‌ബുക്ക്, ഓപ്ഷണൽ ഒലമ ജനറേഷൻ സഹായകങ്ങള്‍ ഉള്‍ക്കൊള്ളുന്നു |
| [all.txt](../../../requirements/all.txt) | റിപ്പოზിറ്ററി-ലവൽ പരിശോധനയും CIയും |

ഓരോ നോട്ട്‌ബുക്ക് ഓടിക്കുമ്പോൾ കേന്ദ്രീകരിച്ച ഫയൽ ഉപയോഗിക്കുക. മുഴുവൻ റിപ്പോസിറ്ററി പരിശോധിക്കുമ്പോൾ `all.txt` ഉപയോഗിക്കുക.

`open-source-rag.txt`യും `all.txt`ഉം പ്രാദേശിക എംബെഡ്ഡിംഗുകൾക്ക് `fastembed` ഉൾക്കൊള്ളിച്ചിട്ടുള്ളതാണ്, കൂടാതെ സീരീസ് 2 ഓപ്ഷണൽ ആയി `.env` നിന്നുള്ള ഒലമ ജനറേഷൻ സജ്ജമാക്കാൻ `python-dotenv` ഉപയോഗിക്കുന്നു, ഇതിലൂടെ തിരിച്ചടി പൈപ്പ്ലൈനിൽ മാറ്റം വരുത്താതെ കഴിയുന്നു.
