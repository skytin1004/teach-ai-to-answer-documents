# മാറ്റങ്ങൾ

## റിലീസ് ചെയ്യാത്തത്

**നിങ്ങളുടെ രേഖകളും അടിസ്ഥാനമാക്കി ചോദ്യങ്ങൾക്കു ഉത്തരം നൽകാൻ AI- നു പഠിപ്പിക്കുക** എന്നതിനുള്ള പ്രാഥമിക പൊതു റിലീസ് പരിധി.

### ചേർത്തത്

- RAG معماري തീരുമാനങ്ങൾ, Azure നും open-source ഒടൊപ്പം താരതമ്യങ്ങളും fine-tuning എവിടെയാണെന്ന് സംബന്ധിച്ച സീരീസ് 1 ലേഖനം.
- Qdrant local mode, FastEmbed local embeddings, ലഘു reranking, Ollama, Phi-4-mini എന്നിവ ഉപയോഗിച്ച് ഒരു ലൊക്കൽ open-source RAG പ്രവൃത്തി മുതലായ സീരീസ് 2 ലേഖനവും നോട്ട്‌ബുക്കും.
- Python സ്നിപ്പറ്റുകളോടും നടപ്പിലാക്കിയ നോട്ട്‌ബുക്ക് പരിശോധക കുറിപ്പുകളോടും കൂടിയ സീരീസ് 2 പടിയെടുത്ത് പടിയെടുത്ത് Tutorial ഫോർമാറ്റ്.
- ഡിഫോൾട്ട് പാതയായി ലൊക്കൽ CPU-സൗഹൃദ റിട്രീവലിനെ നിലനിർത്തികൊണ്ട് Ollama, Phi-4-mini ഉപയോഗിച്ച ഓപ്ഷണൽ സീരീസ് 2 ഉത്തരം സൃഷ്ടിക്കൽ പാത.
- RTX 3060 ലാപ്‌ടോപ്പ് GPU ൽ `phi4-mini:3.8b` ഉപയോഗിച്ച് സീരീസ് 2 ലൊക്കൽ Ollama സ്ഥിരീകരണം.
- സ്കൂൾ നയം, കോഴ്സ് AI മാർഗ്ഗനിർദ്ദേശത്തിനുള്ള സാമ്പിൾ ഡാറ്റ.
- പൊതു നോട്ട്‌ബുക്ക്, റിപ്പോസിറ്ററി-നിരപ്പ് സ്ഥിരീകരണത്തിന് ആവശ്യമായ ഫോൾഡറുകൾ.
- ലൊക്കൽ മാർക്ക്‌ഡൗൺ ലിങ്കുകൾക്കും നോട്ട്‌ബുക്ക് സാധുതക്കും പ്രവര്‍ത്തനത്തിനുമുള്ള റിപ്പോസിറ്ററി സ്ഥിരീകരണ സ്ക്രിപ്പ്റ്റ്.
- നോട്ട്‌ബുക്ക് പരിശോധനയ്ക്കുള്ള GitHub Actions പ്രവൃത്തി പ്രക്രിയ.
- ലൊക്കൽ കോൺഫിഗറേഷൻ കമ്മിറ്റ്മെന്റ് ചെയ്യാതെ ഓപ്ഷണൽ ലൊക്കൽ Ollama സൃഷ്ടീകരണത്തിന് `.env.example`.
- ലേഖനങ്ങൾ, നോട്ട്‌ബുക്കുകൾ, ആവശ്യമായ ഫയലുകൾ, സാമ്പിൾ ഡാറ്റ, സ്ക്രിപ്പ്റ്റുകൾ എന്നിവയ്ക്കുള്ള ഫോൾഡർ ലെവൽ README ഫയലുകൾ.
- പൊതു സുരക്ഷയ്ക്കും സ്ഥിരീകരണത്തിനും പ്രസിദ്ധീകരണ പരിശോധ പട്ടിക.
- ഭാവിയിലെ Azure, മൂല്യനിർണയ ഉള്ളടക്കത്തിനുള്ള ഡ്രാഫ്റ്റ് വർക്ക്‌സ്പേസ്.

### സ്ഥിരീകരിച്ചതു

- ലൊക്കൽ Markdown ലിങ്കുകൾ സാധുത പരിശോധനയ്ക്ക് കീഴ്‌പ്പെട്ടു.
- സീരീസ് 2 നോട്ട്‌ബുക്ക് വിജയകരമായി സാധുത പരിശോധനയ്ക്ക് കീഴ്‌പ്പെട്ടു.
- ലൊക്കൽ സ്ഥിരീകരണ പരിസ്ഥിതിയിൽ സീരീസ് 2 നോട്ട്‌ബുക്ക് വിജയകരമായി പ്രവർത്തിച്ചു.
- നോട്ട്‌ബുക്ക് ഫയലുകൾ സേവ് ചെയ്ത ഔട്ട്പുട്ടുകളോ പ്രവർത്തന എണ്ണങ്ങളോ കൂടാതെ സൂക്ഷിക്കപ്പെട്ടിട്ടുണ്ട്.
- യഥാർത്ഥ രഹസ്യങ്ങൾ ഒന്നും കമ്മിറ്റ് ചെയ്തിട്ടില്ല.
