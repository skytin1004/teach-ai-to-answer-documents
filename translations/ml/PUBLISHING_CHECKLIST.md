# പ്രസിദ്ധീകരണ ചെക്ലിസ്റ്റ്

പബ്ലിക് അപ്ഡേറ്റുകൾ കമ്മിറ്റ് ചെയ്യുന്നതിനു മുൻപ് ഈ ചെക്ലിസ്റ്റ് ഉപയോഗിക്കുക.

## സുരക്ഷ

- API കീകൾ, ടോക്കണുകൾ, പാസ്വേഡുകൾ, അല്ലെങ്കിൽ പ്രൈവറ്റ് എൻഡ്‌പോയിന്റുകൾ മാർക്ക്‌ഡൗൺ ഫയലുകളിലോ, നോട്ട്ബുക്കുകളിലോ, സാമ്പിൾ ഡേറ്റയിലോ സ്‌ക്രിപ്റ്റുകളിലോ എഴുതിയിട്ടില്ലെന്ന് സ്ഥിരീകരിക്കുക.
- ക്രെഡൻഷ്യലുകൾ കമ്മിറ്റ് ചെയ്ത ഫയലുകളിലല്ല, പരിസ്ഥിതി വേരിയബിളുകളിലോ മാനേജർ ഐഡന്റിറ്റിയിലോ സൂക്ഷിക്കുക.
- `.env` ഫയലുകളും 실행ം കഴിഞ്ഞ നോട്ട്ബുക്ക് ഔട്ട്പുട്ട് ഫയലുകളും കമ്മിറ്റ് ചെയ്യരുത്.
- `.env.example` പ്ളേസ്ഹോൾഡർ മാത്രമാകണം.

## സ്ഥിരീകരണം

റിപ്പോസിറ്ററി സ്ഥിരീകരണ സ്ക്രിപ്റ്റ് 실행ിക്കുക:

```powershell
python scripts\verify_notebooks.py
```

പ്രവർത്തനപരമായ മാറ്റങ്ങൾ പ്രസിദ്ധീകരിക്കുന്നതിന് മുമ്പ് പൂർണ്ണമായ് ലോക്കൽ-സുരക്ഷിതമായി നോട്ട്ബുക്ക് 실행ം നടത്തുക:

```powershell
python scripts\verify_notebooks.py --execute
```

എക്സ്പെക്ടഡ് ചെക്കുകൾ:

- ലോക്കൽ മാർക്ക്‌ഡൗൺ ലിങ്കുകൾ പാസ്സ് ചെയ്യുക
- നോട്ട്ബുക്ക് JSON സാധുത പാസ്സ് ചെയ്യുക
- നോട്ട്ബുക്കുകളിൽ സേവ് ചെയ്ത ഔട്ട്പുട്ടുകളോ 실행 എണ്ണംകൾഅഗയോ ഇല്ലാപോവുക
- ഉയർന്ന അപകടം ഉള്ള ഹൃദയ രഹസ്യ പാറ്റേൺ സ്‌കാൻ പാസ്സ് ചെയ്യുക
- പബ്ലിക് നോട്ട്ബുക്കുകൾ ലോക്കലായി 실행ചെയ്യുക
- `drafts/` കീഴിലുള്ള ഡ്രാഫ്റ്റ് മെറ്റീരിയൽ ഉദ്ദേശിച്ചുള്ള skipped ആകുന്നു

## അവലോകനം

- README ലേഖന ലിങ്കുകൾ ലക്ഷ്യമിട്ടിരിക്കുന്ന ഫയലുകളിലേക്ക് പോകരുതെന്ന് സ്ഥിരീകരിക്കുക.
- ഓരോ ലേഖനത്തിനും റിപ്പോസിറ്ററി നാവിഗേഷൻ, ബന്ധപ്പെട്ട നോട്ട്ബുക്ക് ലിങ്കുകൾ ഉണ്ട് എന്നറിയിക്കുക.
- ഡ്രാഫ്റ്റുകൾ പബ്ലിക് ഇൻഡക്സുകളിൽ ലിങ്ക് ചെയ്‌തിട്ടില്ലെന്ന് സ്ഥിരീകരിക്കുക, അവ പ്രസിദ്ധീകരിക്കാൻ തയ്യാറായിരിക്കില്ലെങ്കിൽ മാത്രം.
- GitHub ഇഷ്യൂമുകളും പുൾ.REQUEST ടെംപ്ലേറ്റുകളും ഇപ്പോഴും റിപ്പോസിറ്ററി പ്രവർത്തി രീതിക്ക് അനുയോജ്യമാണ് എന്ന് പരിശോധിക്കുക.
- ലേഖനത്തിലെ സ്ഥിരീകരണ ഫലം ഏറ്റവും പുതിയ നോട്ട്ബുക്ക് ഔട്ട്പുട്ടിനോടാണ് പൊരുത്തപ്പെടുന്നെന്ന് സ്ഥിരീകരിക്കുക.
- GitHub ആക്ഷൻസ് പ്രവർത്തനരീതികൾ പുഷ് കഴിഞ്ഞാൽ പ്രവർത്തിക്കും എന്ന് ഉറപ്പുവരുത്തുക.
- `CHANGELOG.md` പ്രസിദ്ധീകരിക്കൽ അപ്ഡേറ്റിന്റെ പ്രതിഫലം നൽകുന്നു എന്ന് ഉറപ്പ് വരുത്തുക.
- `CONTRIBUTING.md` ഇപ്പോഴും റിപ്പോസിറ്ററി പ്രവർത്തി രീതിയോട് പൊരുത്തപ്പെടുന്നോ എന്ന് പരിശോധിക്കുക.

- `git diff --stat` അവലോകനം ചെയ്യുക.
