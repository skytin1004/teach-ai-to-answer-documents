# Scripts

ഈ ഫോൾഡറിൽ റെപ്പോസിറ്ററി സ്ഥിരീകരണ സ്ക്രിപ്റ്റുകൾ ഉൾപ്പെടുന്നു.

## `verify_notebooks.py`

സ്ഥానിക Markdown ലിങ്കുകൾ, നോട്ട്‌ബുക്ക് JSON, നോട്ട്‌ബുക്ക് ഔട്ട്പുട്ടിന്റെ ശുചിത്വം, ഉയർന്ന അപകടസാധ്യതയുള്ള രഹസ്യ പാറ്റേൺ എന്നിവയെ വേർതിരിച്ച് പരിശോധന നടത്തുന്നു:

```powershell
python scripts\verify_notebooks.py
```

ഏതാനും പൊതുജനങ്ങളുടെ ആഗോള-സുരക്ഷിത നോട്ട്‌ബുക്കുകൾ സജീവമാക്കുന്നു:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions workflow ഇതേ സ്ക്രിപ്റ്റ് ഉപയോഗിക്കുന്നു.

`drafts/` സബ്ഫോള്ഡറിൽ ഉള്ള ഡ്രാഫ്റ്റ് സാമഗ്രി പൊതുജന സൂചികയ്ക്ക് തയ്യാറാക്കുന്നത് വരെ ഒഴിവാക്കപ്പെടും.
