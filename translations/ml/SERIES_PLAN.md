# നിങ്ങളുടെ ഡോക്യുമെന്റുകളുടെ അടിസ്ഥാനത്തിൽ AI-നെ ചോദ്യങ്ങൾക്ക് ഉത്തരം പറഞ്ഞുകൊടുക്കാൻ പരിശീലിപ്പിക്കുക - സീരിസ് പദ്ധതി

ഈ പദ്ധതി പൊതു സീരിസ് 1യും സീരിസ് 2യും റിലീസുകൾ ട്രാക്ക് ചെയ്യുന്നു. പിന്നീട് Azureയും ഇവല്യുവേഷൻ ജോലികളും ഉദാഹരണങ്ങൾ പൂർണമായും എൻഡ്-ടു-എൻഡ് പ്രവർത്തനക്ഷമവും സാധൂകരിച്ചുകൊണ്ടിരിക്കുമ്പോൾ ഡ്രാഫ്റ്റുകളായി സൂക്ഷിക്കപ്പെടുന്നു.

സൂചിപ്പിക്കപ്പെട്ടില്ലെങ്കിൽ മാറ്റങ്ങൾ കമ്മിറ്റ് ചെയ്യുകയോ പുഷ് ചെയ്യുകയോ ചെയ്യരുത്.

## പൊതു പരിധി

 ഇപ്പോഴുള്ള പൊതു റിലീസ്:

- സീരിസ് 1 ലേഖനം: RAG ആർക്കിടെക്ചർ തീരുമാനങ്ങൾ, Azure vs ഓപ്പൺ-സോഴ്‌സ് ട്രേഡ്-ഓഫുകൾ, fine-tuning എവിടെയാണെന്ന്.
- സീരിസ് 2 ലേഖനം: പ്രാദേശിക ഓപ്പൺ-സോഴ്‌സ് RAG ട്യൂട്ടോറിയൽ.
- സീരിസ് 2 നോട്ട്ബുക്ക്: FastEmbed, Qdrant, Ollama, Phi-4-mini എന്നിവ ഉപയോഗിച്ച് പ്രാദേശിക RAG ലാബ് റണ്ണബിള്‍.
- സാമ്പിൾ ഡാറ്റ: സ്കൂൾ പൊലസി, കോഴ്സ് AI മാർഗ്ഗനിർദ്ദേശ Markdown ഫയലുകൾ.

ഡ്രാഫ്റ്റ് ചെയ്തിട്ടുണ്ടെങ്കിലും പൊതു ഇൻഡക്സിൽ ഇനിയും ചേർക്കാത്തത്:

- Azure AI Search, Azure OpenAI പുനർനിർമ്മാണം.
- RAG ഇവല്യുവേഷൻ, റെഗ്രഷൻ പരിശോധനകൾ.

## ട്യൂട്ടോറിയൽ സീനാരിയോ

പങ്കുവെച്ച സീനാരിയോ ഒരു സ്കൂൾ പോളസി അസിസ്റ്റന്റാണ്.

അസിസ്റ്റന്റ് പ്രാദേശിക ഡോക്യുമെന്റുകളിൽ നിന്ന് ഈ ചോദ്യത്തിന് ഉത്തരം പറയുന്നു:

```text
Can I use generative AI for my final assignment?
```
  
പ്രതീക്ഷിക്കുന്ന പെരുമാറ്റം:

1. പ്രാദേശിക Markdown ഡോക്യുമെന്റുകൾ ലോഡു ചെയ്യുക.  
2. തലക്കെട്ടുകൾ അടിസ്ഥാനമാക്കി പാർസ് ചെയ്ത് ചങ്കുകളാക്കി വിഭജിക്കുക.  
3. പ്രാദേശിക embeddings സൃഷ്ടിച്ച് മെറ്റാഡേറ്റയോടുകൂടിയ സെർച്ചബിൾ റിപ്രസെന്റേഷനുകൾ സംഭരിക്കുക.  
4. ബന്ധപ്പെട്ട പോളസി വിഭാഗം തിരിച്ചു പിടിക്കുക.  
5. ആവശ്യമെങ്കിൽ റീറാങ്ക് ചെയ്യുക.  
6. ഉറപ്പുള്ള ഉത്തരം ഉണ്ടാക്കുക അല്ലെങ്കിൽ എഴുതുക.  
7. സൈറ്റേഷനുകൾ തിരിച്ചു നൽകുക.  
8. പരിശോധനാ ഫലങ്ങൾ രേഖപ്പെടുത്തുക.

## സീരിസ് 2 പരിശോധന

Windows-ൽ Python 3.12.6 ഉപയോഗിച്ച് പരിശോധിച്ചതും സ്ഥിരീകരിച്ചതും.

- `requirements/open-source-rag.txt` വഷളം ഇൻസ്റ്റാൾ ചെയ്തു.  
- `notebooks/series-2-open-source-rag.ipynb` `nbclient` ഉപയോഗിച്ച് കൃത്യമായി എക്‌സിക്യൂട്ട് ചെയ്തു.  
- പ്രാദേശിക പരിശോധന പരംവട്ടം വിജയം: 2 സാമ്പിൾ ഡോക്യുമെന്റുകൾ ലോഡുചെയ്തു, 8 ചങ്കുകൾ സൃഷ്ടിച്ചു, FastEmbed 384-ഡൈമെൻഷൻ പ്രാദേശിക embeddings ഉണ്ടാക്കി, Qdrant ഇൻ-മെമ്മറി കളക്ഷൻ ഇൻ‌ഷിയലൈസ് ചെയ്തു, 8 വെക്ടറുകൾ ഇൻസേർട്ട് ചെയ്തു.  
- പരീക്ഷണ ചോദ്യമായി: "എന്റെ ഫाइनल അസൈൻമെന്റിന് ജനറേറ്റീവ് AI ഉപയോഗിക്കാമോ?"  
- ലൈറ്റ് റീറാങ്ക് ചെയ്തതിന് ശേഷം മുൻനിരയിൽ കിട്ടിയ സോഴ്സ്: `school_ai_policy.md`.  
- ലഘു റീറാങ്ക് ചെയ്ത ശേഷം മുൻനിര സെക്ഷൻ: `Final Assignments`.  
- ഡീഫോൾട്ട് ഉത്തരം പാത: പ്രാദേശിക ട്രാൻസ്പറന്റ് ഉത്തരം കോമ്പോസർ.  
- Ollama winget വഴി ഇൻസ്റ്റാൾ ചെയ്തു; `phi4-mini:3.8b` വിജയകരമായി പുള്ളുചെയ്‌തു.  
- Ollama ഉത്തരം നിർമ്മാണ പാത: `phi4-mini:3.8b` ഉപയോഗിച്ച് പൂർത്തിയായി.  
- Ollama മോഡൽ ഫയൽ വലിപ്പം: ഡിസ്കിൽ ഏകദേശം 2.49GB.  
- Ollama ലോഡ് ചെയ്ത മോഡൽ വലുപ്പം: `ollama ps` പ്രകാരം 3.3GB റിപ്പോര്ട്ട്.  
- GPU ഓഫ്ലോഡ്: RTX 3060 ലാപ്‌ടോപ് GPU-യിൽ `ollama ps` പ്രകാരം 100% GPU ഉപയോഗം.  
- ഉത്തരം സൃഷ്ടിച്ചതിന് ശേഷം GPU മെമ്മറി നിരീക്ഷണം: ഏകദേശം 6GB-ലെ 3.5GB.  
- കാഷേൽഡ് FastEmbed മോഡലും Ollama ജനറേഷൻ സജീവവും ഉള്ള നോട്ട്ബുക്ക് എക്സിക്യൂഷൻ, പരിശോധനാ സ്ക്രിപ്റ്റ് വഴി ഏകദേശം 34 സെക്കൻഡിൽ പൂർത്തിയായി.  
- നിരീക്ഷണം: തുടക്കത്തിൽ ഒരു ഡോക്യുമെന്റ് ലോഡിങ്ങ് പാസ് തെറ്റുതിരുത്തിയത് കൊണ്ട് `sample_data/README.md` ഉൾപ്പെട്ടിരുന്നു; ഇപ്പോൾ വ്യക്തമായി രണ്ടിന്നം ആവശ്യമായ സാമ്പിൾ ഡോക്യുമെന്റുകൾ മാത്രമേ ലോഡ് ചെയ്യപ്പെടുകയുള്ളൂ.

## റിപ്പോസിറ്ററി പരിശോധന

- `scripts/verify_notebooks.py` പ്രാദേശിക Markdown ലിങ്കുകൾ, നോട്ട്ബുക്ക് JSON, നോട്ട്ബുക്ക് ഔട്ട്പുട്ടിന്റെ ശുദ്ധി, ഉയർന്ന അപകടസാധ്യതയുള്ള രഹസ്യ പാറ്റേണുകൾ എന്നിവ പരിശോധിക്കുന്നു.  
- `scripts/verify_notebooks.py --execute` റിപ്പോസിറ്ററി റൂട്ടിൽനിന്ന് പൊതുവായ നോട്ട്ബുക്കുകൾ പ്രവർത്തിപ്പിക്കുന്നു.  
- `drafts/` ഇലോ ഡ്രാഫ്റ്റ് ഉള്ളടക്കങ്ങൾ ഇച്ഛാനുസരണം ഒഴിവാക്കുന്നു.

## തുടര്‍ന്നുള്ള ജോലി

- സമാന സീനാരിയോ Alexa AI Search കേരള Azure OpenAI ഉപയോഗിച്ച് പുനർനിർമ്മിക്കുക, ഭാവിയിലെ സീരിസ് ഭാഗമായി.  
- പ്രാദേശികവും Azure ഇംപ്ലിമെന്റേഷനുകളും സ്ഥിരതയുള്ളതാകുന്നതോടെ റിട്രീവലും ഉത്തരം വിലയിരുത്തലും ചേർക്കുക.
