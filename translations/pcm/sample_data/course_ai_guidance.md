# Course Guide: Responsible AI Use

## Allowed Uses

Students fit use AI tools to compare ideas, check drafts, make am easier to read, and practice how to explain concepts for different ways.

## Required Disclosure

When AI tools dey used for assignment, the student suppose add one AI use note for the end of the submission. The note go carry the tool name, the kind help wey e give, and if any generated text join.

## Citation Expectations

AI-generated summaries no be primary sources. Students suppose cite original books, articles, datasets, or official documents instead of to dey cite the AI tool itself.

## Group Work

Teams suppose agree on how dem go use AI tools before dem start group work. Each team member still dey responsible to understand and explain the final submission.
