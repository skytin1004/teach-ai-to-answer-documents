# Scripts

हा फोल्डर रिपॉझिटरी पडताळणी स्क्रिप्ट्सचा समावेश करतो.

## `verify_notebooks.py`

स्थानिक Markdown दुवे, नोटबुक JSON, नोटबुक आउटपुटची स्वच्छता, आणि उच्च-जोखमीच्या गुप्त नमुन्यांची पडताळणी करते:

```powershell
python scripts\verify_notebooks.py
```

सर्व सार्वजनिक स्थानिक-सुरक्षित नोटबुक चालवतो:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions वर्कफ्लोही त्याच स्क्रिप्टचा वापर करतो.

`drafts/` अंतर्गत मसुदा साहित्य सार्वजनिक निर्देशांकासाठी तयार होईपर्यंत वगळले जाते.
