# योगदान

हा रेपो ब्लॉग मालिकेप्रमाणे तसेच चालवता येणाऱ्या नोटबुक उदाहरणांसह आयोजित केला आहे.

## पुल विनंती उघडण्यापूर्वी

स्थानिक सत्यापन स्क्रिप्ट चालवा:

```powershell
python scripts\verify_notebooks.py
```

अमलबजावणी किंवा नोटबुक बदलांसाठी, स्थानिक-सुरक्षित नोटबुक अंमलबजावणी चालवा:

```powershell
python scripts\verify_notebooks.py --execute
```

## नोटबुक मार्गदर्शक तत्त्वे

- नोटबुक वाचनीय ठेवा आणि संबंधित लेखावर लक्ष केंद्रीत ठेवा.
- जतन केलेले नोटबुक आउटपुट किंवा अंमलबजावणी संख्या कमिट करू नका.
- `sample_data/` मधील लहान नमुना डेटा वापरा जोपर्यंत लेखाला विशिष्ट बाह्य साधनाची गरज नसते.
- वर्तन बदलल्यानंतर विदृती संबंधित लेखात नोंदवा.

## गुपिते आणि प्रमाणपत्रे

- API कीज, टोकन्स, संकेतशब्द, खाजगी एपी घेतलेले नाहीत, किंवा `.env` फाइल कमिट करू नका.
- `.env.example` फक्त प्लेसहोल्डर किमतींसाठी वापरा.
- पर्यायी स्थानिक Ollama प्रयोगांसाठी पर्यावरणीय चल वापरा.

## दस्तऐवज

- लेख नेव्हिगेशन दुवे अद्ययावत ठेवा.
- नवीन लेख, नोटबुक, आवश्यकता फाइल, किंवा नमुना डेटा फाइल जोडताना `README.md` अद्ययावत करा.
- दिसणाऱ्या रेपो अद्ययावत करण्यापूर्वी `CHANGELOG.md` अद्ययावत करा.

## सत्यापन

GitHub Actions कार्यप्रवाह चालतो:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` अंतर्गत मसुदा सामग्री सार्वजनिक अनुक्रमणासाठी तयार होईपर्यंत रेपो सत्यापनातून वगळली जाते.

## समस्या

लेख दुरुस्तींसाठी लेख अभिप्राय टेम्पलेट वापरा आणि नोटबुक अंमलबजावणी समस्यांसाठी नोटबुक समस्या टेम्पलेट वापरा.
