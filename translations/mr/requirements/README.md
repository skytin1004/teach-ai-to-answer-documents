# आवश्यकता

प्रत्येक अंमलबजावणी लेखासाठी केंद्रित आवश्यकता फाइल असते.

| फाइल | वापरले जाते |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | सिरीज 2 मुक्त स्त्रोत RAG नोटबुक, पर्यायी Ollama जनरेशन सहाय्यकांसह |
| [all.txt](../../../requirements/all.txt) | संग्रहालय स्तरावर पडताळणी आणि CI |

एका नोटबुक चालवताना केंद्रित फाइल वापरा. संपूर्ण संग्रहालय पडताळताना `all.txt` वापरा.

`open-source-rag.txt` आणि `all.txt` मध्ये स्थानिक एम्बेडिंगसाठी `fastembed` आणि सिरीज 2 ला `.env` मधून Ollama जनरेशन पर्यायीपणे सक्षम करण्यासाठी `python-dotenv` समाविष्ट आहे, ज्यामुळे पुनर्प्राप्ती पाइपलाइन बदलण्याची गरज नाही.
