# आपल्या दस्तऐवजांवर आधारित प्रश्नांची उत्तरे देण्यासाठी AI शिकवा - मालिका आराखडा

हा आराखडा सार्वजनिक मालिका 1 आणि मालिका 2 रिलीझचा मागोवा घेतो. नंतर Azure आणि मूल्यांकनाचे कार्य उपपाठ्यरूपात ठेवले गेले आहे जोपर्यंत उदाहरणे पूर्णपणे अखंड आणि सत्यापित नाहीत.

स्पष्टपणे निर्देशित न करता बदल कमिट किंवा पुश करू नका.

## सार्वजनिक व्याप्ती

सध्याचा सार्वजनिक रिलीझ:

- मालिका 1 लेख: RAG आर्किटेक्चर निर्णय, Azure विरुद्ध ओपन-सोर्स व्यापार-offs, आणि फाइन-ट्यूनिंग कुठे बसते.
- मालिका 2 लेख: स्थानिक ओपन-सोर्स RAG ट्यूटोरियल.
- मालिका 2 नोटबुक: FastEmbed, Qdrant, Ollama, आणि Phi-4-mini सह राबवता येणारा स्थानिक RAG लॅब.
- नमुना डेटा: शाळेची धोरणे आणि कोर्स AI मार्गदर्शन Markdown फायली.

मुसळधार पण अद्याप सार्वजनिक निर्देशांकात नाही:

- Azure AI सर्च आणि Azure OpenAI पुनर्बांधणी.
- RAG मूल्यांकन आणि पुनरायोजनेची तपासणी.

## ट्यूटोरियल परिस्थिती

सामायिक परिस्थिती ही शाळेची धोरण सहाय्यक आहे.

सहाय्यक स्थानिक दस्तऐवजांमधून हा प्रश्न उत्तर देतो:

```text
Can I use generative AI for my final assignment?
```

अपेक्षित वर्तन:

1. स्थानिक Markdown दस्तऐवज लोड करा.
2. त्यांना शीर्षकेनुसार पार्स आणि विभागा.
3. स्थानिक एम्बेडिंग तयार करा आणि मेटाडेटासह शोधण्यायोग्य प्रतिनिधित्व जतन करा.
4. संबंधित धोरण विभाग मिळवा.
5. आवश्यकतेनुसार पुनर्स्थित करा.
6. एक आधारभूत उत्तर तयार करा किंवा संकलित करा.
7. संदर्भ परत करा.
8. सत्यापन निकाल नोंदवा.

## मालिका 2 सत्यापन

Windows वर Python 3.12.6 सह सत्यापित केले.

- `requirements/open-source-rag.txt` यशस्वीपणे स्थापित केले.
- `notebooks/series-2-open-source-rag.ipynb` `nbclient` ने चालवले.
- स्थानिक सत्यापन पास: 2 नमुना दस्तऐवज लोड झाले, 8 विभाग तयार केले, FastEmbed ने 384-आयामी स्थानिक एम्बेडिंग तयार केले, Qdrant इन-मेमरी संग्रह प्रारंभ केला, आणि 8 व्हेक्टर घातले.
- चाचणी प्रश्न: "मी माझ्या अंतिम असाइनमेंटसाठी जनरेटिव्ह AI वापरू शकतो का?"
- हलक्या पुनर्स्थितीनंतर सर्वाधिक मिळालेले स्त्रोत: `school_ai_policy.md`.
- हलक्या पुनर्स्थितीनंतर सर्वाधिक मिळालेले विभाग: `Final Assignments`.
- डीफॉल्ट उत्तर मार्ग: स्थानिक पारदर्शक उत्तर स्रष्टा.
- Ollama winget ने स्थापित केले; `phi4-mini:3.8b` यशस्वीपणे डाउनलोड झाले.
- Ollama उत्तर-निर्मिती मार्ग: `phi4-mini:3.8b` सह पूर्ण.
- Ollama मॉडेल फाईल आकार: डिस्कवर सुमारे 2.49GB.
- Ollama लोड केलेल्या मॉडेलचा आकार: `ollama ps` नुसार 3.3GB नोंदवले गेले.
- GPU ऑफलोड: RTX 3060 लॅपटॉप GPU वर `ollama ps` ने 100% GPU नोंदवले.
- निर्मितीनंतर GPU मेमरी निरीक्षण: 6GB पैकी सुमारे 3.5GB.
- FastEmbed मॉडेल कॅशेड आणि Ollama निर्मिती सक्षम करून नोटबुक चालवणे सत्यापन स्क्रिप्टद्वारे सुमारे 34 सेकंदांत यशस्वी.
- निरीक्षण: एक लवकर दस्तऐवज लोडिंग चालून चुकिच्या `sample_data/README.md` समाविष्ट झाले होते; आता नोटबुक फक्त दोन निर्दिष्ट नमुना दस्तऐवज स्पष्टपणे लोड करते.

## रीपॉझिटरी सत्यापन

- `scripts/verify_notebooks.py` स्थानिक Markdown दुवे, नोटबुक JSON, नोटबुक आउटपुट स्वच्छता, आणि उच्च-धोकादायक गुप्त नमुन्यांची पडताळणी करते.
- `scripts/verify_notebooks.py --execute` रीपॉझिटरी रूटमधून सार्वजनिक नोटबुक चालवते.
- `drafts/` अंतर्गत मुसळधार साहित्य जाणूनबुजून वगळले गेले आहे.

## पुढील काम

- भविष्यातील मालिकेच्या भाग म्हणून Azure AI सर्च आणि Azure OpenAI सह समान परिस्थिती पुनर्बांधणी करा.
- स्थानिक आणि Azure परिपक्व झाल्यावर पुनर्प्राप्ती आणि उत्तर मूल्यांकन जोडा.
