# नमुना डेटा

नोटबुक्स लहान सार्वजनिक नमुना कॉर्पस वापरतात ज्यामुळे उदाहरणे खाजगी कागदपत्रे किंवा क्लाउड प्रमाणपत्रांशिवाय चालू शकतात.

| फाईल | उद्देश |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | अंतिम असाईनमेंट्स, परीक्षा, संशोधन प्रकल्प, आणि प्रशिक्षकांच्या प्रतिस्थापनांबद्दल विभागांसह शाळेची धोरण आणखी कागदपत्र |
| [course_ai_guidance.md](./course_ai_guidance.md) | परवानगी असलेल्या वापर, प्रकटीकरण, उद्धरण अपेक्षा, आणि गट कार्याबद्दल विभागांसह कोर्स मार्गदर्शक कागदपत्र |

नमुना कागदपत्रे जाणूनबुजून लहान ठेवलेली आहेत. ती पुनर्प्राप्ती, मेटाडेटा, आणि उद्धरणांस सहज तपासण्यासाठी केली आहेत.
