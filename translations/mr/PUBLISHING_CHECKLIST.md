# प्रकाशन तपासणी यादी

सार्वजनिक अपडेट कमिट किंवा पुश करण्यापूर्वी ही तपासणी यादी वापरा.

## सुरक्षितता

- Markdown फायली, नोटबुक, नमुना डेटा किंवा स्क्रिप्टमध्ये कोणतेही API की, टोकन्स, पासवर्ड किंवा खाजगी एन्डपॉइंट्स लिहिलेले नाहीत याची खात्री करा.
- साखळीमध्ये क्रेडेन्शियल्स न ठेवता, पर्यावरणीय चल किंवा व्यवस्थापित ओळखीत ठेवा.
- `.env` फाइल किंवा निष्पादित नोटबुक आउटपुट फाइल्स कमिट करू नका.
- `.env.example` फक्त प्लेसहोल्डर म्हणून ठेवा.

## पडताळणी

रिपॉझिटरी पडताळणी स्क्रिप्ट चालवा:

```powershell
python scripts\verify_notebooks.py
```

अमलबजावणीमध्ये बदल प्रकाशित करण्यापूर्वी संपूर्ण स्थानिक-सुरक्षित नोटबुक अंमलबजावणी चालवा:

```powershell
python scripts\verify_notebooks.py --execute
```

अपेक्षित तपासण्या:

- स्थानिक Markdown दुवे यशस्वी होते
- नोटबुक JSON वैधता यशस्वी होते
- नोटबुकमध्ये जतन केलेले आउटपुट किंवा अंमलबजावणी मोजणी नाहीत
- उच्च-जोखिम गुप्त नमुना स्कॅन यशस्वी होते
- सार्वजनिक नोटबुक स्थानिकपणे अंमलात येतात
- `drafts/` खालील मसुदा सामग्री जानूने वगळली जाते

## पुनरावलोकन

- README लेख दुवे इच्छित फाइल्सकडे निर्देशित आहेत याची खात्री करा.
- प्रत्येक लेखात रिपॉझिटरी नेव्हिगेशन आणि संबंधित नोटबुक दुवे आहेत याची खात्री करा.
- मसुदे सार्वजनिक निर्देशिकेतून लिंक केलेले नाहीत, जोपर्यंत ते प्रकाशित करण्यासाठी तयार नाहीत.
- GitHub इश्यू आणि पुल रिक्वेस्ट टेम्पलेट्स अजूनही रिपॉझिटरी कार्यप्रवाहाशी सुसंगत आहेत याची खात्री करा.
- लेखातील पडताळणी निकाल नवीनतम नोटबुक आउटपुटशी जुळतात याची खात्री करा.
- GitHub Actions कार्यप्रवाह पुश नंतर चालण्याची अपेक्षा आहे याची खात्री करा.
- `CHANGELOG.md` मध्ये प्रकाशित होणाऱ्या अद्यतनाचा उल्लेख आहे याची खात्री करा.
- `CONTRIBUTING.md` अजूनही रिपॉझिटरी कार्यप्रवाहाशी सुसंगत आहे याची खात्री करा.

## Git

- `git status --short --branch` पुनरावलोकन करा.
- `git diff --stat` पुनरावलोकन करा.
- फक्त स्पष्टपणे तयार असताना कमिट आणि पुश करा.
