# बदलनोंची नोंद

## अजून प्रदर्शित नाही

**Teach AI to Answer Questions Based on Your Documents** साठी प्रारंभिक सार्वजनिक प्रकाशन श्रेणी.

### जोडलेले

- RAG आर्किटेक्चर निर्णयांवर, Azure विरुद्ध मुक्त स्रोत व्यापारांवर, आणि fine-tuning कुठे बसते यावर Series 1 लेख.
- Qdrant लोकल मोड, FastEmbed लोकल एम्बेडिंग्ज, लाइटवेट री-रैंकिंग, Ollama, आणि Phi-4-मिनी वापरून लोकल मुक्त स्रोत RAG वर्कफ्लो साठी Series 2 लेख आणि नोटबुक.
- Python स्निपेट्स आणि चाललेला नोटबुकमधून पडताळणी नोंदींसह Series 2 चे टप्पा-दर-टप्पा अखेरचे ट्युटोरियल स्वरूप.
- लोकल CPU- योग्य पुनर्प्राप्ती डिफॉल्ट मार्ग ठेवताना Ollama आणि Phi-4-मिनी यांसह ऑप्शनल Series 2 उत्तर-निर्मिती मार्ग.
- RTX 3060 लॅपटॉप GPU वर `phi4-mini:3.8b` वापरून Series 2 साठी स्थानिक Ollama पडताळणी.
- शाळेच्या धोरणासाठी आणि अभ्यासक्रम AI मार्गदर्शनासाठी नमुना डेटा.
- सार्वजनिक नोटबुक आणि रिपॉझिटरी-स्तरीय पडताळणीसाठी आवश्यक फाइल्स.
- स्थानिक Markdown दुवे आणि नोटबुक पडताळणी/अमलबजावणीसाठी रिपॉझिटरी पडताळणी स्क्रिप्ट.
- नोटबुक पडताळणीसाठी GitHub Actions वर्कफ्लो.
- स्थानिक Ollama निर्मितीसाठी `.env.example` जे स्थानिक कॉन्फिगरेशन कमिट न करता वापरता येईल.
- लेख, नोटबुक, आवश्यक फाइल्स, नमुना डेटा, आणि स्क्रिप्टसाठी फोल्डर-स्तरीय README फाइल्स.
- सार्वजनिक सुरक्षा आणि पडताळणीसाठी प्रकाशन तपासणी यादी.
- भविष्यातील Azure आणि मूल्यांकन सामग्रीसाठी मसुदा वर्कस्पेस.

### पडताळलेले

- स्थानिक Markdown लिंक पडताळणी उत्तीर्ण.
- Series 2 नोटबुक यशस्वीपणे पडताळलेले.
- Series 2 नोटबुक स्थानिक पडताळणी पर्यावरणात यशस्वीपणे चालवलेले.
- नोटबुक फाइल्स सेव्ह केलेले आउटपुट किंवा अंमलबजावणी मोजणीशिवाय ठेवलेले.
- कोणतेही वास्तविक गुपिते कमिट केलेले नाहीत.
