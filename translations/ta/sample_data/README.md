# மாதிரி נתונים

நோட்புக்குகள் சிறிய பொது மாதிரி கூர்பஸைக் பயன்படுத்துகின்றன, ஆகவே உதாரணங்கள் தனிப்பட்ட ஆவணங்கள் அல்லது மேக அணுகல் விவரங்களின்றி இயங்க முடியும்.

| கோப்பு | நோக்கம் |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | இறுதி பணிகள், தேர்வுகள், ஆராய்ச்சி திட்டங்கள் மற்றும் பேராசிரியர் மாற்றங்கள் பற்றி பிரிவுகள் கொண்ட ஒரு பள்ளி கொள்கை ஆவணம் |
| [course_ai_guidance.md](./course_ai_guidance.md) | அனுமதிக்கப்பட்ட பயன்பாடுகள், மாற்றம், மேற்கோள் எதிர்பார்ப்புகள் மற்றும் குழுக் வேலை பற்றி பிரிவுகள் கொண்ட ஒரு படிப்புக் கையேடு ஆவணம் |

மாதிரி ஆவணங்கள் குறைவாக உள்ளன. அவை மீட்டெடுக்கும், மெட்டாடேட்டா மற்றும் மேற்கோள்களை எளிதாக பரிசீலிக்க உருவாக்கப்பட்டவை.
