# Scripts

இந்த கோப்பு களஞ்சியத்தை சரிபார்க்கும் ஸ்கிரிப்ட்களை கொண்டுள்ளது.

## `verify_notebooks.py`

உள்ளூர் மார்க்டவுன் இணைப்புகள், நோட்புக் JSON, நோட்புக் வெளியீட்டு சுத்தம் மற்றும் உயர்-ஆபத்து இரகசிய மாதிரிகள் சரிபார்க்கிறது:

```powershell
python scripts\verify_notebooks.py
```

அனைத்து பொது உள்ளூர்-பாதுகாப்பு நோட்புக்களை இயக்குகிறது:

```powershell
python scripts\verify_notebooks.py --execute
```

GitHub Actions பணிமுறை அதே ஸ்கிரிப்ட்டைப் பயன்படுத்துகிறது.

`drafts/` கீழுள்ள வரைவு பொருள் பொதுச் குறியீட்டுக்கு தயாராகும் வரை தவிர்க்கப்படுகிறது.
