# மாற்றம்சூழல்

## வெளியிடப்படாதவை

**உங்கள் ஆவணங்களின் அடிப்படையில் கேள்விகளுக்கு பதில் அளிக்க AI-ஐ பயிற்றுவிக்க** ஆரம்ப பொதுப் வெளியீட்டு வரைபடம்.

### சேர் செய்யப்பட்டவை

- RAG கட்டமைப்பு தீர்வுகள், Azure மத்தியிலும் திறந்த மூல வர்த்தகங்களின் உறுதிப்படுத்தல்கள் மற்றும் மிகை அழுத்தம் எங்கு பொருந்துகிறது என்பதில் தொடர் 1 கட்டுரை.
- Qdrant உள்ளூர் முறை, FastEmbed உள்ளூர் உறுப்பிகள், எளிய மீண்டும் வரிசைப்படுத்துதல், Ollama மற்றும் Phi-4-mini பயன்படுத்தும் உள்ளக திறந்த மூல RAG பணியெழுத்துக்கான தொடர் 2 கட்டுரை மற்றும் நோட்புக்.
- Python துணுக்குகளுடன் மற்றும் இயக்கப்பட்ட நோட்புக் இருந்து சரிபார்ப்பு குறிப்புகளுடன் தொடர் 2 படி படியான முழு பயிற்சி வடிவம்.
- உள்ளூர் CPU-க்கு நடுவில் மீட்டெடுப்பு இயலுமையான வழியை நிலையாக வைத்துக்கொண்டு Ollama மற்றும் Phi-4-mini உடன் விருப்ப தொடர் 2 பதிலளிப்பு உருவாக்கும் பாதை.
- RTX 3060 லேப்டாப் GPU-ல் `phi4-mini:3.8b` பயன்படுத்தி தொடர் 2 உள்ளூர் Ollama சரிபார்ப்பு.
- பாடசாலை கொள்கை மற்றும் பாட AI வழிகாட்டலுக்கான மாதிரிப் தரவு.
- பொது நோட்புக் மற்றும் தொகுப்பகம் அடிப்படையிலான சரிபார்ப்பு தேவைகள் கோப்புகள்.
- உள்ளூர் Markdown இணைப்புகள் மற்றும் நோட்புக் சரிபார்ப்பு/இயக்கத்திற்கு தொகுப்பகம் சரிபார்ப்பு ஸ்கிரிப்ட்.
- நோட்புக் சரிபார்ப்பிற்கான GitHub Actions பணியெழுத்து.
- உள்ளூர் உள்ளமைவு cammit செய்யாமல் விருப்ப உள்ளூர் Ollama உற்பத்தி அமைப்புக்கான `.env.example`.
- கட்டுரைகள், நோட்புக், தேவைகள், மாதிரிப் தரவு மற்றும் ஸ்கிரிப்டுகளுக்கான கோப்புறைக் README கோப்புகள்.
- பொது பாதுகாப்பு மற்றும் சரிபார்ப்பிற்கான வெளியீட்டு செக் லிஸ்ட்.
- எதிர்கால Azure மற்றும் மதிப்பீடு உள்ளடக்கத்துக்கான வரைவு வேலைநிலையில்.

### சரிபார்க்கப்பட்டவை

- உள்ளூர் Markdown இணைப்பு சரிபார்ப்பு கடந்து உள்ளது.
- தொடர் 2 நோட்புக் வெற்றிகரமாக சரிபார்க்கப்பட்டது.
- தொடர் 2 நோட்புக் உள்ளூர் சரிபார்ப்பு சூழலில் வெற்றிகரமாக இயங்கியது.
- நோட்புக் கோப்புகள் சேமிக்கப்பட்ட வெளிப்பாடுகளும் அல்லது இயக்க எண்ணிக்கைகளும் இல்லாமல் வைத்திருக்கும்.
- எந்த உண்மையான இரகசியங்களும் cammit செய்யப்படவில்லை.
