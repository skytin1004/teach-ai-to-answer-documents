# கட்டுரைகள்

இந்த கோப்புறை மார்க்டவுன் கட்டுரை தொடர்களைக் கொண்டுள்ளது.

| தொடர் | கட்டுரை | கவனம் |
| --- | --- | --- |
| தொடர் 1 | [RAG, Azure மற்றும் திறந்த மூல மாற்றுகள், மற்றும் சிறப்பு பயிற்சி எப்போது பொருந்தும்](./series-1-rag-azure-open-source-fine-tuning.md) | ஆவணம் அடிப்படையிலான AI அமைப்புகளுக்கான தீர்மான வடிவமைப்பு |
| தொடர் 2 | [ஒரு உள்ளூர் திறந்த மூல RAG அமைப்பை முடிவுக்கு கொண்டு வருக](./series-2-open-source-rag-end-to-end.md) | உள்ளூர் மாதிரி ஆவணங்கள், Qdrant உள்ளூர் முறை, மீட்டெடுக்கும், மீறுமுறை, மற்றும் மூல இணைப்பு |

தொடர் 3 மற்றும் பின்னர் பகுதிகள் தனித்தனியாக உருவாக்கப்படுகின்றன மற்றும் தற்போதைய பொது குறியீட்டில் உள்ளடக்கப்படவில்லை.
