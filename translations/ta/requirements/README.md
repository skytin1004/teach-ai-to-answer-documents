# தேவைகள்

ஒவ்வொரு அமலாக்கக் கட்டுரைக்கும் ஒரு கவனிக்கப்பட்ட தேவைகள் கோப்பு உள்ளது.

| கோப்பு | பயன்படும் இடம் |
| --- | --- |
| [open-source-rag.txt](../../../requirements/open-source-rag.txt) | தொடர் 2 திறந்த மூல RAG நோட்புக், விருப்பமான Ollama உருவாக்க உதவிகளுடன் |
| [all.txt](../../../requirements/all.txt) | களஞ்சிய நிலை சரிபார்ப்பு மற்றும் CI |

ஒரு நோட்புக் இயக்கும் போது கவனிக்கப்பட்ட கோப்பைப் பயன்படுத்தவும். முழு களஞ்சியத்தை சரிபார்க்கும்போது `all.txt` ஐ பயன்படுத்தவும்.

`open-source-rag.txt` மற்றும் `all.txt` உள்ளூர் நொளிப்படுதல்கள் கிடைக்க `fastembed` மற்றும் தொடர் 2 `.env` இல் இருந்து மாற்றம் செய்யாமல் Ollama உருவாக்கத்தை விரும்பத்தக்கவாறு இயக்க `python-dotenv` ஐ கொண்டுள்ளன.
