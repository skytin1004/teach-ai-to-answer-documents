# வெளியீட்டு சரிபார்ப்பு பட்டியல்

பொது புதுப்பிப்புகளை உறுதிப்பத்திரம் செய்தல் அல்லது தள்ளுவதற்கு முன் இந்த சரிபார்ப்பு பட்டியலை பயன்படுத்தவும்.

## பாதுகாப்பு

- API விசைகள், டோக்கன்கள், கடவுச்சொற்கள் அல்லது தனிப்பட்ட இறுதிப்புள்ளிகள் Markdown கோப்புகள், நோட்புக், மாதிரிச் தகவல்கள் அல்லது ஸ்கிரிப்ட்களில் எழுதப்படவில்லை என்பதனை உறுதிபடுத்தவும்.
- அடையாள அங்கீகாரம் கோப்புகளுக்கு பதிலாக சூழல் மாறிலிகள் அல்லது நிர்வகிக்கப்பட்ட அடையாளத்தில் வைதல்.

- `.env` கோப்புகளை அல்லது இயங்கிய நோட்புக் விளைவுகளை உறுதிப்பத்திரம் செய்யக்கூடாது.
- `.env.example` மட்டுமே நிறைவேற்றப்பட வேண்டும்.

## சரிபார்ப்பு

கோப்பக சரிபார்ப்பு ஸ்கிரிப்டை இயக்கவும்:

```powershell
python scripts\verify_notebooks.py
```

வெளியீடு செயல்பாடுகளை வெளியிடுவதற்கு முன் முழு உள்ளூர்-பாதுகாப்பான நோட்புக் செயல்பாட்டை இயக்கவும்:

```powershell
python scripts\verify_notebooks.py --execute
```

எதிர்பார்க்கப்படும் சரிபார்ப்புகள்:

- உள்ளூர் Markdown இணைப்புகள் கடந்து செல்வது
- நோட்புக் JSON சரிபார்ப்பு கடந்து செல்வது
- நோட்புக் கள் சேமிக்கப்பட்ட வெளியீடுகள் அல்லது செயல்பாட்டு கணக்குகளை கொண்டிருக்க வேண்டாம்
- உயர்-ஆபத்தான ரகசிய வாரிய வடிவம் சரிபார்ப்பு கடந்து செல்வது
- பொது நோட்புக் கள் உள்ளூரில் இயங்குகின்றன
- `drafts/` கீழ் உள்ள வரைவு பொருள் எதிர்பாராத முறையில் தவிர்க்கப்படுகிறது

## மதிப்பாய்வு

- README கட்டுரை இணைப்புகள் நோக்கி வேறு கோப்புகள் இலக்கிடப்படுகிறதா என்பதை உறுதிப்படுத்தவும்.
- ஒவ்வொரு கட்டுரைக்கும் கோப்பக மற்றும் தொடர்புடைய நோட்புக் இணைப்புகள் உள்ளன என உறுதிப்படுத்தவும்.
- வரைவுகள் பொதுச் பட்டியல்களில் இணைக்கப்படவில்லை என்பதை உறுதிப்படுத்தவும், அவை வெளியிட தயாராக உள்ளதே இல்லையெனில்.
- GitHub குறைக்கோள் மற்றும் ஈர்க்கும் வேண்டுகோள் மாதிரிகள் இன்னும் கோப்பக பணிமுறைக்கு பொருந்துகிறதா என்பதை உறுதிப்படுத்தவும்.
- கட்டுரையில் சரிபார்ப்பு முடிவுகள் கடைசிநோட்புக் வெளியீட்டுடன் பொருந்துகிறதா என்பதை உறுதிப்படுத்தவும்.
- GitHub நடவடிக்கைகள் பணிமுறை தள்ளல் பிறகு இயங்குவதாக எதிர்பார்க்கப்படுகிறது என்பதை உறுதிப்படுத்தவும்.
- `CHANGELOG.md` வெளியிடப்படும் புதுப்பிப்பை பிரதிபலிக்கிறது என்பதை உறுதிப்படுத்தவும்.
- `CONTRIBUTING.md` இன்னும் கோப்பக பணிமுறைக்கு பொருந்துகிறது என்பதை உறுதிப்படுத்தவும்.

## Git

- `git status --short --branch` ஐ மதிப்பாய்வு செய்யவும்.
- `git diff --stat` ஐ மதிப்பாய்வு செய்யவும்.
- தெளிவாக தயாராக இருக்கும் போது மட்டும் உறுதிப்பத்திரம் செய்யவும் மற்றும் தள்ளவும்.
