## உள்ளூர் இயக்குதல்

நீங்கள் இயக்க விரும்பும் நோட்புக்கிற்கு தேவையானவை நிறுவு:

```powershell
python -m venv .venv-series2
.\.venv-series2\Scripts\activate
python -m pip install -r requirements\open-source-rag.txt
```

அல்லது அனைத்து சார்புக்களையும் நிறுவு:

```powershell
python -m pip install -r requirements\all.txt
```

## உறுதிப்படுத்துக

காட்டியிலிருந்து:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

தொடர் 2 Ollama கட்டமைப்பைக் காட்சி மூலம் ரெப்போ-ருட் `.env` கோப்பில் படிக்க முடியும். தொடங்க [../.env.example](../../../.env.example) என்ற கோப்பிலிருந்து, இது தொடரின்படி பிரிக்கப்பட்டது.
