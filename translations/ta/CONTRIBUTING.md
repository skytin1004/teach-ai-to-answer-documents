# பங்களிக்க

இந்த ரெப்பாசிடரி ஒரு பிளாக் தொடர் மற்றும் இயக்கக்கூடிய நோட்புக் எடுத்துக்காட்டுகளாக அமைக்கப்பட்டுள்ளது.

## புல் கோரிக்கை துவங்குவதற்கு முன்பு

உள்ளூர் உறுதிப்படுத்தல் ஸ்கிரிப்ட்டை இயக்கவும்:

```powershell
python scripts\verify_notebooks.py
```

நடவடிக்கை அல்லது நோட்புக் மாற்றங்களுக்கு, உள்ளூர்-பாதுகாப்பான நோட்புக் இயக்கத்தைக் இயக்கவும்:

```powershell
python scripts\verify_notebooks.py --execute
```

## நோட்புக் வழிகாட்டிகள்

- நோட்புக்களை வாசிக்க கூடியதும் தொடர்புடைய கட்டுரையில் கவனம் செலுத்தப்பட்டதுமானதாக வைத்திருங்கள்.
- சேமிக்கபட்ட நோட்புக் வெளியீடுகள் அல்லது இயக்க எண்ணிக்கைகளை கமிட் செய்யாதீர்கள்.
- கட்டுரை ஒரு குறிப்பிட்ட வெளிப்புற வளத்தை தேவைப்படுத்தாதவரை, `sample_data/` இலிருந்து சிறிய மாதிரியான தரவை பயன்படுத்துங்கள்.
- நடத்தை மாற்றங்களுக்குப் பதிவு முடிவு தொடர்புடைய கட்டுரையில் பதிவு செய்யவும்.

## ரகசியங்கள் மற்றும் அடையாள சான்றிதழ்கள்

- API விசைகள், டோக்கன்கள், கடவுச்சொற்கள், தனிப்பட்ட முடிவுக்கான முகவரிகள் அல்லது `.env` கோப்புகளை கமிட் செய்யாதீர்கள்.
- `.env.example` ஐ மட்டுமே இடைவெளி மதிப்புகளுக்குப் பயன்படுத்துங்கள்.
- விருப்பமான உள்ளூர் Ollama பரிசோதனைகளுக்கு சுற்றுச்சூழல் மாறிலிகள் பயன்படுத்தவும்.

## ஆவணப்படுத்தல்

- கட்டுரை வழிசெலுத்தல் இணைப்புகளை சமீபத்திய நிலையில் வைத்திருங்கள்.
- புதிய கட்டுரை, நோட்புக், தேவையான கோப்பு அல்லது மாதிரி தரவு கோப்பு சேர்க்கும் போது `README.md` புதுப்பிக்கவும்.
- பார்வைக்கூடிய ரெப்பாசிடரி புதுப்பிப்பை வெளியிடுவதற்கு முன் `CHANGELOG.md` ஐ புதுப்பிக்கவும்.

## உறுதிப்படுத்தல்

GitHub செயற்பாடுகள் வேலைபோக்கு இயக்குகிறது:

```powershell
python scripts\verify_notebooks.py
python scripts\verify_notebooks.py --execute
```

`drafts/` கீழ் உள்ள வரைபட பொருட்கள் பொது குறியீட்டிற்காக தயார் ஆகும் வரை ரெப்பாசிடரி verification மூலம் தவிர்க்கப்படுகின்றன.

## பிரச்சனைகள்

கட்டுரை திருத்தங்களுக்காக கட்டுரை பின்னூட்ட மாதிரியை மற்றும் நோட்புக் செயற்பாட்டு பிரச்சனைகளுக்காக நோட்புக் பிரச்சனை மாதிரியைப் பயன்படுத்தவும்.
