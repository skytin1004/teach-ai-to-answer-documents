# உங்கள் ஆவணங்களுக்கு அடிப்படையாகக் கொண்டு கேள்விகளுக்கு பதில் சொல்ல AI-ஐ கற்பிக்க - தொடர்ச்சிப் திட்டம்

இந்தத் திட்டம் பொது தொடரணி 1 மற்றும் தொடரணி 2 வெளியீட்டை கண்காணிக்கிறது. பின்னர் Azure மற்றும் மதிப்பாய்வு பணிகள் உதாரணங்கள் முழுமையாக முடிவடையும் மற்றும் சரிபார்க்கப்படும் வரை வரைபாகங்களாக வைக்கப்படுகின்றன.

விரிவான அறிவுறுத்தல்கள் இல்லாமல் மாற்றங்களை கட்டுப்படுத்தவோ, தள்ளவோ வேண்டாம்.

## பொது பரப்பளவு

தற்போதைய பொது வெளியீடு:

- தொடரணி 1 கட்டுரை: RAG கட்டமைப்பு முடிவுகள், Azure மற்றும் திறந்த மூல வர்த்தகத் தள்ளுபடிகள், மற்றும் எங்கே நுட்பமாக அமைத்தல் பொருந்துகிறது.
- தொடரணி 2 கட்டுரை: உள்ளூர் திறந்த மூல RAG பாடநெறி.
- தொடரணி 2 நோட்புக்: FastEmbed, Qdrant, Ollama மற்றும் Phi-4-mini உடன் இயக்கக்கூடிய உள்ளூர் RAG ஆய்வு கூடம்.
- மாதிரி தரவு: பள்ளி கொள்கை மற்றும் பாட AI வழிகாட்டி Markdown கோப்புகள்.

வரைவிலக்காக உள்ளதாயினும் இன்னும் பொது குறியீட்டில் சேர்க்கப்படவில்லை:

- Azure AI Search மற்றும் Azure OpenAI மீள்கட்டமைப்பு.
- RAG மதிப்பாய்வு மற்றும் பிறவி சோதனைகள்.

## பாடத்திட்ட சூழல்

பகிரப்பட்ட சூழல் என்பது ஒரு பள்ளி கொள்கை உதவியாளராகும்.

உதவியாளர் உள்ளூர் ஆவணங்களிலிருந்து இந்தக் கேள்விக்கு பதில் அளிக்கிறது:

```text
Can I use generative AI for my final assignment?
```
  
எதிர்பார்க்கப்பட்ட நடத்தை:

1. உள்ளூர் Markdown ஆவணங்களை ஏற்றுகொள்ளவும்.  
2. தலைப்புகளின் படி பகுப்பாய்வு செய்து துண்டுகளை உருவாக்கவும்.  
3. உள்ளூர் எண்ணங்களை உருவாக்கி, தொகுப்புகளுடன் கூடிய தேடக்கூடிய பிரதிநிதிகளை சேமிக்கவும்.  
4. தொடர்புடைய கொள்கை பிரிவை மீட்டெடுக்கவும்.  
5. தேவையான போது மறுபங்கீட்டு செய்யவும்.  
6. அடிப்படையுடைய பதிலை உருவாக்கவும் அல்லது தொகுக்கவும்.  
7. மேற்கோள்களை திருப்பி அளிக்கவும்.  
8. சரிபார்ப்பு முடிவுகளை பதிவு செய்யவும்.

## தொடரணி 2 சரிபார்ப்பு

Windows மற்றும் Python 3.12.6 உடன் சரிபார்க்கப்பட்டது.

- `requirements/open-source-rag.txt` வெற்றிகரமாக நிறுவப்பட்டது.  
- `notebooks/series-2-open-source-rag.ipynb` `nbclient` உடன் இயங்கப்பட்டது.  
- உள்ளூர் சரிபார்ப்பு நிறைவேற்றப்பட்டது: 2 மாதிரி ஆவணங்கள் ஏற்றப்பட்டது, 8 துண்டுகள் உருவாக்கப்பட்டது, FastEmbed 384-பரிமாண உள்ளூர் எண்ணங்கள் உண்டாக்கியது, Qdrant நினைவகத் தொகுப்பு துவக்கப்பட்டது மற்றும் 8 செல்லிகள் சேர்க்கப்பட்டது.  
- சோதனை கேள்வி: "என் இறுதி ஒதுக்கீட்டிற்கு நான் உருவாக்கும் AI-யை பயன்படுத்தலாமா?"  
- இலகுரக மறுபங்கீட்டுக்கு பின் சிறந்த பெற்றீடு மூலமாக: `school_ai_policy.md`.  
- இலகுரக மறுபங்கீட்டுக்கு பின் சிறந்த பெற்றீடு பிரிவு: `Final Assignments`.  
- இயல்புநிலை பதில் பாதை: உள்ளூர் தெளிவான பதில் தொகுப்பாளர்.  
- Ollama winget மூலம் நிறுவப்பட்டது; `phi4-mini:3.8b` வெற்றிகரமாக இறக்கப்பட்டது.  
- Ollama பதில் உருவாக்க பாதை: `phi4-mini:3.8b` உடன் முடிந்தது.  
- Ollama மாடல் கோப்பு அளவு: சுமார் 2.49GB வட்டு ஆவணத்தில்.  
- Ollama ஏற்றுக் கொண்ட மாடல் அளவு: `ollama ps` மூலம் 3.3GB அறிவிக்கப்பட்டது.  
- GPU ஏற்றுதலைப் பொறுத்து: RTX 3060 லேப்டாப் GPU-யில் `ollama ps` மூலம் 100% GPU அறிவிக்கப்பட்டது.  
- உருவாக்கத்திற்கு பின் GPU நினைவகம் கவனிக்கப்பட்டது: 6GB-இல் சுமார் 3.5GB.  
- காட்சி மாடல் மற்றும் Ollama உருவாக்க உதவும் நோட்புக் 34 விநாடிகளில் சரிபார்ப்பு ஸ்கிரிப்ட் மூலம் வெற்றிகரமாக இயங்கியது.  
- கவனிப்பு: ஆரம்ப ஆவண ஏற்றல் முயற்சியில் தவறுதலாக `sample_data/README.md` சேர்க்கப்பட்டது; இப்போது நோட்புக் இரண்டு குறிப்பிட்ட மாதிரி ஆவணங்களையே தெளிவாக ஏற்றுகிறது.

## அகவை சரிபார்ப்பு

- `scripts/verify_notebooks.py` உள்ளூர் Markdown இணைப்புகள், நோட்புக் JSON, நோட்புக் வெளிப்படையான தன்மை மற்றும் ஆபத்து மிகுந்த ரகசிய வார்ப்புக்கிண்ணங்களைக் சரிபார்க்கிறது.  
- `scripts/verify_notebooks.py --execute` கொண்டு பொதுநோட்பூக்களை தொகுதிச்சரியான மூலத்தில் இருந்து இயக்குகிறது.  
- `drafts/` கீழ் உள்ள வரைவிலக்கப் பொருட்கள் விரும்பி தவிர்க்கப்படுகின்றன.

## அடுத்த பணிகள்

- அதே சூழலை Azure AI Search மற்றும் Azure OpenAI உடன் மீள்கட்டமைக்க போதுமான கால திருப்பாக மூலமாகச் செய்ய வேண்டும்.  
- உள்ளூர் மற்றும் Azure செயலாக்கங்கள் இரண்டும் நிலைத்தடை பெறும்போது மீட்டெடுக்கும் மற்றும் பதில் மதிப்பீட்டைப் பின்பற்ற வேண்டும்.
