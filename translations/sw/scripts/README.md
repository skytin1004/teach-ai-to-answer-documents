# Scripts

Hii folda ina skripti za uhakiki za hazina.

## `verify_notebooks.py`

Inathibitisha viungo vya Markdown vya ndani, JSON ya daftari, usafi wa matokeo ya daftari, na mifumo ya siri yenye hatari kubwa:

```powershell
python scripts\verify_notebooks.py
```

Hutekeleza daftari zote za umma zilizo salama kwa ndani:

```powershell
python scripts\verify_notebooks.py --execute
```

Kazi ya GitHub Actions inatumia skripti ile ile.

Nyaraka za rasimu chini ya `drafts/` hazizingatiwi hadi ziko tayari kwa faharasa ya umma.
