# Zoznam zmien

## Nezverejnené

Počiatočný verejný rozsah vydania pre **Naučiť AI odpovedať na otázky na základe vašich dokumentov**.

### Pridané

- Článok série 1 o rozhodnutiach architektúry RAG, kompromisoch Azure vs open-source a kde zapadá doladenie.
- Článok série 2 a poznámkový blok pre lokálny open-source RAG pracovný postup pomocou režimu Qdrant lokal, lokálnych embeddingov FastEmbed, ľahkého pretriedenia, Ollama a Phi-4-mini.
- Formát krok-za-krokom tutoriálu série 2 s Python útržkami a poznámkami overenia z vykonaného poznámkového bloku.
- Voliteľná cesta generovania odpovedí série 2 s Ollama a Phi-4-mini pri zachovaní lokálneho CPU-priateľského vyhľadávania ako predvolenej cesty.
- Lokálne overenie Ollama pre sériu 2 pomocou `phi4-mini:3.8b` na RTX 3060 Laptop GPU.
- Ukážkové dáta pre školskú politiku a usmernenie AI kurzu.
- Súbory požiadaviek pre verejný poznámkový blok a overenie na úrovni repozitára.
- Skript na overenie repozitára pre lokálne odkazy Markdown a validáciu/vykonanie poznámkového bloku.
- Pracovný tok GitHub Actions pre overenie poznámkového bloku.
- `.env.example` pre voliteľné nastavenie lokálnej generácie Ollama bez commitovania lokálnej konfigurácie.
- Súbory README na úrovni priečinkov pre články, poznámkové bloky, požiadavky, ukážkové dáta a skripty.
- Kontrolný zoznam publikovania pre verejnú bezpečnosť a overenie.
- Návrh pracovného priestoru pre budúci obsah Azure a hodnotenia.

### Overené
