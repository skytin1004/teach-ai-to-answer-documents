# Course Guide: Responsible AI Use

## Allowed Uses

Students can use AI tools to compare ideas, review drafts, improve readability, and practice explaining concepts in different ways.

## Required Disclosure

When AI tools are used for an assignment, the student should add an AI use note at the end of the submission. The note should include the tool name, the type of assistance, and whether any generated text was included.

## Citation Expectations

AI-generated summaries are not primary sources. Students should cite original books, articles, datasets, or official documents instead of citing the AI tool itself.

## Group Work

Teams should agree on how AI tools will be used before starting group work. Each team member remains responsible for understanding and explaining the final submission.
