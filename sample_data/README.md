# Sample Data

The notebooks use a small public sample corpus so the examples can run without private documents or cloud credentials.

| File | Purpose |
| --- | --- |
| [school_ai_policy.md](./school_ai_policy.md) | A school policy document with sections about final assignments, exams, research projects, and instructor overrides |
| [course_ai_guidance.md](./course_ai_guidance.md) | A course guide document with sections about allowed uses, disclosure, citation expectations, and group work |

The sample documents are intentionally small. They are meant to make retrieval, metadata, and citations easy to inspect.
